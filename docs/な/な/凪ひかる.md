## 简介

凪ひかる是日本AV女优。2020年7月起以「有栖花あか」名义在写真周刊杂志刊登裸体写真，同年9月发行写真集《Big Baby》进入演艺圈，10月以「とにかく顔が美形--、とにかく乳が美形--」（总之脸很美——总之胸很美——）为宣传语，从S1 NO.1 STYLE专属AV出道。出道作在FANZA「2020年年度DVD排行」中Blu-ray版列第6位、DVD版列第8位。此后两度改名：2021年12月改为「汐世」，2022年11月改为现名「凪ひかる」并移籍8MAN，同期参与该事务所的写真企划「8woman」。她以105cm的J罩杯与端正面容为卖点，乳交题材为标志性特色，出道以来始终是S1的专属女优。所属事务所 8MAN 现已改称 SO MODEL AGENT（官网 8man.jp 跳转至 so-agent.jp），2026年官方档案仍以其名义刊载本人资料。

## 人物

- 兴趣为观赏动画、游戏、与狗猫玩耍；特技是能立刻入睡。
- 决定出演AV的契机是此前就对AV有兴趣、想亲自尝试。
- 身材变化：初中二年级时仅A罩杯、未穿胸罩；初三起急速发育到D～E罩杯；升入高中后长到H罩杯。初体验为高一与高一届的前辈，初次乳交为高二。
- 出生日期存在两种口径：以「有栖花あか」名义活动时公开的生日为1998年2月17日（据S1官方女优页），现名下（官方档案）为1997年4月6日。
- AV评论家渋江譲二评价其身材「どの体位でもダイナミックに暴れまくるさまはもはやエンターテインメント」（无论何种体位都动感十足地横冲直撞，已是娱乐表演）。
- 关于从「有栖花あか」改名「汐世」的理由，她在采访中表示是「对AV女优身份意识的转变」「想作为AV女优活下去」，并称「其实想用本名」。

## 作品特征

- 出道起即为S1 NO.1 STYLE专属，本篇作品全部由S1发行；2021年11月起另发行单体精选集（OFJE 系）。
- 以105cm、J罩杯的爆乳为核心卖点，作品标题多含「Jカップ」「パイズリ」，涵盖痴女、上司/人妻、风俗、主観ASMR 等题材。
- 除本篇外还发行大量VR作品，以及写真集《Big Baby》（2020）、《愛の炎》（2022）、《凪》（2023）与「8woman」企划系列数字写真。
