# 児童買春・児童ポルノ禁止法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 児童買春・児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律 |
| 通称 | 児童買春・児童ポルノ禁止法 |
| 法令番号 | 平成11年法律第82号 |
| 施行 | 1999年5月1日 |
| 所管 | 厚生労働省、警察庁 |

## 概要

该法是保护儿童免受性剥削的法律，禁止儿童卖淫和儿童色情制品的制作、持有、传播等行为。

## 主要内容

### 禁止行为

- 儿童卖春（与儿童进行有偿性行为）
- 儿童ポルノ的制作、持有、传播、展示
- 儿童卖春的媒介、斡旋
- 以儿童卖春为目的的引诱

### 处罚

- 制造儿童ポルノ：3年以上有期徒刑
- 持有儿童ポル诺：1年以上有期徒刑
- 传播儿童ポルノ：3年以上有期徒刑
- 儿童卖春：5年以上有期徒刑或罚金

## 与AV行业的关联

该法对AV行业的影响在于确保出演者年龄的真实性。AV制作方必须严格核实出演者年龄，避免触犯该法。未成年人出演AV可能构成儿童ポルノ相关犯罪。
