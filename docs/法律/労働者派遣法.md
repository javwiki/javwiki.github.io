# 労働者派遣法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 労働者派遣法 |
| 法令番号 | 昭和60年法律第88号 |
| 施行 | 1986年7月1日 |
| 所管 | 厚生労働省 |

## 概要

労働者派遣法规范劳务派遣行为，保护派遣劳动者的合法权益，规定派遣单位和用人单位的义务。

## 主要内容

### 派遣许可

- 从事劳务派遣需获得厚生劳动大臣的许可
- 需满足一定的资质要求

### 劳动者保护

- 禁止不当派遣
- 保护派遣劳动者的工资、福利
- 禁止差别对待

### 用人单位义务

- 对派遣劳动者负有安全卫生义务
- 禁止强迫劳动
- 保障劳动者的合法权益

## 与AV行业的关联

AV出演者常以"模特"、"演员"等身份参与制作，与制作单位的关系可能涉及劳务派遣。该法为AV出演者作为劳动者提供保护，禁止不当派遣和强迫劳动。
