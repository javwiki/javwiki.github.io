## 简介

跨越两家厂商的超长寿命系列，2011年5月由 **SOD Create（SODクリエイト）**以 SACE-006 启动。2020年转移至 **PRESTIGE（プレステージ）** 继续发行，以 ABW/ABF 番号出品。

核心概念是女优扮演「全裸家政婦（全裸家务工）」，在完全不穿衣服的状态下进行打扫、洗衣等家务，并在过程中被男主人侵犯或主动勾引。系列强调「全裸围裙」或「一丝不挂做家务」的视觉反差感。

## 系列特征

- 核心玩法：全裸状态下进行家政服务并发生性行为
- 前期由 SOD Create 制作（2011-2017，SACE 番号）
- 后期由 PRESTIGE 制作（2020-2023，ABW/ABF 番号）
- 全系列为单体作品
- 部分作品有无码破解流出
