# SO MODEL AGENT (formerly 8MAN)

So Model Agency refers to this entry on this site. The official website uses **SO MODEL AGENT**, also styled SO MODELAGENT on its homepage.

## Basic information

- **Current name**: SO MODEL AGENT (ソウ モデルエージェント)
- **Former name**: 8MAN (エイトマン)
- **Founded**: In Osaka in 2006, according to the official website
- **Location**: Osaka headquarters in Minamisenba, Chuo Ward; Tokyo branch in Kanda-Jimbocho, Chiyoda Ward
- **Services**: Management of AV actresses, models, entertainers and gravure idols, with support for television, film and magazine work
- **Association**: Member of the Japan Production Association (JPG)
- **Website**: <https://so-agent.jp/>
- **Former website**: <https://www.8man.jp/> now redirects to the website above
