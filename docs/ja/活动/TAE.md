# TAE 台灣成人博覽會

TAE（Taiwan Adult Expo、台灣成人博覽會）は台湾・台北市で開催される成人博覧会で、長らく台北世貿一館C区で毎年1回開催されてきた。撮影会、ツーショット撮影会、ステージゲームを主な形式とし、台湾・日本・韓国などのグラビアアイドルやAV女優が参加するほか、メーカーのブースも設けられる。

2026年の第12回は初めて高雄（左営国際活動展演中心）へ会場を移し、「アジア潮流カーニバル」を掲げた。主催者はイベントの系列を2011年まで遡るとしている（自称 since 2011）が、回数から逆算すると2025年が第11回にあたる。

## 基本情報

- **正式名称**: TAE 台灣成人博覽會（台湾成人博覧会）
- **英語名**: Taiwan Adult Expo（主催者側では Taiwan Angel Expo と表記する場合もある）
- **開催地**: 台北世貿一館C区（例年）→ 高雄・左営（2026年以降）
- **主催**: 博展国际有限公司
- **初開催**: 2010年代（公式は since 2011 と自称）

## 主な特徴

- **撮影会とツーショット撮影会**: 専用スタジオが設けられ、来場者はチケットを購入して女優の撮影やツーショット撮影ができる
- **ステージゲーム**: 大ステージで参加型のゲームコーナーが行われる
- **多彩な出演者**: 日本・韓国のグラビアアイドルやAV女優に加え、女性向けAV男優、ゲイ向け作品の男優、台湾地元のアダルト映像制作会社も出展する
