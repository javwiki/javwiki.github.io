# イベント

JAV関連のリアル展示会・イベントを扱い、主に中国大陸、台湾、日本などで開催される成人向け展示会やグラビア博覧会といった現場のイベントを収録している。こうしたイベントでは、日本のAV女優やグラビアアイドル、各地のコスプレイヤーが招かれ、ステージ公演、サイン会・ツーショット撮影、撮影交流が行われる。成人向け健康用品の商談を主とする業界見本市も含む。

## 記事一覧

| イベント | 地域 | 開催頻度 | 説明 |
| --- | --- | --- | --- |
| [TRE 台北國際成人展](TRE.md) | 台湾・台北 | 毎年 | アジア有数の大型成人博覧会。2019年に初開催され、2026年から「台北國際紅人展」に改称 |
| [TSE 台灣寫真博覽會](TSE.md) | 台湾・台北 | 不定期 | グラビアアイドルとAV女優を中心とするグラビア博覧会。2017年に初開催 |
| [TAE 台灣成人博覽會](TAE.md) | 台湾・台北/高雄 | 毎年 | 台北世貿一館で長く開催されてきた成人博覧会。2026年から高雄へ会場を移す |
| [JAE Japan Adult Expo](JAE.md) | 日本・東京 | 開催終了 | AVファン感謝祭。IPPA主催で、2014–2017年に有明のDiffer Ariakeで開催 |
| [AVN Adult Entertainment Expo](AEE.md) | アメリカ・ラスベガス | 毎年 | アメリカ最大の成人業界見本市。AVN誌が主催し、AVN成人賞と同時期に開催 |
| [上海国際成人用品展](上海国际成人用品展.md) | 中国・上海 | 毎年 | 成人向け性生活用品と生殖健康用品の展示会。2004年に初開催 |
