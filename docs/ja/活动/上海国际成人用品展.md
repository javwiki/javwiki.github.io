# 上海国際成人用品展

上海国際成人用品展（正式名称：中国国际成人保健及生殖健康展览会）は、中国・上海で開催される成人向け性用品と生殖健康用品の展示会で、2004年に始まった。主催は中展集团公司で、開催理念は「以贸易为导向、以需求为宗旨、以发展为目标」。「上海国際成人展」とも呼ばれる。
