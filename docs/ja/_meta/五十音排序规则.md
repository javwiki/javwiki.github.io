# 五十音順のルール

本ドキュメントは、本百科の女優ディレクトリ構成と `list.yaml` の並び順ルールを定義し、記事インデックス、ファイルシステム、リストファイルの三者の一致を確保する。

## 五十音の行と段

ディレクトリ構成には**五十音図の二層インデックス**を使用する：

| 行 (row) | 段 (col) |
|----------|----------|
| あ行 | あ・い・う・え・お |
| か行 | か・き・く・け・こ |
| さ行 | さ・し・す・せ・そ |
| た行 | た・ち・つ・て・と |
| な行 | な・に・ぬ・ね・の |
| は行 | は・ひ・ふ・へ・ほ（濁音 ば・び・ぶ・べ・ぼ、半濁音 ぱ・ぴ・ぷ・ぺ・ぽ を含む） |
| ま行 | ま・み・む・め・も |
| や行 | や・ゆ・よ |
| ら行 | ら・り・る・れ・ろ |
| わ行 | わ・を・ん |

濁音・半濁音はそれぞれ所属する行に分類する：
- **ば行** は **は行** に属する（べ → は行・べ段）
- **ぱ行** は **は行** に属する

## 女優の配置ルール

各女優は、その**芸名の読み**によって所属する行と段が決まる：

### 漢字名
漢字の音読みから仮名を判断し、その**先頭の仮名**で位置を決める。

例：
- 河北彩花（かわきた さいか） → 先頭の「か」→ か行・か段
- 相沢みなみ（あいざわ みなみ） → 先頭の「あ」→ あ行・あ段
- 深田えいみ（ふかだ えみ） → 先頭の「ふ」→ は行・ふ段

### カタカナ・外来語名
カタカナの実際の発音どおりに読み、**先頭の仮名**で判断する。

例：
- ベアトリクス（べあとりくす） → 先頭の「べ」→ は行・べ段
- アイカ（あいか） → 先頭の「あ」→ あ行・あ段
- ミル（みる） → 先頭の「み」→ ま行・み段

### 漢字と仮名の混合名
漢字と仮名が混在する場合も、全体の読みの先頭の仮名で判断する。

例：
- あずみ恋（あずみ れん） → 先頭の「あ」→ あ行・あ段

### 濁音・半濁音
濁音・半濁音はそれぞれの仮名ごとの行に分類する（ば・ぱ は は行）。

- 読みが「ば・び・ぶ・べ・ぼ」で始まる → は行 + 対応する段
- 読みが「ぱ・ぴ・ぷ・ぺ・ぽ」で始まる → は行 + 対応する段

## list.yaml の構造

```yaml
title: 女優一覧
items:
  - name: 女優名      # 芸名（漢字・カタカナ・英字）
    row: 行           # 五十音の行名（あ/か/さ/...）
    col: 段           # 五十音の段名（あ/い/う/...）
    completeness: N%  # 記事の完成度（0-100）
```

### 並び順のルール

items は次の順に並べる：
1. **行の順序**：あ → か → さ → た → な → は → ま → や → ら → わ
2. **段の順序**：あ → い → う → え → お

女優は読みに従い、上記のグリッド内に順番に配置する。

## ファイルシステムとの対応

ディレクトリパス：`docs/{row}/{col}/{女优名}.md`

例：
- `docs/か/か/河北彩花.md`
- `docs/は/べ/ベアトリクス.md`
- `docs/ま/み/Miru.md`

各 `{row}/` ディレクトリの下には `index.md`（行インデックス）、各 `{row}/{col}/` ディレクトリの下にも `index.md`（段インデックス）が必要である。

## 一貫性の制約

次の三者は完全に対応していなければならない：
1. **list.yaml** の `row` / `col`
2. **ファイルシステム**のディレクトリパス `docs/{row}/{col}/`
3. **ディレクトリ索引** `docs/{row}/index.md` と `docs/{row}/{col}/index.md` の記事リンク

追加・変更・削除を行う場合は、必ず上記の三か所を同期して更新する。

## 完成度 (completeness)

| 等級 | 意味 |
|------|------|
| 100% | 記事の内容が完全（基本情報、プロフィール、作品の特徴、年表、参考資料が揃っている） |
| 65%  | 基本的な構造はあるが、一部の章が欠けている |
| 10%  | 骨組みのみで、内容は未充填 |
| 0%   | 未作成 |
