# 8MAN / SO MODEL AGENT

## 基本情報

- **正式名称**: 8MAN（エイトマン）
- **現称**: SO MODEL AGENT（ソウ モデルエージェント）
- **沿革**: 旧公式サイト <https://www.8man.jp/> は現在 <https://so-agent.jp/> へ301リダイレクトされる。8MAN は SO MODEL AGENT へ改称されており、同一のプロダクションである
