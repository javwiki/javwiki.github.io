# プロダクション

プロダクション（事務所）はAV女優の仲介機関であり、女優の芸能活動の管理、契約交渉、仕事の調整などを担う。主要なプロダクションを知ることは、女優の職業上の背景や活動の軌跡を理解する助けとなる。

## 事務所の役割

### 主な業務

| 職能 | 説明 |
| --- | --- |
| 女優のマネジメント | 女優の芸能活動の管理、契約交渉 |
| 仕事の調整 | 撮影、イベント、宣伝などの仕事の手配 |
| イメージ管理 | 女優の公的イメージ、SNSの管理 |
| 法務 | 契約、著作権などの法務処理 |
| 財務管理 | 女優の収入、税務などの管理 |

### メーカーとの関係

プロダクションとメーカーは協力関係にあり、プロダクションは女優のリソースを提供し、メーカーは作品の製作と発売を担う。両者は契約によって報酬の配分比率や労働条件を定める。

## プロダクションと女優の関係

### 契約の種類

| 種類 | 説明 |
| --- | --- |
| 専属契約 | 女優は特定のメーカーのみで作品を発売する |
| 非専属契約 | 女優は複数のメーカーで作品を発売できる |
| 独立契約 | 女優が自身の活動を独立して管理する |

### 契約期間

契約期間は通常1-3年で、満了後は更新または解除ができる。一部の女優は独立して活動する道を選び、プロダクションに依存しなくなる。

## 事務所の選び方

### 選定基準

| 基準 | 説明 |
| --- | --- |
| 会社の規模 | 大手はリソースが豊富で、小規模な会社は柔軟性が高い |
| 業務範囲 | 女優が必要とする業務を網羅しているか |
| 評判 | 業界での評判と女優からの評価 |
| 報酬の配分比率 | 収入の配分が妥当か |
| 成長の機会 | より多くの活躍の機会を提供できるか |

### 注意事項

- 正規のプロダクションを選び、悪質な仲介業者を避ける
- 契約条項をよく読み、権利と義務を理解する
- 関連する証拠を保管し、自身の権利を守る
