# 溜池ゴロー

## 経歴とインタビュー

2016-12-28掲載の STAND インタビューは、1964年生まれ、大学卒業後に助監督となり、30歳で成人映像監督としてデビューしたと記載する。本人は1999年の制作経験やパッケージ映像からネット配信への変化を振り返っている。当時の役職を現在の職務として扱わない。

人物と同名ブランドを区別する。旧稿の「2005年から活動」と「NINE・COOLシリーズ」は作品資料がなく撤去した。全作品年表と受賞歴は未確認。
