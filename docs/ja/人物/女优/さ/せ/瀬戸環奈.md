# 瀬戸環奈

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 瀬戸環奈
- **英語名**: Kanna Seto

## プロフィール

瀬戸環奈は2004年5月10日生まれ、神奈川県相模原市出身。Bstar所属。AVデビュー前はグラビアアイドルで、2024年10月7日発売の『週刊ポスト』10月18・25日号で水着グラビアを披露した。同月9日にはデジタル写真集『瀬戸環奈 てぇてぇJカップ。』が配信開始。2024年12月24日、2025年1月28日にS1 NO.1 STYLEからAVデビューすると発表した。身長170センチ、Jカップ。

## 作品の特徴

- デビュー前から小学館の写真集『emerald』（2025年1月28日）と複数のデジタル写真集を出しており、AVデビュー後はS1専属を続けている。
- 作品名は「最強ヒロイン」シリーズを軸に、恋人、風俗、教師と生徒、NTR、痴女、VRまで題材が広がる。宣伝ではJカップと170センチの体型が前面に出される。
- 『月刊FANZA』2025年上半期女優ランキングで1位。集計期間中の5作品すべてが上半期作品ランキングのベスト10に入った。『アサヒ芸能』の集計では2025年の年間販売ランキング1位から9位までを瀬戸の作品が占めた。
- AV男優の鮫島健介はキスを「攻撃的といっていいほどグイグイと舌を入れてきたり、舌を吸ってきたり」と評し、積極性を特筆している。本人はデビュー前に私生活でのパイズリ経験がほとんどなく、デビュー作で初披露したと語る。
- 2025年5月にはゲーム『ハーレムオブトーキョー』で初めて声の仕事を務めた。
