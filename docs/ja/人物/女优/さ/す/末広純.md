# 末広純

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

末広純は2000年1月10日生まれ、山梨県出身の日本のAV女優。LIGHT所属で、六本木のレッドドラゴンにも在籍している。2022年4月12日にマドンナ専属女優としてAVデビューし、同年8月9日にマドンナを離れて企画単体女優となった。

2023年は露出が増えた年で、4月3日には『人妻自宅サロン 底辺クズ隣人の汚らわしいデカマラに堕ちた若妻エステティシャン』が週FANZAレンタルフロアランキングで1位。同月のレンタルフロア月間AV女優ランキング1位、上半期AV女優ランキング19位、11月の月間ランキング5位、年間女優ランキング11位に入った。同年、MOODYZの忘年会では最優秀エムズビデオグループ賞を受賞している。

2024年もFANZA各フロアの週間・月間ランキングに登場し、12月には光文社『FLASH』の独自集計「FLASHセクシー女優ランキング2024」で25位となった。2025年1月からSNSの更新を止め、5月5日に台湾の中時新聞網が再開を報じた。11月3日には2025年4月発売の出演作が週FANZA動画フロアランキングで再注目され9位に入り、2026年3月16日週には出演したKMPVR10周年特別作品が初登場10位となった。

## 人物

- 山梨県出身。デビュー前は調理師として就職したが、一人暮らしができないほど給料が安く、貯金もしたかったため「1本だけやってみるか」と軽い気持ちで事務所の門を叩いた。
- 芸名は「広末涼子に似ている」と言われたことから。バラエティ番組出演時にも「広末涼子似」と紹介された。
- デビューして5本目までほとんどが人妻を演じるドラマ作品で、「AVって演技力がいるんだ」と驚いたという。スタート時期に身につけた演技の下地はキカタン転身後も役立っている。
- ファンにはおしりを評価されることが多く、中高とバスケットボールに明け暮れたおかげで下半身がしっかりしているのではと自己考察している。尻特化作品への出演も多いため、垂れないように日常的に鍛えている。
- 下着についてはフルバック10％、Tバック30％、残りがノーパンと述べ、通気性と食い込みに気を付け、なるべく穿かない生活を心がけている。
- 『アサヒ芸能』の担当者は素の末広について「語尾の全部に音符やハートがつきそうなくらいキュートで陽キャな雰囲気」と記している。
- 2025年1月22日、週刊文春によりDeNAベイスターズの東克樹投手との不倫関係にあることが報じられた。末広はベイスターズ女子としても知られ、シーズン中は頻繁に横浜スタジアムに通い、ユニフォーム姿をSNSに上げていた。

## 作品の特徴

- 2022年4月にマドンナ専属でデビューし、同年8月に企画単体へ転身。以後は複数メーカーの作品に出演している。
- デビュー初期は人妻役のドラマ作品が中心で、5本目までほとんどが人妻役だった。初期の演技経験がその後の企画単体の仕事を支えている。
- 尻を売りにした作品が多く、本人も身体の特徴として臀部を挙げている。
- 2023年は『人妻自宅サロン 底辺クズ隣人の汚らわしいデカマラに堕ちた若妻エステティシャン』などでFANZAレンタルフロアの週間・月間1位を獲得した。
- AVのほかYouTubeチャンネルやABEMAの配信番組に出演し、デジタル写真集『はだかの家政婦』を発表、『月刊FANZA』のインタビューも受けている。
