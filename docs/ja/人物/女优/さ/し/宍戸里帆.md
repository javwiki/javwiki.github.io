# 宍戸里帆

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

- **生年月日（公式資料）**: 2001-10-14
- **身長（公式資料）**: 153 cm

## プロフィール

宍戸里帆は2001年10月14日生まれ、東京都出身。マインズ所属。2022年3月、MOODYZ専属女優としてAVデビューし、同月発売の『週刊ポスト』2022年4月1日号で初グラビアが掲載された。2023年11月29日には初主演映画『モーテル303』が公開。2024年3月30日に大学卒業を報告し、同年12月17日にMOODYZ専属を離れて企画単体へ転じることを発表した。

## 作品の特徴

- MOODYZ専属時代は恋人、人妻、愛人、NTRといった関係性を軸にした作品が中心で、「ドリームウーマン」シリーズのようなハードな企画にも出演した。
- 2024年末に企画単体へ転じてからはメーカーと題材が広がり、人妻の不倫、看護師、痴漢、NTRなどを扱う作品が増えた。
- バスト86センチの柔らかな胸が身体的な特徴。本人はかつてコンプレックスだったが、デビュー後は自分らしさとして捉えるようになったという。事務所プロフィールの身長は153センチ。
- AVのほか、FANZAニュース、デラべっぴんR、Bezzyでのコラム連載や、映画、舞台、ゲームにも出演している。AVライターの芝田カズはこの時期の企画単体転向を驚きと記し、くろがね阿礼は専属を離れて「新しい引き出しが発見され、プレイの幅も拡大」したと述べた。
- 2022年5月、『アサヒ芸能』「2022現役AV女優SEXY総選挙」41位、『月刊FANZA』「2022夏 新人編」1位。
