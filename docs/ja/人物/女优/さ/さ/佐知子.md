# 佐知子

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

佐知子は1999年8月8日生まれ、宮崎県出身の日本のAV女優。2019年5月、SODクリエイトの「キミホレ」レーベル専属女優としてAVデビューした。同年8月に専属を離れて企画単体女優となり、以後は複数のメーカーの作品に出演している。デビュー作が眼鏡キャラだったこともあり、当初は作品の9割が眼鏡姿だった。2021年時点でも「それでも6割くらい眼鏡をかけています」と答えている。

Jカップ、バスト105cmの体型を武器に活動しているが、本人は元々コンプレックスもあったと語っている。2020年8月、月刊FANZA発表の2020年上半期AV女優ランキングで10位。2021年2月、ゲオTVの「バレンタインチョコを貰いたいAV女優！アンケート」で2位となった。『週刊プレイボーイ』のインタビューでは「地味で（アダルト通販サイトを）検索するとダントツ1位」と紹介された。

2023年5月22日週、出演した『BAZOOKA 冬の大感謝セール コスパ最強ノーカットベスト爆乳限定2749分』がFANZA動画フロアランキングで1位を記録した。記事に記載された出演期間は2019年から2022年までである。

## 人物

- 宮崎県出身。趣味は漫画喫茶。
- 元々は胸にコンプレックスがあった。胸が大きくなり始めたのは中学2年生の頃で、初めてスポーツブラを母親と買いに行った際にFカップだったと判明し、胸の大きさに気づいた。当時は恥ずかしさから小さく見せる努力をしていたが、現在はJカップを武器に活動している。
- 2020年上半期のAV売り上げで10位。『週刊プレイボーイ』のインタビューでは「地味」と紹介されつつ、アダルト通販サイトで検索すると「ダントツ1位」とも書かれた。
- デビュー作が眼鏡キャラだったため、当初は作品の9割が眼鏡姿だった。2021年時点でも6割くらいは眼鏡をかけていると答えている。

## 作品の特徴

- 2019年5月にSODクリエイトの「キミホレ」専属としてデビューし、同年8月に企画単体へ転向。以後は複数メーカーの作品に出演している。
- Jカップ（105cm）の体型と、眼鏡、地味系のキャラクターが特徴。
- 単体作、共演作、VR、配信と幅広く出演。2023年5月のBAZOOKAベスト作はFANZA動画フロアランキングで1位。
- 2019年8月にイメージDVD『Sachiko 揺れる… 想い…』（REbecca）、2020年9月に『MY DEAR』（ファインピクチャーズ）を発売した。
- 2021年11月にはデジタル写真集『DOUBLE 佐知子×辻井ほのか』（プレステージ出版）を発売した。
