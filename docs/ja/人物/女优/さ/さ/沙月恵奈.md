# 沙月恵奈

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 沙月恵奈
- **英語名**: Ena Satsuki

## プロフィール

沙月恵奈は1999年6月11日生まれ、千葉県出身。LINX所属。2020年9月、配信特化型メーカーFALENOの「FALENOstar」専属としてAVデビューした。2021年10月に専属を離れて企画単体に転じ、月に20本から25本ほどの作品を撮影した時期もあった。2026年1月にはKMPのMillion内に新設された「sugar」の専属となり、約4年2か月ぶりの専属復帰となった。

## 作品の特徴

- FALENOstar時代は配信特化型メーカーの専属だった。企画単体に転じてからは各メーカーをまたぎ、人妻、NTR、痴女、レズ、アナル、緊縛、SMまで題材が広がった。
- 2022年1月にレズを解禁し、以後は相手役としての出演も多い。2023年からアナル、2025年には緊縛とSMにも挑み、「できそうだから断らなかった感じ」と語っている。
- アへ顔と淫語が特徴で、アへ顔を主題にした企画もある。アへ顔には当初から抵抗がなかったという。
- 監督の矢澤レシーブは「戦闘員のような（自分でグイグイ行く）女優」と評し、『夕刊フジ』のコラムは「万人受けするタイプで、オヤジキラー資質アリ」としつつ「キカタンの女王」と呼んだ。
