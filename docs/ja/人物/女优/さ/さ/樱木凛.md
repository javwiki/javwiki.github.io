# 桜木凛

## プロフィール

桜木凛は日本AV業界を代表する女優の一人で、俳優や歌手としても活動している。2007年10月に KUKI 専属女優としてデビューし、清楚な外見と優れた演技力で注目を集めた。

桜木凛は恵比寿マスカッツの2期生で、バラエティ番組でも活躍した。歌手ユニット P＊cherry のメンバーでもある。2017年4月の引退後、2019年7月に希崎ジェシカの引退に伴い期間限定で復帰した。

## 人物

- 桜木凛は兵庫県出身、血液型はB型。
- 趣味は買い物とデジタルカメラ。
- 芸名は3月生まれであることから、春にちなんだ「花」の字を取った。
- 恵比寿マスカッツの2期生で、希崎ジェシカ、かすみ果穂、初音みのり、希志あいのらと仲が良かった。
- 2014年にさくらゆらとユニット P＊cherry を結成。
- 2015年に一度「沼田早苗」へ改名したが、その後は「桜木凛」を使い続けた。
- 2017年4月22日に引退。
- 2019年7月に希崎ジェシカの引退に伴い期間限定で復帰し、結婚して子どもが一人いることを報告した。

## 作品の特徴

- 初期は清純派のイメージが中心で、後期はより多様な役柄に挑戦した。
- 痴女系、ドラマ系などの役柄を得意とする。
- 作品は高品質と評されている。
