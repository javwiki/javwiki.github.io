# 架乃ゆら

日本のタレント、女優、YouTuber、元AV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

架乃ゆらは1998年12月28日生まれ、岡山県出身の日本のタレント、女優、YouTuber、元AV女優。高校時代からモデルとして活動し、18歳からヌードモデルを始めた。2017年11月19日、「無限の透明感」のキャッチコピーでS1 NO.1 STYLE専属としてAVデビューした。デビュー前には『週刊大衆ヴィーナス』でヌードグラビアが掲載されている。

2018年6月29日、恵比寿マスカッツ1.5に研修生として加入し、同年8月24日に正式メンバーへ昇格した。2020年3月10日には、まいてぃ、三上悠亜、吉澤友貴とともにユニット「SCANTY4」を結成し、楽曲「パンチラリズム」を公開。2021年2月3日に市川まさみ、山岸逢花が加わり「SCANTY6」となった。2021年12月6日、恵比寿マスカッツのオンラインライブでグループ卒業を発表した。

2021年8月、「読者300人が選んだFLASH 2021セクシー女優ランキング」読者投票で31位、同月の『月刊FANZA』「このAV女優がすごい!2021年夏」で5位。2023年5月には『アサヒ芸能』「2023現役AV女優SEXY総選挙」で25位、2024年4月の同総選挙では総合36位となった。

2024年5月7日、7月いっぱいでAV女優を引退すると発表し、AV以外の活動は継続するとした。同月16日にはYouTubeで、引退は一般女優を目指してのものであり、病気や結婚が理由ではないこと、AV復帰は考えていないことを明かした。引退作は同年2月に撮影を終えている。10月には舞台『バック・トゥ・ザ・うんちゃん〜ドライバーの消える日〜』に出演し、AV引退後初の舞台となった。

2025年5月1日、それまで所属したLINXを退所し、業務提携として関係を続ける。同年9月25日には体調不良のため活動を休止し、11月から再開した。以後は女優・タレントとして舞台、ウェブドラマ、テレビ番組に出演している。

## 人物

- 岡山県出身で、2017年時点では岡山県に在住していた。兄が1人おり、幼い頃は兄の成人向け漫画をこっそり読んでいたという。
- 趣味・特技はサイクリング。中学では演劇部、高校では美術部に所属し、そのためドラマ仕立ての作品を好む。
- 昭和歌謡と特撮のファンで、平成仮面ライダーシリーズはすべて視聴。一番好きな作品は『仮面ライダーオーズ/OOO』で、成人用変身ベルトも所持している。
- 好きなタイプは年上で優しく、小太りな人。SかMかの問いには「変態」と答え、後には「ややM寄り」と答えることが多い。
- 初体験は高校生の時で、相手は部活の先輩。デビューまでの経験人数はこの1人だけである。
- 芸名は「どこにもない名前」として事務所が命名し、苗字の漢字一字一字に意味があるという。ニックネームはファンから募集し、「ゆららん」に決まった。
- 尊敬するAV女優はつぼみ、麻美ゆま、友田彩也香。七海ティナとは親友で、引退についても最初に相談した。
- オスのマンチカン「シンバ」を飼い、ハムスターを飼った経験もある。二葉エマとは互いに「双子の姉妹」と称し、顔や声が似ていると言われている。

## 作品の特徴

- 2017年11月からS1 NO.1 STYLE専属で、デビュー時のキャッチコピーは「無限の透明感」。
- 2023年6月、出演作『エスワンファン感謝祭』のBlu-ray版がFANZA通販フロア週間ランキングで初登場1位、DVD版は4位。翌週も1位を維持し、同作は7月17日週のFANZA動画フロアランキングでも1位となった。
- 2021年発売の『童貞君の成績と射精を徹底管理してくれる世話焼き家庭教師の献身的筆おろし講習 架乃ゆら』が2023年12月11日週のFANZA動画フロアランキングで8位に再浮上。同月25日週にはVR作品『彼女に振られ引きこもっていたら… 僕のことが心配すぎておせっかいでセックス練習させてくれた筆おろしブラコンお姉ちゃん 架乃ゆら』が初登場10位に入った。
- 引退作『かのゆらすと 架乃ゆら』は2024年7月15日週のFANZA通販フロアランキングで初登場6位、翌週には5位へ浮上した。
- 演技力の評価が高く、ライターの鷲谷憲樹は彼女のアドリブ台詞と表情を「史上最高」と評し、特にNTR作品で強く現れていると論じている。
- AVのほかオリジナルビデオ、映画、舞台、ウェブドラマに出演し、写真集とデジタル写真集も多数発表している。
