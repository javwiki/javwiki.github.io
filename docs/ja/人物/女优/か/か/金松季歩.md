# 金松季歩

日本のAV女優、元グラビアアイドル、AKB48元研究生。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 金松季歩
- **読み**: かねまつ きほ
- **英語名**: Kiho Kanematsu
- **別名**: 金子さとみ、金子智美（旧芸名、読みはいずれも「かねこ さとみ」）
- **生年月日**: 1989年12月22日
- **出身地**: 日本 愛知県豊橋市
- **所属事務所**: Bstar（ビースター。以前はPIGROOM、リップ）
- **主要メーカー**: S1 NO.1 STYLE（AVデビュー作はMUTEKI）
- **活動期間**: 2024年〜（AV女優）。2014年からグラビア活動

## プロフィール

金松季歩は1989年12月22日生まれ、愛知県豊橋市出身の日本のAV女優、元グラビアアイドル。AKB48の元研究生（4期生）。旧芸名は金子さとみ、金子智美で、読みはいずれも「かねこ さとみ」。2007年にAKB48第1期研究生（4期生）オーディションに合格したが、同年11月15日より前に辞退し、研究生時代に舞台へ立つことはなかった。その後は金子さとみ名義で2010年にVシネマ『マン・ハンティング』に主演し初ヌードを披露、2014年にグラビアアイドルへ転向した。

グラビア時代は2017年7月18日に「ミスアクショングランプリ2017」を獲得し、2018年2月24日にはテレビ東京『ゴッドタン』の第1回「腐りグラドルグランプリ」でグランプリとなった。所属はPIGROOM（2020年7月31日まで）、リップ（2020年9月1日から2023年6月24日まで）を経ている。2021年10月発売の写真集『美しい人』は1週間で重版した。2023年6月24日、同月末でリップを退所し芸能界を引退すると報告し、25日に引退式を行った。

2024年2月27日、金松季歩へ改名し、光文社『FLASH』のグラビアとインタビューで復帰。3月5日、4月2日にMUTEKIからAVデビュー作『18Gold』を発売すると発表した。同年6月11日にはS1専属女優となり7月9日にエスワンデビュー作が発売されること、YouTubeチャンネル「KIHO Channel」の開設、Bstar所属、7月18日の初ヌード写真集発売を報告した。2024年12月24日、光文社『FLASH』独自集計の「FLASHセクシー女優ランキング2024」で4位。『月刊FANZA』2025年10月号の「FANZA2025年上半期女優ランキング」では5位を記録した。

## 人物

- アドリブは苦手だと述べている。
- 初体験は19歳の時で、相手はバイト先で出会った人である。
- マスコミでは「元AKB」と呼称されることも多いが、本人は「その肩書を使うにふさわしい人間ではない」として早々に使うのをやめている。
- 研修生時代は一度も舞台に立っておらず、歌手としての初ステージは金松名義になった後の2025年5月26日。2026年4月8日のソロライブで初めてAKB48の『夕陽を見ているか?』を歌唱した。
- グラビア時代、イメージビデオの露出面に限界を感じ、どんなシチュエーションや設定が人気なのかを確かめるためアダルトビデオを教材として観ていた。
- 21歳の時、AKB以前から世話になった人物にAV事務所へ連れて行かれ、寸前で留まった。後年、騙されていた、ちょっと洗脳されていたと振り返っている。
- 引退に際しては「『リタイア』この言葉がしっくりきます」と答え、別のインタビューでは「18禁グラドル」のイメージが浸透しすぎて一般のグラビア仕事が激減したことを引退理由に挙げた。
- 2024年の復帰時は「34歳という年齢もあり出演前は悩んだ」が、「グラビアで8年間頑張ってきた自分を信じて臨みました」と述べ、「自分の天職を見つけてしまった」と語った。
- 芸名は本人が決めた。前名を残すため「金」の字を姓に残し、金銀銅と松竹梅のどちらも1番にくる漢字をつなげて「金松」とした。「季歩」は2文字の名前に憧れがあったことと姓名判断による。
- 父親は鉄工所勤務、母親は専業主婦。姉と兄がおり、兄はダンサーである。
- AVライター兼プロデューサーのいんごまは、彼女の魅力を「美人、スマイル、プロポーション」に加え、無理難題にも体当たりでぶつかる「豪胆さ」にあると分析している。

## 作品の特徴

- AVデビュー作『18Gold』（2024年4月2日、MUTEKI）はイメージビデオの延長戦という演出で、あえてインタビューを入れていない。
- 2024年7月からS1 NO.1 STYLE専属で、作品は「グラビア芸能人」シリーズを軸に、上司、不倫、教師、痴漢などの大人向け設定を扱う。
- 2024年から2025年にかけてS1 20周年記念の大型共演作に参加し、河北彩伽、本郷愛、七ツ森りりらと共演した。
- 2026年にはメーカーを超えた共演作があり、長浜みつりとのアイデアポケット作品、MOODYZ創立25周年記念作（九野ひなの、桜空もも、伊藤舞雪）がある。
- AVのほか写真集とデジタル写真集を継続して発表し、テレビドラマ、バラエティ、ラジオ、Netflix『デスキスゲーム』にも出演している。
- VR作品は2024年から順次発表され、「VR NO.1 STYLE」シリーズを含む。
