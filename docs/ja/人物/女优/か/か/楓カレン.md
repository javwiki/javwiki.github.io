# 楓カレン

日本のAV女優、元グラビアアイドル。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 楓カレン
- **読み**: かえで かれん
- **英語名**: Karen Kaede
- **生年月日**: 1999年8月25日
- **出身地**: 日本 東京都
- **所属事務所**: ライフプロモーション
- **活動期間**: 2018年〜（2022年3月引退、2023年6月復帰）

## プロフィール

楓カレンは1999年8月25日生まれ、東京都出身の日本のAV女優、元グラビアアイドル。ライフプロモーション所属。2018年9月にグラビアアイドルとしてデビューし、同年12月、アイデアポケット設立20周年記念女優として同メーカー専属でAVデビューした。

2021年4月、『週刊アサヒ芸能』「2021現役AV女優SEXY総選挙」で9位。8月の「FLASH 2021セクシー女優ランキング」読者投票では23位に入り、同月と9月にはFANZAレンタルフロア月間AV女優ランキングで1位を記録した。業界の賞レースにはほとんど関与しなかったが、アイデアポケットの柱と目される存在になった。

2022年3月28日、Twitterで引退を表明。2023年4月20日には「田中レモン」名義でFALENO専属として再デビューし、所属はエイトマンで5作品をリリース、台湾などでは楓カレンと同一人物と報じられた。同年6月27日、楓カレンとして完全復活を宣言してライフプロモーションに再所属。11月14日に復帰作を発売してアイデアポケット専属に戻り、12月には「アサ芸AV大賞2023」でカムバック大賞を受賞した。2024年4月、『週刊アサヒ芸能』「2024現役AV女優セクシー総選挙」で総合3位。

## 人物

- 東京都出身。特技は料理で、とくに肉じゃがを得意とする。主食は駄菓子。
- 憧れのAV女優に橋本ありなを挙げ、女優の川口春奈に似ていると評される。グラビアアイドル時代に憧れていたのは中村静香。
- 狆の「うし」とエキゾチックショートヘアの「かに」を飼っている。
- 見た目に反してアニメファンで、かつてはアニメイトに通った。店内でBL作品に出会い、以後はBL漫画の読書を趣味としている。
- 長らくロングヘアだったが、2023年の再デビュー時にショートヘアにした。
- 日本では「女版・吉村卓」の異名を持ち、中華圏では「楓花戀」と表記される。台湾では川口春奈に似ていることから「暗黑版川口春奈」とも報じられた。
- 芸人の青柳貴哉は「ルックスが清楚なのに、小ボケを計算してちょこちょこ言うタイプ」と評した。
- ゴールデンボンバーの鬼龍院翔がファンを公言しており、復活を「解散したバンドが突如、再結成したようなもの。日本は夢ある」と述べた。

## 作品の特徴

- デビュー時からアイデアポケット専属で、その契機は同メーカー設立20周年記念女優。2023年の復帰後も同メーカー専属を続ける。
- 単体作と共演作のほか、WikipediaにはVR作品が複数挙がっており、2024年には8K VRの長編を発表した。
- 2023年2月13日週、『楓カレン-純美の終焉- COMPLETE BEST 48時間BOX 豪華37作品12枚組』がFANZA通販フロア週間ランキング1位。
- 2025年1月13日週、新ありなとの共演作『楓カレンと新ありな。最強のふたり。女神ハーレム 今世紀最も美しいお姉さんに挟まれ痴女られSpecial』がFANZA通販フロア週間ランキング初登場3位、アサヒ芸能「2025年最も売れたAVはコレだ!!」年間18位に入った。
- AVのほかイメージビデオと写真集（2019年から2026年までに6冊）を発表し、テレビバラエティやゲームの役柄にも出演している。
