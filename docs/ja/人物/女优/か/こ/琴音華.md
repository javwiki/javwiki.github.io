# 琴音華

## プロフィール

琴音華は2000年8月17日生まれ、秋田県出身の日本の元AV女優。ティーパワーズに所属していた。2021年3月1日、MOODYZ（ムーディーズ）専属女優としてAVデビュー。きっかけは親孝行したかったことで、母親から許可をもらってデビューした。母には撮影時の写真やパッケージ写真、インタビュー内容をその都度送っている。2021年12月には『週プレアダルトアワード2021』で優秀新人賞を受賞し、光文社『FLASH』発表の2021年セクシー女優ランキングで22位となった。

2023年1月、MOODYZ専属を離れ、企画単体女優への転向を発表した。2024年3月1日、同月31日をもってAV女優を引退すると発表し、5月31日付で所属していたティーパワーズを退所した。引退は台湾でも報道された。2025年1月、引退作を発売して現役を終え、発売日に各種SNSアカウントを削除した。Wikipediaが引く公式プロフィールによれば、現在は六本木のレッドドラゴンに在籍している。

## 人物

- 初体験は18歳で、相手は高校の部活の2個下の後輩であり初の彼氏。お互い処女と童貞だった。
- 緊張しやすいタイプで、プレッシャーで体調を崩したことがある。
- 芸名はNHKの朝ドラ出演女優とその役名、さらに花が好きであることから取った。
- 初のドラマ作品を撮り終えた際、自身の演技を「ちょっと棒読み」と評価している。
- 2021年6月時点の抱負は「いただいた仕事を全力でやっていきたい」。
- 顔射されるのが好きで、デビュー前から彼氏と行っていた。顔射後の自分の顔は、相手の男性に自分のスマートフォンで撮影してもらいコレクションしている。
- 放送作家の瓶底めがねは「純朴な見た目に反して中身はドスケベ」、AVライターのさおりは「実は170センチの高身長。脱ぐとものすごいスレンダー美ボディ」と評した。身長はInfoboxの164センチと一致しない。

## 作品の特徴

- 2021年3月からMOODYZ専属で、デビュー作は同メーカーの新人シリーズにあたる。
- 2021年7月に発表されたFANZA上半期アダルト動画売り上げランキングで2位。
- 2023年1月に企画単体へ転向してからは、共演作や企画ものにも題材が広がった。
- 2023年発売の『タダマンFile19 はな24歳 都合のよいセフレに精飲と中出しまくった記録』が2024年8月19日週のFANZA動画フロア週間ランキングで8位まで上昇。
- 2025年1月の引退作『ピストン止めないでってばぁ! No.1デカチンAV男優と追撃エンドレス中出しFUCK!! ヘルメット美少女琴音華 危険日にAV引退撮影! 最後に華ちゃんを絶対に孕ませる!』は、ジャージにヘルメット姿というデビュー作のオマージュで、AVライターの東風克智は「6時間完全燃焼」と評した。
- ゲームの声優出演が2作あり、『戦国愛撫-CHIGIRI-』で伊達政宗役、『社長と美女たちの二重奏』で中井安乃役を務めた。
