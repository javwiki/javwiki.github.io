# 清宮仁愛

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 清宮仁愛
- **読み**: きよみや とあ
- **英語名**: Toa Kiyomiya
- **生年月日**: 3月15日（年は非公開）
- **所属事務所**: バンビプロモーション
- **活動期間**: 2024年〜

## プロフィール

清宮仁愛は3月15日生まれの日本のAV女優。バンビプロモーション所属。2024年4月にデビューし、デビュー時のキャッチフレーズは「このカラダ、ラスボス。」。もともとAVのヘビーユーザーで、好きなものをやってみたいという純粋な興味からデビューした。

2025年5月には埼玉・しらこばと水上公園で行われたプール撮影会「TREND GIRLS撮影会2025」に、9月には神奈川・大磯ロングビーチで行われた同撮影会に、それぞれ撮影モデルとして参加した。夏場は髪を金髪に染めてギャルの役作りをし、痴女役を演じた。内心では「痴女物を出したときに受け入れてもらえるか心配だった」といい、その後は落ち着いた色に戻している。ギャル期間があったことで、作品の中の「清宮仁愛」像を確立できた時期でもあったと述べている。

2025年10月28日には、初のワンマンライブ『月で逢いましょう vol.130 清宮仁愛』を東京・三軒茶屋グレープフルーツムーンで開催し、カバー曲9曲を歌唱した。2026年2月8日には東京・秋葉原の書泉ブックタワーで、写真集『プレミアムヌードポーズブック 清宮仁愛』の発売記念イベントを開催した。

2026年2月9日週、4月発売予定だった出演作『MOODYZファン感謝祭バコバコバスツアー2026 25周年専属大集合!大乱交!大感謝スペシャル!』がFANZA通販フロア週間ランキングで初登場4位。同作は発売日が5月19日に延期されたものの、2月16日週に1位となった。4月13日週には、配信が始まった同作が動画フロア週間ランキングで3位に入った。

## 人物

- 中学生の初期に男子の先輩から「お前、おっぱいデカくね？」と言われ、初めて巨乳であることを自覚した。最初は「おっぱいデカい」と言われ続けてコンプレックスだったが、女の武器だと考えるようになってからは前向きになれたという。
- 自分の好きな体の箇所は「お尻からウエストにかけてのライン」。
- 特技はパイズリとフェラ。性癖はM。
- AVファン時代は「ジャケ買い」派だった。デビュー後もAVは見ているが、知っている監督の顔がちらつくためエロ目的での鑑賞は卒業し、「勉強の一環」として視聴している。
- ライターのもちづき千代子は「女体という単語がこれほどまでに体現された女優」と表現した。
- 酒豪で、2025年8月発売の『ギャルと呑むと楽しいしエロがってくれる!』（E-BODY）では作品内で記憶がなくなるまで飲酒するなど、本人の嗜好にちなんだ作品も制作されている。飲酒すると「セックスしたーい!と叫ぶ」「超ハッピーちゃんになる」と述べている。
- ボイン学園ハマノ理事長は「バストとウエストの差が50センチとすさまじく、なおかつ乳首位置が高い」とスタイルを論評し、柔らかさもあるため「騎乗位のときは円を描く軌道でバストが揺れる」と分析した。

## 作品の特徴

- 2024年4月にデビューし、キャッチフレーズ「このカラダ、ラスボス。」でスタイルを売りにしている。
- 2025年夏は金髪ギャルの姿で痴女役を演じ、その後は落ち着いた髪色に戻して作品内の人物像を確立した。
- 2026年の『MOODYZファン感謝祭バコバコバスツアー2026 25周年専属大集合!大乱交!大感謝スペシャル!』がFANZA通販フロア週間ランキングで1位を記録した。
- AVのほか2026年カレンダーと写真集『プレミアムヌードポーズブック 清宮仁愛』を発表し、プール撮影会や音楽イベントにも参加している。
- 2025年10月には初のワンマンライブを開催し、カバー曲9曲を歌唱した。
