# 木下凛々子

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

木下凛々子は1985年10月4日生まれ、東京都出身の日本のAV女優。プライムエージェンシーを経てGG所属。2020年3月、マドンナ専属女優としてAVデビューした。30代でのデビューで、同メーカーの熟女路線の専属として活動している。

2021年12月、『アサヒ芸能』が独断と偏見で選ぶ「アサ芸AV大賞」で熟女クイーンを受賞。2022年12月には同誌主催「アサ芸AV大賞2022」抱きたい熟女賞を受賞した。2023年6月27日発売の『週刊SPA!』「グラビアン魂」にモデル出演。みうらじゅんがAV女優と知らずに写真集を購入してグッと来たことでオファーされ、AV女優だから裸というのは安易すぎるという判断から着衣グラビアが掲載された。同年10月25日、東京・池袋Live inn ROSAの音楽イベント『楽演祭vol.27』に出演。10月27日には白石茉莉奈、奥田咲、希島あいり、風間ゆみ、JULIAと共にFANZA「11月19日は#いい熟女の日! 熟女・人妻キャンペーン2023」のキャンペーンガールに就任した。

2024年8月発売の『月刊FANZA』10月号で発表されたFANZA2024年上半期女優ランキングで9位。10月30日には『楽演祭 vol.33』でトリを務めた。以後も『LADY MADONNA』などの音楽イベントに出演し、2025年11月度のFANZA通販フロア月間AV女優ランキングで9位に入った。2026年5月29日から30日まで、台湾で行われた「第3回TOP女神台北感謝祭 春夏」に招待された。

## 人物

- 1985年10月4日生まれ、東京都出身、天秤座。趣味・特技はゴルフと料理。
- 初体験は16歳の時で、相手は初めて付き合った彼。
- 18歳からずっと勉強のつもりでAVを観ており、AV女優やセクシーな女性に憧れていた。30代でAVデビューする人が増えているという記事をネットで見た瞬間に最後のチャンスと思い、自ら応募してAV女優になった。
- 当初は1本だけのつもりだった。事務所面接で「1本だけでもリスクはある」「ヌードを残したいだけならAV女優でなくても良い」と説明され、逆にちゃんとした会社だと感銘を受けてデビューを決意した。内心では自分の作品などすぐ埋もれるだろうと思っていたという。
- 既婚者で、2020年6月時点で結婚6年目。デビュー時は仕事を夫に秘密にしていたが、2023年のバレンタインデーに夫婦生活をした際、夫はデビューに気づきながらあえて指摘せず、激しめの責めで得意げな顔をしたという。こうした経緯から事実上の夫公認となり、一時は不仲になったものの、もともと友達同士のような束縛しない間柄だったことや仕事への熱意、家庭を疎かにしない姿勢が伝わり、2026年時点では認め合って仕事も明確にカミングアウトしている。母親、妹にも仕事は伝えている。
- 好きな味はラ・フランスのような精液の味。SかMかを問われて「W」と答えている。
- マドンナはNTRや羞恥物の出演が多いが、本人曰く痴女作品の撮影の方が好みだという。
- 2026年のインタビューでは、目標とする人物として風間ゆみ、友田真希を挙げている。

## 作品の特徴

- 2020年3月からマドンナ専属で、熟女、人妻ものを中心にNTR、羞恥、痴女系まで幅広く出演している。
- 2021年にアサ芸AV大賞熟女クイーン、2022年に同賞抱きたい熟女賞を受賞し、熟女カテゴリの中心的な女優と位置づけられている。
- AVのほかOP PICTURESの映画に多数出演し（2023年から2026年）、オリジナルビデオと2021年7月29日発売のアダルトグッズもある。
- 2022年10月5日からFANZAニュースで連載コラム『木下凛々子の進め! これが私の人妻いっぽん道』を執筆。2025年9月4日からはWebラジオ『木下凛々子のりりこ様のひととき♪』を担当する。
- 音楽イベント「楽演祭」「LADY MADONNA」に繰り返し出演し、2024年10月30日の『楽演祭 vol.33』ではトリを務めた。
- 2026年5月、台湾の「第3回TOP女神台北感謝祭 春夏」に招待された。
