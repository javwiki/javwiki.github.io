# 北野未奈

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 北野未奈
- **英語名**: Mina Kitano

## プロフィール

北野未奈（きたの みな、2000年5月20日 - ）は、日本のAV女優。LIGHT所属。2021年4月、『弱冠20歳! 銀座NO.1（某有名高級クラブ）Hカップホステスと大型契約 AVデビュー』（E-BODY）でデビューした。キャッチフレーズは「男を虜にする最高級の美貌とスタイル」。2021年12月に『週プレアダルトアワード2021』最優秀新人女優賞を受賞。2022年5月から本中とFitchのW専属となり、2023年12月と2024年1月にMOODYZ、ワンズファクトリーとの専属契約を順次追加した。2025年6月に各メーカーとの契約が満了し、企画単体女優となる。

## 作品の特徴

- デビュー時は「銀座ナンバーワンホステス」という経歴を打ち出し、Hカップ（B92）の体型が作品の宣伝材料となった。
- 痴女もの、風俗もの、介護もの、調教ものを中心に出演。2025年に企画単体へ転向してからは出演メーカーがさらに増えた。
- 得意技は「スパイダー騎乗位」と自称する。2025年時点では膣圧で笛を鳴らす「おま○こリコーダー」と答えている。
- AV男優の森林原人は「フェロモンがたっぷりの美女なのに、無邪気な少女の一面を持ち合わせている」と評し、ライターの芝田カズは「全身凶器のような肉感ボディ」と評した。
- 2021年から2024年にかけて、FANZA／HHHグループの「トリプルHAPPYキャンペーン2021」「セクシースイーツキャンペーン2022」「GW大感謝祭2024」でキャンペーンガールを務めた。
