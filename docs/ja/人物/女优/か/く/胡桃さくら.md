# 胡桃さくら

## プロフィール

胡桃さくらは2002年10月29日生まれの日本のAV女優。ティーパワーズ所属。福井県出身。2022年2月23日、SODクリエイトの「もぎたて」レーベル専属女優としてAVデビューした。それ以前は声優専門学校へ進学するために上京しており、新人声優の仕事がアダルトアニメやアダルトゲームに偏る一方で自身の経験が少なかったことから、勉強のために3本限定でAVに出演し、のちに継続するに至った。

2022年夏、月刊FANZA「このAV女優がすごい!2022夏 新人編」で3位を獲得。2023年1月にはパチ・スロ サイトセブンTVの番組『魚拓と成瀬のツキとスッポンぽん』#434、#435に出演した。2022年3月には『月刊ソフト・オン・デマンド』3月号でグラビアとインタビューを務めている。

2024年4月、『アサヒ芸能』「2024現役AV女優セクシー総選挙」で総合37位。同月8日週には出演作がFANZA動画フロアランキング10位に入り、10月28日週には出演作がFANZA通販フロアランキングで初登場9位となった。2025年2月17日週には出演VR作品がFANZA動画フロアランキングで初登場9位、2026年1月26日週には出演作がFANZA通販フロアランキングで初登場8位となった。2025年2月から8月にかけてプレステージ出版からデジタル写真集を3冊刊行し、2026年3月1日には東京・代々木で行われたREAL20周年記念イベントに参加した。

## 人物

- 福井県出身。趣味はアニメ鑑賞で、『テニスの王子様』『黒子のバスケ』などスポーツ系アニメを好む。
- 初体験は17歳で、相手は同級生の初彼氏。デビュー時の経験人数は2人。
- 声優専門学校に進学するために上京し、デビュー前は声優を志していた。
- 新人声優の仕事はアダルトアニメやアダルトゲームが多い一方、自身の経験が少なかったため、勉強のために3本限定でAVに出演し、のちに継続した。
- 2026年3月のREAL20周年記念イベントに出演者として参加した。

## 作品の特徴

- 2022年2月にSODクリエイト「もぎたて」レーベル専属でデビュー。以後はSOD作品のほか、桃太郎映像出版、MAXING、KMPVR-彩-などのメーカー作品にも出演している。
- 2022年夏の月刊FANZA「このAV女優がすごい!2022夏 新人編」で3位となり、デビュー年の新人評価を得た。
- 2024年から2026年にかけて、出演作がFANZA動画フロアと通販フロアの週間ランキングで複数回トップ10入りし、最高は2026年1月の通販フロア8位。
- 2025年2月から8月にかけてプレステージ出版からデジタル写真集を3冊刊行。撮影はいずれも潤。
- 2022年3月に『月刊ソフト・オン・デマンド』3月号でグラビアとインタビュー、2023年1月に『魚拓と成瀬のツキとスッポンぽん』に出演した。
