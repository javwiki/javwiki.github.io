# 倉本 すみれ

日本のアダルトビデオ女優。

## 基本情報

- **名前**: 倉本すみれ
- **英語名**: Sumire Kuramoto
- **生年月日**: 2001年9月14日
- **出身地**: 日本東京都
- **身長**: 153cm
- **所属事務所**: ボディコーポレーション

## プロフィール

倉本 すみれは2001年9月14日、東京生まれ、ボディコーポレーション所属。2021年10月、MOODYZの新人作『新人20歳 女子アナにいそうなほど可愛い! 渋谷区にあるお洒落なカフェで働く敏感スレンダー美少女 エッチが好きすぎてAVデビュー!!』でAVデビューし、『月刊FANZA』「このAV女優がすごい!2021年冬 新人編」で3位に入った。以後は企画単体としてMOODYZ、MAXING、h.m.pなどで作品をリリースし、2022年11月度FANZA月間AV女優ランキング2位、2022年年間8位。2023年11月には「みんなあつまれ MOODYZキャンペーン2023」のキャンペーンガールを務めた。2024年10月15日、企画単体を離れ、同年11月から無垢・本中・ダスッ!の3メーカー専属になることを発表。2025年には松本いちかとユニット「fleuЯR（フルール）」を結成し、シングル『好きすぎる / 明日くもりのち』をリリースした。

## 作品の特徴

- デビュー作はMOODYZの新人作。以後は長く企画単体としてメーカーをまたぎ、彼女、妹、姉、人妻、悪女、ハードな企画まで幅広い役柄をこなす。
- 2021年冬からFANZAや『月刊FANZA』のランキングに度々登場。2021年冬新人編3位、2022年夏女優編2位、2022年年間8位、2023年上半期11位、2023年年間通販10位・レンタル2位。
- 2024年2月12日週、出演作『MOODYZファン感謝祭 バコバコバスツアー2024』がFANZA通販フロア週間ランキング初登場1位。2024年2月度動画フロア月間AV女優ランキング3位。
- 2025年10月13日週、出演作『【MOODYZ創立25周年記念】 MOODYZ 大ハード学園』がFANZA動画フロア週間ランキング1位。
- 細身の体型で、初期は自然な体毛も特徴の一つだった。2024年末に剃毛作品を出し、2025年に元に戻したことを『週刊プレイボーイ』が「剃毛も役作り」と報じた。
- AVライターの沢木毅彦は、優等生、劣等生、小悪魔、悪女、娘、姉、妹などをこなせるとし、「AV界の令和の怪物」と評した。
