# 倉本すみれ

日本の成人映像出演者。

## 基本情報

- **名前**: 倉本すみれ
- **英語名**: Sumire Kuramoto

## プロフィール

倉本すみれは2001年9月14日生まれ、東京都出身。ボディコーポレーション所属。2021年10月、MOODYZの新人作『新人20歳 女子アナにいそうなほど可愛い! 渋谷区にあるお洒落なカフェで働く敏感スレンダー美少女 エッチが好きすぎてAVデビュー!!』でAVデビューした。以降は企画単体としてMOODYZ、MAXING、h.m.pなど複数メーカーの作品に出演し、2024年11月から無垢・本中・ダスッ!の3メーカー専属となる。2025年には松本いちかとアイドルユニット「fleuЯR」を結成し、シングル『好きすぎる / 明日くもりのち』を配信リリースした。

## 作品の特徴

- デビュー作はMOODYZの新人作。その後は長く企画単体として各メーカーをまたぎ、恋人、妹、姉、人妻、悪女、ハードな企画まで役柄は広い。
- 2021年冬からFANZAや『月刊FANZA』の女優ランキングに入り、2021年冬新人編3位、2022年夏女優編2位、2022年年間8位を記録した。
- 細身の体型で、初期は自然な陰毛が特徴の一つだった。2024年末にパイパン作品を出し、2025年には元に戻しており、『週刊プレイボーイ』は剃毛も役作りの一環だったと記している。
- AVライターの沢木毅彦は、優等生から劣等生、小悪魔、性悪女、娘、姉、妹まで演じ分けられるとし「AV界の令和の怪物」と評した。本末ひさお、渋江譲二も体型について論じている。
