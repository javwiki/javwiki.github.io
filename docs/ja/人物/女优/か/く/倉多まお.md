# 倉多まお

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 倉多まお

- **出身地**: 日本 秋田県
- **所属事務所**: ニューゲート
- **活動期間**: 2012年〜

## プロフィール

倉多まおは1994年3月7日生まれ、秋田県出身の日本のAV女優。ニューゲート所属。2012年8月にエスワンからAVデビューした。デビューのきっかけについて、後年「今思い返しても、なにがきっかけだったか思い出せない」と述べている。趣味はダンス、特技はフィギュアスケートで、CSスカパー!958ch「バニラスカイチャンネル」のバニラガールズのメンバーでもある。

2012年から出演を続け、AVのほかSILK LABOの女性向け作品、イメージDVD、写真集、デジタル写真集、テレビやミュージック・ビデオにも出演している。2023年5月22日週には出演作『BAZOOKA 冬の大感謝セール コスパ最強ノーカットベスト爆乳限定2749分』がFANZA動画フロア週間AVランキングで1位を記録。同年10月30日週には主演作がFANZA通販フロアランキングで10位となった。2025年2月24日週には2024年発売の『【配信専用】倉多まお 全部見せます完全収録BEST 1320分』がFANZA動画フロアで7位まで急上昇した。

## 人物

- 目標は「毎回全力投球で完璧な作品を作り上げる」こと。
- 理想とする女優像は「ずば抜けてすごい、という感じではなく、安心して作品を買ってもらえるような女優」、すなわち「安心安定の品質を提供する女優」。
- AVライターの本末ひさおは「優しく攻めるのが得意でソフトな痴女をさせたら絶品」「超スロー手コキの気持ちよさは画面越しにも伝わってくる」と評している。

## 作品の特徴

- 2012年8月にエスワンからデビューし、以後は単体企画や共演作を中心に2012年から2025年まで出演を続けている。
- AVのほか、SILK LABOの女性向け作品（2016〜2023年）、イメージDVD（2017年）、テレビ出演（2013年、2017年）がある。
- 写真は2012年の双葉社写真集『All Blue』のほか、2017年から2023年にかけてアイロゴス、プレステージ出版からデジタル写真集を発表している。
- 2023年から2025年にかけて、BAZOOKAの総集編と個人ベスト作品が数次にわたりFANZA週間ランキングのトップ10に入った。
