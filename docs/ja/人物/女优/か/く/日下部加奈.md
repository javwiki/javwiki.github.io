# 日下部加奈

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 日下部加奈
- **読み**: くさかべ かな
- **英語名**: Kana Kusakabe
- **生年月日**: 1995年7月11日
- **カップ**: I（デビュー時。のちに店頭で測り直しJ）
- **所属事務所**: プライムエージェンシー→GG
- **活動期間**: 2019年〜

## プロフィール

日下部加奈は1995年7月11日生まれの日本のAV女優。プライムエージェンシーを経てGG所属。2018年4月にソフト・オン・デマンド（SOD）へ入社し宣伝部に配属された。同年11月13日からは綾瀬麻衣子と2人で宣伝部のTwitterを受け継いでいる。自身がAVに出演する予定はないと問われれば2人とも否定していたが、上司のすすめもあり、『月刊ソフト・オン・デマンドDVD』2019年4月号で出演が発表され、SOD社員のまま2019年3月にAVデビューした。「SOD女子社員・日下部加奈」として3作品に出演している。

2019年7月にSODを退社し、8月13日から新たにTwitterを開始。9月にMOODYZ専属女優としてデビューすることを報告し、12月13日にMOODYZの最優秀新人賞に選ばれた。2021年1月よりアタッカーズ専属となり、2022年8月9日にはマドンナへ移籍したことを報告した。

2025年2月17日週、出演作『マドンナALL専属バスツアー2025 ハーレムを掴み取った男たちが極上の美女を独占!! 酒池肉林のお祭りはまだまだ続く!! 夢の大共演 & 大乱交FESTIVAL!! 後編』がFANZA通販フロア週間ランキングで初登場8位となった。2025年11月5日からはウェブラジオ『日下部加奈のかなのお部屋でごゆっくり～♪』を担当している。

## 人物

- 趣味・特技は映画鑑賞、バレーボール、字を書くこと。
- 自身がAVに出演するとは思っていなかったが、SOD社員時代に上司から薦められ、「この業界に興味があってSODに入社した訳だし、もっと現場を知るためにも出てみよう」と考えて出演を決めた。撮影時にスタッフが真剣に作品を作っていることを知り、みんなで一つの作品を作る楽しさを感じたこと、また「色々な挑戦をしたい」という思いから、退社して本格的にAV女優として活動することを選んだ。
- SOD退社後のプロフィールでは「元トリンプ下着販売員」と記述されることがある。
- 小学5年生でFカップ、デビュー時にはIカップあった。デビュー後に下着を買いに行った店で測ってもらうとJカップになっていたが、Jカップのブラジャーは20代が着けるようなデザインの物がなく、窮屈ではあるもののIカップのブラを使用している。
- 普段の服装はワンピースなどお姉さん系。
- AV男優の澤野ヒロムは、胸に顔をうずめるだけで癒される癒し系としながら、「それでいてイタズラっ子のような愛嬌がある」「不意に乳首をイジってきて僕の反応を楽しんでいる」と、時折見せる茶目っ気も論評している。

## 作品の特徴

- 2019年3月にSOD社員のままデビューし、初期作品は「SOD女子社員」という人物設定が中心。
- 2019年9月からMOODYZ専属となり、同年12月にMOODYZの最優秀新人賞を受賞。
- 2021年1月にアタッカーズ専属、2022年8月にマドンナへと、時期ごとに専属メーカーが替わっている。
- 2020年4月25日、写真集『ゴージャスプリン』（ジーウォーク、撮影：安田一福）を発売。
- 2025年2月に出演したマドンナ全専属バスツアーの後編が、FANZA通販フロア週間ランキングで初登場8位となった。
