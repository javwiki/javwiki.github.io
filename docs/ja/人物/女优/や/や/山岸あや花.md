# 山岸あや花

日本の女優、元AV女優、元地方テレビ局アナウンサー。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 山岸あや花
- **読み**: やまぎし あやか
- **英語名**: Ayaka Yamagishi
- **別名**: 山岸逢花（旧名、やまぎし あいか）
- **生年月日**: 1992年11月30日
- **所属事務所**: リスタープロ（2025年9月末に退所、以後フリー）

## プロフィール

山岸あや花は1992年11月30日生まれの日本の女優、元AV女優で、地方テレビ局の元アナウンサー。2017年7月、「山岸逢花」（やまぎし あいか）名義でPREMIUM（プレミアム）専属女優としてAVデビューした。当時の所属事務所はクルーズグループ。2023年5月15日、30歳を迎えた機にリスタープロへの移籍を発表し、「山岸あや花」へ改名した。改名に際しては「山岸」という名字の知名度を考えて名字を残し、下の名前は「あや花」と「あやめ」の2案から「花」の文字を残したいという本人の意向で「あや花」に決まった。

2018年5月19日に開催されたDMMアダルトアワード2018では新人賞にノミネートされた。2020年2月11日配信の「恵比寿マスカッツ 真夜中の運動会」に新メンバー最終候補として出演し、同年3月31日の配信で加入を発表。同年5月には『綺麗なお姉さんがチ○ポバカになるまでヌイてくれる種搾りメンズエステ 山岸逢花』がFANZA動画フロア週間ランキングで2週連続1位となり、2020年上半期の女優別ランキングでは9位、12月の「FLASH 2020年現役最強セクシー女優BEST100」読者投票では31位に入った。2021年1月1日には業界初のUltra HD Blu-ray規格ソフトがアイデアポケット、PREMIUM、ダスッ!の3メーカーから同時発売され、山岸はPREMIUM作品の主演を務めた。同年6月17日にはピンク映画ベストテン2020で新人女優賞と桃熊新人女優賞を同時受賞した。

2022年1月、同じ事務所所属だった美谷朱里とのユニット「ぎしたに」としてYouTubeチャンネル「山岸と美谷。」を開設し、5月から『週刊アサヒ芸能』で対談連載を始めた。同年8月には写真展「縁-circle-」を開催し、恵比寿マスカッツの卒業公演を経てグループ解散に伴い卒業。2023年5月の『アサヒ芸能』「2023現役AV女優SEXY総選挙」では45位。同年10月から11月にかけ、『お義父さん、そんなに強く抱かれたら…若妻が絶倫義父との中出しセックスに溺れた日々。山岸逢花』がFANZAレンタルフロア週間ランキングで4週連続1位となり、11月の月間女優ランキングでも1位を記録した。2024年にはFANZAのキャンペーンガールを2度務め、12月には美谷朱音とともに「アサ芸セクシーアワード2024」共演賞に選出された。2025年2月には台湾の「TOP女神台北感謝祭」に参加。同年9月10日、所属事務所のXにて9月末をもってリスタープロ退所とAV女優としての活動終了を発表し、10月以降はフリーとして活動している。

## 人物

- 以前は東海地区の地方テレビ局のアナウンサーであったが、理想と現実の狭間で短期間で退社した。その後は別の仕事をしていたが華やかな世界が忘れられず、AVデビューを決めた。
- デビュー後しばらくは「ひっそりやる」くらいの意識で、売れることを意識せず、ツイッターなどもしていなかった。
- アナウンサー時代、実況経験がないにもかかわらず、私生活では実況を求められることが多かったとコメントしている。
- 初オナニーは小学4年の時で、初体験は中学3年の時に1つ年上の先輩と。
- 趣味はカフェめぐりで、カルチャー系の趣味は持たないが、アナウンサー歴から音楽、雑誌、ファッションなど全般的な知識を持つ。
- AVライターの末吉みちおは「どんなに変態プレイをしても、下品にならないのが素晴らしい」と評している。
- 改名時には、新しい名前でも旧ファンに「山岸」と分かってもらえることを願い、「花」の字は本人が残すことにこだわった部分だと説明している。

## 作品の特徴

- 2017年から長くPREMIUM専属として出演し、人妻、義父もの、共演企画など幅広い題材をこなした。2023年の義父ものはレンタルフロア週間ランキングで4週連続1位となった。
- 2021年には業界初のUltra HD Blu-ray規格作品の一つに主演し、同規格の初期参加者となった。
- 写真集は『花と逢』（2020年）、『Reflection』（2021年）、『duende』（2022年）、『Cosplay Fetish Book 山岸あや花』（2024年）、『斐色』（2024年）の5冊。ほかに『プレミアムヌードポーズブック Model 山岸あや花』（2023年）がある。
- AVのほかピンク映画、オリジナルビデオ、舞台、ウェブドラマにも出演し、Netflix『全裸監督』第7話やfempass Cinemaの複数作品が含まれる。
- 2025年9月末のAV引退後も女優として活動し、以前のVR共演作は2025年11月にFANZA動画フロア週間ランキング1位となった。
