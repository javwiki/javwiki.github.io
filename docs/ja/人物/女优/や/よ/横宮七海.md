# 横宮七海

日本の元AV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 横宮七海
- **読み**: よこみや ななみ
- **英語名**: Nanami Yokomiya
- **生年月日**: 2002年2月17日
- **逝去**: 2023年12月（Wikipediaは12月10日と記載。同日は訃報公開日で、正確な日付は未確認）
- **所属事務所**: クローネ
- **活動期間**: 2021年〜2023年

## プロフィール

横宮七海は2002年2月17日生まれの日本のAV女優。クローネ所属。2021年4月10日にデビューし、ロリ系として知られた。

2022年2月、「このエロVRがすごい!」において、出演作『【VR】天井特化アングルVR ～何もない休日に彼女とヤリまくる～ 横宮七海』が2021年下半期作品ランキング1位を獲得した。

2023年12月10日、友人がSNSを通じて訃報を発表した。日本国内ではほとんど報道されず、台湾などアジア圏では大きく報じられた。正確な逝去日は公開情報では確認できておらず、Wikipediaは12月10日を卒日として記載するが、公開報道で確認できるのは同日が訃報の公開日であるという点までである。本項はこの相違を残している。

## 人物

- 趣味・特技は食べ歩きと料理。ボールペンで絵を描くことと水鉄砲も挙げている。
- 好きな花は芝桜、勿忘草、向日葵。尾崎豊のファン。
- 経験人数は100人を超えると述べている。
- AV監督の太田みぎわは、虐待が儚く見える女優として横宮を挙げ、「そういう相手だと依存しちゃう可能性があるんです。それがメチャクチャエロい」と論じた。
- 「真島奈央」「宇佐ましろ」「白石もえ」などの名義でもイメージDVDを発表しているが、Wikipediaはこれらの名義を別名欄には置いていない。

## 作品の特徴

- 2021年4月からロリ系としてデビュー。WikipediaにはDVD、VR、配信の各分類が置かれている。
- VR作『天井特化アングルVR ～何もない休日に彼女とヤリまくる～ 横宮七海』が「このエロVRがすごい!」2021年下半期作品ランキング1位。
- イメージDVDは3作とも別名義で、『放課後えっちズム』（真島奈央）、『セーラー服を脱がさないで…』（宇佐ましろ）、『もえもえキュン』（白石もえ）。
- 2021年9月24日、デジタル写真集『娘に喰わせてもらってます。』（WAAP photo）を発表した。
