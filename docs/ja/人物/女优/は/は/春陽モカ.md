# 春陽モカ

日本の成人映像出演者。

## 基本情報

- **名前**: 春陽モカ
- **英語名**: Moka Haruhi
- **生年月日（公式・出版資料）**: 2002-05-27

## プロフィール

春陽モカは2002年5月27日生まれ、ACT所属。2024年3月にMOODYZからデビュー（日本語版Wikipediaは3月5日、ACT公式は4月2日、データベースは3月29日。後述）。2025年6月からMOODYZ、ワンズファクトリー、本中の3メーカー専属となった。同年9月末で本中との専属が終了し、11月発売分からOPPAIが加わって再び3メーカー専属となる。2025年7月に写真集『令和最強GAL降臨』を刊行。作品は中出し、巨乳、ギャルを軸に、VR作品や大人数共演の企画にも出演する。

## 作品の特徴

- 2025年時点の出演作では「中出し」「巨乳」「ギャル」がよく設定され、ギャル女優として分類されることが多い（日本語版Wikipediaの作品傾向の整理）。
- AVライターの東風克智は「スタイル抜群で目鼻立ちもクッキリしており、コスプレが非常に似合う」と評しており、外形とコスプレ適性に触れた評価が残る。
- 2025年からはMOODYZ、ワンズファクトリー、本中（のちOPPAI）の複数メーカー専属で、痴女ヘブンやOPPAIの企画にも出演。
- VR作品のほか、MOODYZの大人数共演企画「バコバコバスツアー」2025・2026の両方に出演。
