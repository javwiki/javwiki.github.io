# 福田ゆあ

日本のAV女優、元グラビアアイドル。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

福田ゆあは2005年2月20日生まれ、大阪府出身の日本のAV女優。バンビプロモーション所属。高校卒業後に上京し、2023年からグラビアアイドルとして活動を始めた。当時はGold Circle Entertainmentに所属していた。2025年11月3日、Xで「福田ゆあ」への改名とMOODYZ専属としてのデビューを発表し、Xアカウントも朝霧名義のものから変更した。台湾でもこのデビューは報道され、芸名は福田悠亞と訳された。

AVデビュー作は2025年10月27日週のFANZA通販フロアランキングで初登場1位。11月3日週にはBlu-ray版が6位、DVD版が4位に入った。2025年11月度のFANZA通販フロア月間AV女優ランキングは6位、12月度も6位だった。

2026年1月23日にはYouTubeチャンネルを開設。同年6月、旅行で訪れたニュージーランドで「詳細なアクティビティ予定がなかった」ことを理由に留置場に入れられ、入国拒否の上で強制帰国させられたことが報道された。

## 人物

- 芸名「福田ゆあ」は、「よく笑うから」「福がありそうだね」とプロデューサーに命名された。AVデビュー時のキャッチコピーは「国宝級美少女」で、AVライターのさおりは「国宝級にハレンチな国宝級美少女」と意味合いを解説した。
- 旧芸名「朝霧ましろ」は『魔法少女サイト』の朝霧彩と『ひろがるスカイ!プリキュア』の虹ケ丘ましろの名前を組み合わせたもの。
- 自身の芸名のアルファベット表記は「YUA FUKUDA」ではなく「YUA FUCUDA」としている。朝霧ましろ時代も「MASHIRO ASAGIRI」ではなく「MASILO ASAGILI」という表記を好んで使っていた。
- 母子家庭で育ち、高校生の時まで極貧生活を経験した。そのため旅行や習い事などやりたいことができないことにコンプレックスを抱いていた。
- 初体験は中学2年の13歳の時で、相手は彼氏ではなく、自分に好意を持っていた2つ上の社会人の元先輩。仲の良い友人がみな処女を卒業して話の輪に入れないのが嫌で、ネタづくりのためにラブホテルで初体験を済ませた。その後も複数人と関係を持ったが、全員1回だけの関係だった。オナニーは週7回。中学3年で彼氏ができてからセックスの気持ちよさを知った。
- 好きなラーメンは二郎系。好きなAV女優は跡美しゅりと桃乃木かなで、桃乃木とは同じジロリアンとして崇拝していると話す。
- 高校卒業後すぐに都内でアパートを借り、当時ファンだった跡美しゅりと同じバンビプロモーションを訪ねたが、20歳未満は採用できないと門前払いされた。その足でGold Circle Entertainmentの面接を受け合格し、芸能界デビュー。上京の目的はAV女優になることだったため、20歳になると再びバンビを訪ね、AV女優となった。
- 仲の良いAV女優は純白彩永。生年月日が同じで、仕事でも偶然一緒になることが多く、互いに共演したいと話している。

## 作品の特徴

- 2025年11月からMOODYZ専属としてデビューし、デビュー作はFANZA通販フロアランキングで初登場1位。
- デビュー時の位置づけは「国宝級美少女」で、作品は単体企画とVRが中心。
- 2025年11月24日週、『国宝級美少女 アヘアヘ放心淫れイキ4本番』が通販フロアランキングで初登場7位。同じ週、デビュー作が動画フロアランキングで再び1位となった。
- 2026年1月5日週発売のイメージビデオ『脱グラドル 福田ゆあ』（FAIR＆WAY）が通販フロアランキングで初登場3位。
- 2026年2月2日週、初のVR作品『国宝級にカワイイ最強笑顔プリンセス福田ゆあを味わい尽くすVR』が動画フロアランキングで初登場6位。
- AVのほか写真集とデジタル写真集を発表し、映画にも出演している。
