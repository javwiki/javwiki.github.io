# 星まりあ

日本のAV女優。2022年7月31日までは「天音まひな」名義で活動。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 星まりあ
- **読み**: ほし まりあ
- **英語名**: Maria Hoshi
- **別名**: 天音まひな（旧芸名）
- **生年月日**: 1999年7月16日
- **出身地**: 日本 東京都
- **身長**: 145cm
- **カップ**: G
- **所属事務所**: エイトマン（2022年7月〜。2026年にSO MODEL AGENTへ商号変更）
- **主要メーカー**: S1 NO.1 STYLE（エスワン）
- **活動期間**: 2020年〜

## プロフィール

星まりあは1999年7月16日生まれ、東京都出身の日本のAV女優。エイトマン所属。2020年6月、「天音まひな」名義でエスワン専属女優としてAVデビューした。2022年7月31日、X（当時はツイッター）でフォーティーフォーマネジメントを退所し、「星まりあ」へ改名してエイトマンへ移籍することを報告した。

身長145cmでGカップという体型と、「巨乳で童顔」というギャップを売りにしている。高校生の時はクラスで一番小さく、一番胸が大きかったと本人が話している。ライターのヘルス侍は「大きさ、形、張り、弾力、乳輪のバランス、すべてが完璧なAV界屈指の美巨乳」と評し、AVソムリエの渋江譲二は「巨乳で童顔というギャップに魅了。エッチモードに入ったときの大人びた表情がめっちゃ妖艶」と、そのプレイスタイルを例えている。

デビュー作は『アサヒ芸能』調べ（FANZA協力）の2020年AV年間販売ランキングで15位に入った。2021年にはFANZAのお気に入り登録数が1万を超えた作品が6本あり、ヒット作を連発した。写真では2022年6月に1st写真集『あま恋』を発売し、同年10月には新名義でデジタル写真集『天使の143』を発表した。
