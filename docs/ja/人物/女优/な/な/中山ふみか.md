# 中山ふみか

日本のAV女優、歌手。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

中山ふみかは1997年9月5日生まれの日本のAV女優、歌手。LIGHT所属で、中国語圏では「中山文香」の表記で報道される。幼稚園から小学校低学年までの短い期間だが、舞台を中心に子役として活動していた。2019年12月、MOODYZ専属女優としてAVデビュー。デビュー当時は飲食関係のアルバイトを掛け持ちし、プライベートのSNSを止めてメディア露出もすべて断っていたが、デビューの翌日にバイト先の同僚から「似てるよね」と言われ、周りにバレているのは自分でも感づいていた。それで直接とがめられることがなかったためバイトは続け、撮影後にそのまま出勤したこともあった。

元々5本の出演は決まっていたが、それ以降は返事を保留していたため一度活動を休止する。休止したタイミングで新型コロナウイルスの影響もあり、自身の仕事について考え直すきっかけとなってAV女優を再開することを決断した。このため2020年4月から8月まで作品の間隔があいている。中山は活動再開時の作品を「AV女優としてのデビュー作」と位置づけ、最も緊張した1作に挙げている。

歌手としては2021年9月28日、「月で逢いましょう＃22 ニューカマースペシャル」で初めてライブに出演し、12月20日には初のワンマンライブ「月で逢いましょう＃30」を東京・三軒茶屋グレープフルーツムーンで開催した。以降も定期的にライブ活動を続けている。2022年12月1日にはDMM GAMES「クリムゾン妖魔大戦 新キャラクター声優公開オーディション」にエントリーし、最終オーディションまで参加した。2025年5月20日、長年在籍したMOODYZを離れ、OPPAIへ専属移籍することを自身のSNSで報告した。

## 人物

- 東京都出身。趣味は読書と歌うこと、特技は速読。
- 演じることは幼少時からしており、「芝居物と言えば、という話題の時に上から3番目くらいに名前が挙がる女優」を目標としている。舞台観劇は今でも趣味。
- 高校に入って太ったためダイエットをしたら胸だけが残り、巨乳になった。自身の胸を「寝転がったときに液体かホイップクリームみたいになる」と例えている。
- AV好きの女友達から「AV出てそうだね」と言われ、未知のAVの世界に興味が沸き、見て体験すれば理解も深まるのではと思ってAV女優となった。
- プレイ主体の作品は「素で語れるものが何もないから」と苦手にしており、役柄を演じるドラマ作品を得意としている。同じ事務所の石原希望は「卑屈だなあ。語るものいっぱいあるじゃない」とフォローしている。
- 初体験は17歳。デビューまでの経験人数は3人。AV女優再開時に初めてバイブを購入したが、使ったのは1回だけで、その後は部屋のオブジェになっている。

## 作品の特徴

- 2019年12月にMOODYZ専属でデビュー。2020年4月から8月まで休止とコロナの影響で作品の間隔が空き、再開時の作品を本人は「本当のデビュー作」と位置づけている。
- 巨乳と演技を生かしたドラマ作品が中心で、本人は役柄を演じる芝居物を好む。
- 長くMOODYZに出演し、2025年5月にOPPAI専属へ移籍。
- 歌手活動をAVと並行し、「月で逢いましょう」のワンマンライブを定期的に開催。2026年にはクラウドファンディングで制作したオリジナル曲4曲を公開した。
- 映像作品のほかカレンダーなどの関連商品も発売している。
