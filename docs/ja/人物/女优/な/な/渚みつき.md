# 渚みつき

日本の元AV女優、モデル。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **読み**: なぎさ みつき
- **英語名**: Mitsuki Nagisa
- **生年月日**: 1998年2月7日

- **活動期間**: 2019年〜2024年（AV）、2024年〜2025年（モデル・女優）

## プロフィール

渚みつきは1998年2月7日生まれ、静岡県出身の日本の元AV女優。引退時はバンビプロモーション所属。2019年1月にデビューし、キャッチコピーは「誰もが憧れた学校一のマドンナ」だった。『月刊FANZA』2023年7月号のインタビューによると、正式デビュー前に『大嫌いなオヤジ相手なのに大量潮吹き!』（kira☆kira）へ無記名で出演している。事務所に入った時は金髪だったが、「デビューするなら黒髪に」と言われ、デビュー作とイメージビデオの撮影に臨んだ。

2019年4月までにレズ、ごっくんを次々に解禁し、その後は大量ぶっかけ、集団凌辱、宙づり拘束などのハードな企画にも挑み、企画単体のトップ女優の一人となった。2020年8月、『月刊FANZA』発表の2020年上半期AV女優ランキングで5位。同年12月、「FLASH 2020年現役最強セクシー女優BEST100」読者投票の清楚部門で4位。FANZA発表の2020年年間AV女優ランキングでは8位だった。2021年9月と2022年9月には「トリプルHAPPYキャンペーン」のキャンペーンガールを務めた。

2023年1月18日、デビュー5周年を迎える2024年1月13日をもって引退すると表明。理由は婚活で、占いの結婚予定日が毎年後ろ倒しになり、婚期を逃していると感じたことが発端だった。2024年1月13日、オフ会をもってAVを引退したが、事務所には残り、モデルと女優の仕事を続けた。アクション監督・早瀬重希が全面プロデュースするガールズアクションプロジェクト「アクションKICKガールズ」にも参加している。2025年1月31日には、同年8月いっぱいでの事務所退所と完全引退を発表した。

## 人物

- 静岡県出身。血液型はB型。4歳上の姉と3歳上の兄がいる。
- 趣味はライブ、ドライブ、キックボクシング。特技はカラオケ。
- 初体験は中学1年生で、相手は同い年の彼氏。場所は公園の誰でもトイレ。デビュー時の経験人数は約80人。
- 中学時代に「こいつは名器だ」と言われ、当時の彼氏によくAVを見せられてフェラを覚えたことからAV女優という職業に興味を持った。中学3年の作文に「将来AV女優になりたい」と書き、先生には怒られたが、クラスメイトには「お前ならなれる」と言われた。
- 漫画『鬼滅の刃』のヒロイン・竈門禰豆子のコスプレイヤーとして知られ、発端となったパロディ作品は海外メディアでも取り上げられた。撮影前にはイメージを具体化するため原作を読み込む。
- AVライターのくろがね阿礼は独自の統計から、彼女を2019年上半期の頂点に立つ新人女優と分析した。親友の永瀬ゆいは「みつきちゃんは好きな人としか絡まない人」と評している。
- アドリブのセリフがうまいと評され、俳優の渋江譲二は「無邪気なメスガキ、薄幸の若妻、地雷系女子までどんな役柄もこなせる」と演技力を評価した。本人は小学生役は恥ずかしくないが、本来の性格と正反対の「あざと可愛い」役柄は恥ずかしいと話している。
- 親友は枢木あおいで、仕事としても最多共演女優となった。同学年だが、デビューは枢木の方が2年早い。
- 身長のわりに手足が大きく、特に足のサイズはまだ成長中だと撮影インタビューで答えている。

## 作品の特徴

- 2019年1月のデビュー後は企画単体として活動し、レズ、ごっくんから大量ぶっかけ、集団凌辱、宙づり拘束まで幅広い題材に出演した。
- デビュー作は「学校一のマドンナ」というキャッチコピーに沿った作りで、2019年上半期の新人の頂点と評された。
- 2023年7月3日週、出演作を収録したアンソロジー『【福袋】S-Cute 可愛い子だけ15作品をノーカット収録38時間!』がFANZA動画フロアランキングで1位、8月7日週に3位へ再浮上した。
- 2023年9月、10月と2か月連続でFANZA動画フロア月間AV女優ランキング3位。11月、12月は6位だった。
- 引退後も収録済みの作品が発売され、2024年5月から7月のFANZA動画フロア月間女優ランキングで4位、7位、6位に入った。
- AVのほかオリジナルビデオ、ウェブドラマ、ゲームに出演し、写真集とイメージビデオも発表している。
