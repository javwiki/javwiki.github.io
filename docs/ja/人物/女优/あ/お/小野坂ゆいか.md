# 小野坂ゆいか

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 小野坂ゆいか
- **読み**: おのさか ゆいか
- **英語名**: Yuika Onosaka
- **別名**: 小野坂唯花（中国語圏での表記）
- **生年月日**: 2002年2月9日（2001年12月30日とする説もある）
- **所属事務所**: ティーパワーズ（2026年5月にバンビプロモーションから移籍）
- **活動期間**: 2024年〜

## プロフィール

小野坂ゆいかは2002年2月9日生まれの日本のAV女優。ティーパワーズ所属で、以前はバンビプロモーションに所属していた。中国語圏では「小野坂唯花」と表記される。2024年6月、『FIRST IMPRESSION 174』でアイデアポケットよりAVデビュー。デビュー時のキャッチフレーズは「肉感ヒロイン」である。デビューのきっかけは高校時代からエロ漫画を好んで読んでいたことで、過激なほうが好きなため男性向け作品を好み、そこからAVを見るようになったという。単体女優物は見たことがなく、デビュー作の撮影では「私の知っているAVとなんか違う」と思ったと語っている。

2024年いっぱいで同メーカーの専属を卒業し、2025年より企画単体女優に転向した。単体時代の作品レビューで「おなかが気になる」と書かれたことで、企画単体までの期間に約4キロのダイエットを行い、2025年9月のインタビューではデビュー時より7キロくらい絞ったと答えている。2025年5月4日にはTREND GIRLS撮影会2025に参加し、黒い水着姿がWWSチャンネルで報道された。同年9月に開催される大磯ロングビーチでの撮影会にも参加が発表された。2025年10月13日週のFANZA通販フロアランキングでは、『私たちは、イカれたファンから媚薬漬けにされてどっちにも入れ放題のアヘ顔姉妹オナホに成り下がりました…。』が初登場5位を記録し、2026年1月度の通販フロア月間AV女優ランキングでは10位となった。

2026年はランクインの機会が増えた。2月9日週には4月発売予定だった『MOODYZファン感謝祭バコバコバスツアー2026 25周年専属大集合!大乱交!大感謝スペシャル!』が初登場4位となり、発売日が5月19日に延期された後も2月16日週に通販フロア週間ランキング1位を獲得、4月13日週には動画フロア週間ランキング3位に入った。3月から6月にかけても通販、動画、レンタルの各ランキングで10位以内に入り、『夢?現実?仮想空間? AIでエロ動画を生成していたら、画面から飛び出してエロいプレイと中出しSEXまでできちゃった!』は初登場6位だった。2026年4月時点でバンビプロモーションの公式サイトから名前が消え、代わりにティーパワーズのサイトに名前が載る状況が続き、本人からの発表はなかったが、5月3日に自身のXでティーパワーズへの移籍を発表した。月刊FANZA発表の「FANZA2026年上半期ランキング女優編」では4位に入っている。

## 人物

- 趣味はグルメ巡り、旅行、コスプレ。特技は絵を描くこと。
- 生年月日は出典により2種類ある。週刊FLASH2024年8月20日・27日合併号では「2001年12月30日生まれ」、月刊FANZA2025年7月号では「2002年2月9日生まれ」とされ、週刊実話では「年齢非公開」とされていた。本項は月刊FANZAの2002年2月9日を採用し、相違を残した。
- おにぎりを好み、決めポーズでも手を三角形にする「おにぎりポーズ」を行う。
- 高校時代は美術部で、一時期鉛筆書きのエロ漫画を執筆していた。
- 初体験は高校2年生で、ゲームを通じて出会った30代の男性と。漫画喫茶内だったため、バレそうでバレない緊張感が一時期性癖になったという。
- 企画単体への転向後は月に10から15本ペースで撮影し、月刊FANZAの担当者によればこれは企画単体としては多いほうだという。体力があり撮影で疲れたことはないと述べ、週刊プレイボーイの取材では「寝て起きるとリセットされる」と発言している。役の幅が広がったことも喜びだとしている。
- 有名欲は薄く、有名になるよりは「この子は抜ける」と言われる女優になりたいと述べている。
- 台湾ではチアリーダーの小珍奶（シャオ・ジェンナイ）に似ていることから「暗黑小珍奶」と呼ばれている。
- AV男優の鮫島健介は業界きっての蛇舌の持ち主と評し、「意思があるかのように口内の隅々まで届く」と述べている。アダルトメディア評論家の安田理央は「AV女優というよりもAVのお仕事自体を楽しんでいるなぁという印象。こういう子って貴重ですよね」と人物評を述べた。
- 2026年2月発売の『TVの前のユーザー皆様に究極のオナニーを約束します!淫語女子アナ38 小野坂ゆいかアナSP』では女子アナ役を務め、2026年5月時点のFANZAレビュー17名全員が星5つを付けた。AVライターの末吉みちおは「淫語AV史に燦然と輝く名作」と評した。

## 作品の特徴

- 2024年6月にアイデアポケット専属でデビュー。デビュー作は「FIRST IMPRESSION」シリーズの174作目で、「肉感ヒロイン」という触れ込みだった。
- 2024年内に専属契約を終え、2025年から企画単体に転向。出演は複数メーカーに広がり、役柄も単体女優から「キモいおばさん」などの脇役まで広がった。
- 2026年はFANZAの通販、動画、レンタル各ランキングで10位以内に入る作品が複数あり、MOODYZ25周年感謝祭企画やAI生成を題材にした作品が含まれる。
- 女子アナ、淫語ものを得意とし、淫語女子アナ作品はFANZAで満点のレビューを集めた。
- 2025年12月に写真集『ゆいか日和』、2026年にはトライエックスからカレンダーを発売している。
