# 推川ゆうり

## プロフィール

推川ゆうりは1990年6月13日生まれ、大阪府吹田市出身の日本のタレント、AV女優。ティーパワーズ所属。身長165cm、スリーサイズはB93（F）-W60-H90、血液型AB。高校卒業後、大阪府内で2年間パティシエ見習いとして働き、2011年8月末にクラブイベントを盛り上げるギャルユニット活動中にスカウトされ、ジュエルプロモーションと契約してグラビアアイドルへ転向した。直後に「おねだりマスカットSP!」のオーディションに合格し、2011年10月から恵比寿マスカッツの7期生としてテレビ東京系の同番組に出演した。

2012年3月25日からスーパー耐久でピースモータースポーツのレースクイーンユニット「Love&Peace」のメンバーとして活動。同年4月にはケータイヤングジャンプ「ぷるるんサバイバル2012」4月期を1位で通過し、6月期にも参戦した。2013年1月31日、芸名を「押川唯香」から「推川ゆうり」へ変更。4月7日、舞浜アンフィシアターの恵比寿マスカッツ解散コンサートで卒業した。5月21日発売の『FLASH 2013年6月4日号』巻中グラビアでセミヌードを初披露し、7月1日にMUTEKIからAVデビュー。デビュー理由として、マスカッツ活動でAV女優のメンバーがキラキラして見えたことを挙げている。

2016年から企画単体へ転向。2017年の『淫語』（ワープエンタテインメント）で、優しい口調の言葉攻めをする痴女イメージが付いてブレイクした。その後、アメリカで活躍するポルノスター・まりかを知って約9か月の語学留学を行い、まりかと出会い、アワードの見学や他のポルノスターとの交流も経験。留学はコロナ禍で終えることとなった。2024年2月からマドンナ専属女優となり、2024年9月15日には「TREND GIRLS 撮影会 2024」内のファッションショーでランウェイを歩いた。

## 人物

- 趣味は旅行とソフトテニス。高校時代はソフトテニス部に所属し、近畿大会まで出場する実力だった。
- 恵比寿マスカッツでは、特に同じ7期生の雪美えみると仲が良い。
- ファッションブランドのシャネルが大好きで、2011年7月から飼い始めたロングコートチワワにも「シャネル（♀）」と名付けた。2012年4月から2匹目の「チェルシー（♂）」、2013年2月から3匹目の「キャロル（♂）」を飼い、現在は実家で飼っている。
- AV女優としてのキャッチフレーズは「日本で一番シコい女優」。
- AVライターのくろがね阿礼は、バストやヒップだけでなく手、足、口と全身にテクニックがあると評した。同じくライターの芝田カズは95センチの美巨尻が評判で、バックや背面騎乗位での波打つ尻肉がいやらしいと論じた。

- 2013年7月にMUTEKIからデビューし、同年10月からS1 NO.1 STYLE専属（infoboxでは2014年5月まで）。2016年に企画単体へ転向。
