# 尾崎えりか

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **読み**: おざき えりか
- **英語名**: Erika Ozaki
- **別名**: 与田さくら（旧名）
- **生年月日**: 2000年3月30日

- **活動期間**: 2021年〜

## プロフィール

尾崎えりかは2000年3月30日生まれの日本のAV女優。LIGHT所属。2021年8月、「与田さくら」名義でPREMIUM（プレミアム）専属女優としてAVデビューした。同メーカーの専属は5本でいったん終わり、約2か月の期間を置いた後、尾崎えりか名義でPREMIUMから共演作を出して専属契約を満了した。

2022年8月に「尾崎えりか」へ改名。同年10月以降はPREMIUM専属を離れ、企画単体女優として活動している。企画単体転向以降はナチュラルなエロさとプレイの巧みさで、多数のメーカーから出演のオファーを受ける人気女優となった。2024年3月18日週のFANZA動画フロアランキングでは、出演作『【8K VR】身も心もスッキリできる噂のメンズビューティーサロン 銀座店』が初登場9位に入り、この時期からVR作品の定評が高まって「新・VRの女王」と呼ばれ始めた。

2025年9月30日、自身のXにてケイ・エム・プロデュースのMillionレーベル専属になることを発表した。2026年1月26日週のFANZA動画フロアランキングでは、2023年発売の『【暴発体験談】妹の友人・えりかさんのエステ研修（ブラジリアンワックス）で、風俗ではない真っ当なエステにも関らず、早漏敏感な私はうっかり勃起してことごとくお漏らしルーインド射精してしまった話をご紹介。』が5位まで急上昇。同年3月16日週のFANZA配信フロアランキングでは、KMPVR10周年記念の6時間共演作が初登場10位に入った。

## 人物

- AV女優になったきっかけは「知り合いにAV事務所を紹介されて、『まぁ、やってみるか』って軽い気持ちで」。のちに「ちゃんと自覚をもって取り組めばよかった」と後悔の念も持っており、ふわふわしたまま1年強過ごしたと述べている。
- 企画単体転向以降はナチュラルなエロさとプレイの巧みさで、多数のメーカーからオファーを受ける人気女優となった。
- 学生時代からテストの時のみ英単語などを覚える「短期記憶」が得意で、台本を覚えるのも早い。このためVR作品での現場の評判が上がり、作品数が増えた経緯がある。
- AVにおいては痴女役が多いが、プライベートは淡白で「愛があれば何でもいい」派。性的な好みも声が高い人が好きなくらいで普通だという。一方、デビュー前の経験人数は3桁を超えており、その時々の男性の性嗜好に合わせて対応してきたため、作品により変化をつけて演じられているのもこの経験ではないかと推論している。
- イラストレーターの杜の冷やし中華は「ちょうどいい肉付き」という体型、中でも丸みを帯びたヒップを評価し、「エステ作品で威力を発揮。オイルまみれの尻コキ、肉尻が暴れまくる背面騎乗位などヌキどころの宝庫」と論じている。
- 2023年2月27日、フジテレビONE『もう!バカリズムさんの超H! #42』に出演した。

## 作品の特徴

- デビュー時はPREMIUM専属で、まず「与田さくら」名義で5本を発表し、その後「尾崎えりか」名義で共演作を出して契約を満了した。
- 2022年10月に企画単体へ転向してからは出演が複数メーカーに広がり、エステ、痴女、共演企画など幅広い題材をこなしている。
- VR作品を得意とし、2024年以降は8K VR作品で週間ランキング10位以内に入り、「新・VRの女王」と呼ばれるようになった。
- 2025年9月からMillion専属となり、2026年もKMPVR10周年記念などの大型企画でランクインしている。
- 2026年1月には本人役のアダルトグッズ「YUIRA JAPANホール 尾崎えりか」が発売された。
