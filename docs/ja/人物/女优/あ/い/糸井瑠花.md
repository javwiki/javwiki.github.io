# 糸井瑠花

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

糸井瑠花は生年月日非公表の日本のAV女優。エスフラート所属で、関西出身。学生時代に英語担当の教師に憧れて教師を志し、関西の大学の教育学部に入学した。教師の夢が薄れると将来を考え、好きでサンプル動画を多数見ていたAV女優をまず短期でやろうと考え、エスフラートに所属した。

2024年12月10日、『新人NO.1 STYLE 時代は賢くてエロい娘！若くて綺麗なカラダの教育実習生！糸井瑠花AVデビュー』でS1からデビュー。短期で辞める前提だったが、デビュー作発売後のインタビューでは「でも今はAV女優をずっとやっていきたいなと思ってます」と答えた。

2025年11月発売作品をもってS1専属を卒業し、kawaiiへ専属移籍。その後、VRを含む4作品で専属契約を終え、企画単体へ移行した。2026年9月発売の徳間書店『アサヒ芸能』で「NEXTキカタン美女」に選出された。

## 人物

- 生まれてからずっとショートカットで、最大に伸ばしたのは肩につくくらいの長さ。幼い頃から親や祖母に「あんたはショートがよう似合う!」と言われ続けたためだという。
- 芸名はS1のプロデューサーが命名したもの。関西出身のため「元阪神タイガース・糸井」と指摘されることも多いが、本人は由来を知らず、祖母と親が阪神ファンだと述べている。
- 役としては標準語で話すことも多いが、日常会話は関西弁である。
- 友人にはAVが好きなこと、巨乳グラビアアイドルが好きなことも伝えてあったため、AV女優になったことも伝えている。友人は驚いたものの、「サンプル動画を3回観た!」と返信してきたという。
- 自身の武器は胸だと認識しているが、デビューするまでは意識したことがなく、褒められて「これが武器なんだろう」と理解した。下半身は高校時代に脱毛した。初体験は19歳。
- 静かな間が苦手で、絡みシーンでは「間を埋めるために声を出さなって思うので、我慢せずに声を出しちゃいます」と説明する。ドラマ作品でも台本を覚えるのが苦手でアドリブが多いと話している。
- AV男優の鮫島大介は「絡みでは理性が完全にぶっ飛んで、アへ顔をさらしながら潮をジェット噴射」と潮吹きを評価し、天井まで届きそうだった撮影もあったと振り返る。AVライターの芝田カズは「潮吹きファンタジスタとの呼び声も高い」と評した。

## 作品の特徴

- 2024年12月からS1 NO.1 STYLE専属で、デビュー作は「新人NO.1 STYLE」シリーズ。人物設定は教育実習生。
- 2025年11月発売作品でS1専属を卒業し、kawaiiへ専属移籍。その後、VRを含む4作品で専属契約を終えた。
- 専属期間の終了後は企画単体へ移行し、題材の幅を広げた。
- 2026年9月、『アサヒ芸能』で「NEXTキカタン美女」に選出された。
- AVのほかイメージビデオ『思春期の少女 糸井瑠花』（2025年4月8日）や『Best naked/糸井瑠花』（2026年3月28日）も発表している。
