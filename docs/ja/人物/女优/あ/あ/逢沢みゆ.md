# 逢沢みゆ

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 逢沢みゆ
- **英語名**: Miyu Aizawa

## プロフィール

逢沢みゆ（あいざわ みゆ、2001年1月25日 - ）は、日本のAV女優、元アイドル。2013年に「坂本マリア」名義でアイドルグループ「フラップガールズスクール」に加入し、2018年のグループ卒業後に保育士免許を取得して2年間保育の仕事に就いた。2023年12月12日にS1 NO.1 STYLE専属としてAVデビュー。2024年11月に企画単体への転向を表明し、12月に所属がNAXとなった。2025年12月、『FLASH』「FLASHセクシー女優ランキング2025」で5位。2026年1月には、事務所の許可を得て実際の誕生日が2001年1月25日であることを公表した。

## 作品の特徴

- デビュー作はS1専属で、『新人NO.1STYLE 逢沢みゆ AVデビュー 本物アイドルのAV転身、その全記録ー』というタイトルどおり元アイドルという経歴を打ち出した。
- S1専属は2024年11月まで。企画単体への転向後はSODクリエイト、ロイヤル、プレミアム、h.m.p、グローリークエストなどの作品に出演し、共演もの、義親もの、介護もの、風俗ものなど幅広い題材をこなしている。
- 2024年から2026年にかけて写真集を4冊発表した。『相逢 sou-ai』（双葉社）、『me=you』（徳間書店）、『プレミアムヌードポーズブック』（ジーオーティー）、『Miyutopia』（彩文館出版）。
- 高速騎乗位を得意と自称する。AVライターの東風克智は「処女役が上手い」と評し、監督のレミレミ・ニューワールドは「プロ意識が高く、自己プロデュースと努力の天才」と評した。
- 2026年9月には東京・渋谷のギャラリー・ルデコで写真展「未完成。」を開催した。
