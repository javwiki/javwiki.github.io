# 有村のぞみ

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

有村のぞみは1997年2月14日生まれ、静岡県出身の日本のAV女優。アトラクティブ所属。2018年1月、プレステージ専属女優としてAVデビュー。2019年1月をもって専属を離れ、企画単体女優となった。

2019年3月1日、FANZAアダルトアワード2019最優秀新人女優賞にノミネート。2020年6月、メンズサイゾーのイメージガールに就任し、同年8月からは自身でデザイン、縫製した衣装で撮影するグラビア連載『ハレンチのんちゃん』を始めた。2021年1月22日にはりょうとのコラボ写真集プロジェクトを開始し、2022年10月には同人頒布会「ゆるケット」にワイルドワンモデルとして参加した。

2022年12月20日、『スカパー!アダルト放送大賞2023』新EXガールズオーディションにノミネートされ、同月にコスプレファッションブランド「nonnonstyle」を立ち上げた。2023年3月には審査員推薦により新EXガールズメンバーとなる。2023年6月25日、レフカダ新宿で初のトークイベント「のんちゃんといっしょvol.1」を開催し、ゲストの浜崎真緒と2時間40分にわたって語った。2025年2月10日週、出演作『MOODYZファン感謝祭 バコバコバスツアー2025 素人17名とAV女優17名の1泊2日大乱交 新世代AVオールスター覚醒！』がFANZA通販フロアランキングで予約段階初登場3位。同年10月20日週には、出演作『ダスッ!プレゼンツ WELCOME TO THE ようこそ!ズコバコキングダム 最強AV女優10人衆が痴女プリンセスの座を巡って1泊2日の凄テク激ヌキぱこ祭り!』が動画フロアに初登場9位でランクインした。

## 人物

- 静岡県出身。趣味は海外旅行、お笑いをみること、お酒を飲むこと。
- 好きな女優は浜崎真緒で、2019年にはレズ作品での共演が実現した。
- 特技はY字バランス、前後180度開脚。好きなキャラクターはミニオン。
- 初オナニーは小学3年の時。初体験は中学1年の時で、相手は当時付き合っていた一つ年下の小学6年生。
- デビュー以前はファッション系の仕事をしており、その関係で服のデザインから縫製まで一人でできる。2020年8月からは自身で制作した衣装をまとうグラビア連載を始めた。
- 体液フェチで、潮、おしっこ、母乳もののAVをオナニーのおかずにしている。
- AV女優は天職だといい、いちユーザーとして観たい画を自身の出演作で実演できるのがうれしく、興奮するという。

## 作品の特徴

- 2018年1月から2019年1月までプレステージ専属で、以後は企画単体作品が中心。恋愛、共演、ドラマ系の題材を幅広く扱う。
- AVのほかイメージDVDを多数発表し（2019年から2026年）、女性向けAV、VR、配信作品もある。2019年の『本物マルチタレント 着エロデビュー』は「早川ひとみ」名義で発売された。
- テレビは『ケンコバのバコバコテレビ』（2018年6月から2019年7月、2020年1月から、サンテレビ）と『アトラクティブ女学園』（2020年8月から、エンタ!959）に出演。
- 2019年8月26日に写真集『honey sugar』を出版。2020年8月からメンズサイゾーで『ハレンチのんちゃん』を連載し、撮影衣装のデザインと縫製を自ら手がけた。
- 2022年12月にコスプレファッションブランド「nonnonstyle」を立ち上げ、2023年からBIKINIS TOKYOのモデルを務める。
- 2025年からOP PICTURESの映画に出演し、『セックス指南物語 理性をこえた腰づかい』と2026年の『エロちょろギャル』（ジュリア役）がある。
