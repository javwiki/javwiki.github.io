# 天然美月

日本のAV女優。2021年5月28日までは「天然かのん」名義で活動。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 天然美月
- **読み**: あまね みづき
- **英語名**: Mizuki Amane
- **別名**: 天然かのん（旧芸名、2021年5月28日まで）
- **生年月日**: 1999年12月22日
- **出身地**: 日本 秋田県
- **所属事務所**: Wish（2021年5月〜）。それ以前はプライムエージェンシー
- **デビューメーカー**: SODクリエイト（キミホレレーベル）
- **活動期間**: 2020年〜

## プロフィール

天然美月は1999年12月22日生まれ、秋田県出身の日本のAV女優。Wish所属。2020年8月、SODクリエイトのキミホレレーベルからデビューした。デビュー時はラーメン屋と居酒屋のアルバイトを掛け持ちしており、「エロかわいい」AV女優として売り出された。2021年5月28日、プライムエージェンシーからWishへ移籍し、同時に「天然美月」へ改名した。

芸名は「天然であざとい」ことからデビュー作のプロデューサーが命名した。本人は「キモメン大好き」と自称しており、これを題材にした作品も多い。キミホレ時代は作品パッケージのカラーがオレンジで統一されていた。オレンジは「私のイメージカラー」だといい、レーベルを離れた後も好みの色と答えている。キミホレ専属時代を本人は「オレンジ時代」と呼んでいる。

企画単体に転向してからは役柄の幅が広がった。2022年11月7日週、出演した『マジックミラー号ハードボイルド』シリーズ作がFANZA動画フロアの週間AVランキングで1位を獲得。2023年7月24日週には出演したVR作が同ランキングで1位を記録した。2021年には映画『共振』に初出演し、同作はカナザワ映画祭とゆうばり映画祭に入選している。

## 人物

- 初体験は16歳。デビューまでの経験人数は8人で、うち交際相手は3人。
- 父が見ていた桜樹ルイのAVを見てAV女優に憧れるようになった。性の目覚めは小学校低学年で、きっかけのひとつに父が愛読していた『ヤングジャンプ』連載の『おくさまは女子高生』を挙げている。
- 実家が水商売関係をしており、祖母と母からは「いつまで経っても女でいなさい」と躾けられてきた。
- MT車の免許を持っている。
- あざとい女性を演じることが多く、企画単体転向以降は女子校生から若人妻まで幅広い役柄を演じる。
- 飼っている犬の芸名はクロ子ちゃん。

## 作品の特徴

- 2020年8月からSODクリエイトのキミホレレーベルで活動し、キミホレ時代のパッケージカラーはオレンジで統一されていた。
- 「キモメン大好き」という自称にもとづく設定・題材の作品が多い。
- 2021年に企画単体へ転向してからは、女子校生から若人妻まで役柄が広がり、題材の幅も大きく拡大した。
- AVのほかイメージビデオ『Kanon 清楚系びっち』『くちびるツンととがらせて』、写真集『僕の元カノ』、デジタル写真集、ポーズ集を発表している。
- 2021年には映画『共振』に出演し、テレビ番組『ケンコバのバコバコテレビ』にも出演した。
