# 新井リマ

## プロフィール

新井リマ（あらい りま、2000年10月3日 - ）は、日本のAV女優。兵庫県出身、LIGHT所属。2021年6月にSODクリエイトのレーベル「KMHR」専属女優としてデビューし、同年11月にメーカー専属を離れて企画単体に転向した。2022年6月にはイメージDVD『My Girl』を発売。2024年12月公開の『ネトラレ、純愛。』で映画に初出演した。2025年6月よりMOODYZ、kira☆kira、ワンズファクトリーのトリプル専属女優となる。

## 作品の特徴

- デビュー時のキャラクターは「ちょいギャル」で、ギャル役を演じる機会が多い。
- 2021年11月の企画単体転向後はMAXING、MOODYZ、h.m.p、ワンズファクトリーなど複数メーカーの作品に出演し、義父もの、風俗もの、逆襲ものなど題材も広がった。
- MOODYZ「バコバコバスツアー」シリーズ（2024年・2025年）など、大人数の共演企画に参加している。
- KMPVR-彩- などのVR作品があり、2025年2月17日週には出演VR作品がFANZA動画フロアの週間ランキングに初登場9位となった。
- 2024年から映画に出演し、2025年6月以降は3メーカーの専属作品が中心となる。
