# 浅野こころ

日本の成人映像出演者。

## 基本情報

- **名前**: 浅野こころ
- **英語名**: Kokoro Asano
- **旧芸名**: 歌野こころ

## プロフィール

浅野こころ（あさの こころ、2002年6月11日 - ）は、日本のAV女優、タレント。宮城県仙台市出身、Bstar所属。2023年3月にS1 NO.1 STYLE専属女優「歌野こころ」としてAVデビューし、同年8月22日に「浅野こころ」へ改名することを発表した。2024年7月にはFANZAレンタルフロアの週間ランキングで自身初の1位を記録し、同月と11月に同フロアの月間AV女優ランキング1位となった。2025年1月には2冊目の写真集の発売イベントを行い、初のワンマンライブを開催した。映像作品のほか、音楽イベントや写真集、テレビ番組にも活動の場を広げている。

## 作品の特徴

- S1専属としてデビューし、初期作品では「キレかわ清楚」な女子学生、妹、図書委員などの役柄が多い。
- 2024年7月以降、出演作がFANZAレンタルフロアの週間ランキングで繰り返し1位となり、同月の月間AV女優ランキングでも1位となった。
- 本人は特技を「杭打ちピストン」と答えている。AVライターの芝田カズは「小悪魔痴女ものに定評」と評し、同じくライターのさおりは胸の形を「半円を描くおっぱいは弾力性に富んでいて、寝ても形が崩れないほど張りがある」と評した。
- 2025年には写真集『喉の奥まで触られたい』（ジーオーティー）と同名のイメージビデオ『喉の奥まで触れられたい』（Aircontrol）を発表。後者はAVプロデューサーの肉尊がプロデュースした。
- 音楽活動も並行し、2023年から「月で逢いましょう」「楽演祭」などのライブに出演。2026年3月のワンマンライブでは初めてギターの弾き語りを披露した。
