# 椿りか

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 椿りか
- **英語名**: Rika Tsubaki

## プロフィール

椿りかは1999年6月5日生まれ（日本語版Wikipediaの記載。データベースでは1996-06-05、後述）。2017年4月1日に「大島ひな」名義でAVデビューし、2作品のみ出演した後、川崎のソープランドで勤務した。2019年、風俗総合サイト「ヘブンネット」の全国ミスヘブン総選挙2019で神奈川ソープ部門1位、全国ソープ部門5位。2020年6月13日に「椿りか」へ改名して再デビューし、2022年時点で名前の出ない作品を含め1000作品以上に出演した。2021年頃からは「りかしゃふちゃん」としてパチンコ来店活動も行い、2024年以降は映画にも出演している。

## 作品の特徴

- 企画単体女優として複数メーカーの作品に出演する。ROOKIE公式の作品一覧には『美女と野獣 ギャルとキモオタ』シリーズ、痴女企画の総集編、放尿・潮吹き系の総集編、中出しBESTなどが並ぶ。
- 2024年2月配信の『サンバでエロすぎギャルをナンパ！…』（DOC）は街頭ナンパ、巨乳、中出しを設定とし、2024年6月と8月にFANZA動画フロア週間ランキング10位に入った。
- 2024年以降はh.m.p、マドンナ、MOODYZ、KMPVRなどの作品に出演し、VR作品や大人数共演の企画も含む。
- 映像出演にはOP映画『密着巨乳姉妹 おっぱいは知っている』（2024-11-29、サヤ役）と『さあやとこはる 最終章』（2025-11-21、高橋桃花役）がある。
