# 月野 りさ

## プロフィール

月野 りさは日本の元AV女優、ストリッパー。2008年7月にkawaii*の新人としてデビューし、童顔と女子高生・ギャル系の役柄で知られた。2010年にスカパー!アダルト放送大賞日刊現代賞を受賞。2012年3月末に引退し、その際に『週刊現代』で「AV界のエンジェル」と称された。

## 人物

- 東京都出身。158cmの小柄な体型にCカップ。
- 3人兄妹の末っ子（兄と姉がいる）。
- 童顔で、女子高生やギャル系の役柄を多く演じる。
- 趣味：料理、いたずら、水泳、茶道。
- 引退記念のグラビアが『週刊現代』に掲載され、「AV界のエンジェル」と称された。

## 作品の特徴

- 童顔と女子高生・ギャル系の役柄を中心に、デビュー初期はkawaii*、kira☆kira、プレステージなど多くのメーカーで活躍。
- 2010年以降はクリスタル映像、マキシング、ケイ・エム・プロデュース、ワンズファクトリー、MOODYZ、GARCONなどのメーカーで大量の企画単体作品に出演。
- 引退作『月野りさ完全引退作 月チャンネル!』（マキシング、2011年4月）。
