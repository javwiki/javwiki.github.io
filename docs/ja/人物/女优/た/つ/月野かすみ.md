# 月野かすみ

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 月野かすみ
- **英語名**: Kasumi Tsukino

## プロフィール

月野かすみは2002年1月26日生まれ、神奈川県鎌倉市出身。オールプロ、アローズを経て、現在はリスタープロ所属。2020年10月、DEEP'S専属女優としてAVデビューした。デビュー作DVDMS-585は10月7日にパッケージ発売され、FANZAでは配信開始日を10月3日としている。2021年5月に専属を離れ、企画単体となった。

## 作品の特徴

- DEEP'S専属時代は巨乳、痴女、家庭教師と教え子といった設定の作品が中心だった。企画単体に転じてからはh.m.p、MAXING、妄想族など各メーカーをまたぎ、義姉、NTR、人妻、幽霊などの題材も扱う。
- 本人は「責め好き」と自認し、誘導する役柄や囁き、痴女役の作品が多い。2024年頃にバイセクシュアルを公表し、レズ作品にも出演している。
- 2026年に本人が掲げる方向性は「ふわふわ系ダウナーお姉さん」。
- ライターのもちづき千代子は「想像以上の傑物」と評し、体毛の特徴にも触れている。
