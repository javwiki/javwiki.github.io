# 月野 かすみ

日本のアダルトビデオ女優。以下のデビュー情報は挙げた資料に基づき、順位を人物情報の代わりにはしない。

## 基本情報

- **名前**: 月野かすみ
- **英語名**: Kasumi Tsukino
- **生年月日**: 2002年1月26日
- **出身地**: 日本神奈川県鎌倉市
- **所属事務所**: リスタープロ（かつてオールプロ、アローズ）

## プロフィール

月野 かすみは2002年1月26日、神奈川県鎌倉市生まれ。オールプロ、アローズを経て、現在はリスタープロ所属。2020年10月、DEEP'Sの専属女優としてAVデビューし、デビュー作DVDMS-585は10月7日に実体発売、FANZAでは配信開始日を10月3日としている。2021年5月に専属を離れて企画単体へ。2026年に本人が示した方向性は「ふわふわ系ダウナーお姉さん」。

## 人物

- 鎌倉市出身。趣味は茶道、料理。特技は書道、着付け。
- 小学5年でDカップ、中学ではGカップになっていた。
- 初体験は17歳のとき、同級生の彼氏と。
- デビューのきっかけは、地元の鎌倉でDEEP'Sのスタッフに声をかけられ、「マジックミラー便」で撮影交渉を受けたこと。AVの撮影とは思わず断ったが、車を降りた直後に別のスタッフから雑誌取材と称して後日会い、AVメーカーのスタッフだと明かされて出演を勧められた。最初は衝撃を受けたが、ずっとコンプレックスだった大きな胸を褒められ、「コンプレックスを活かして自信を持てるかもしれない」と思い、出演を決めた。
- 両親は厳格だったが過干渉ではなく、性に関しても家族に迷惑をかけなければよいという考えだった。実家での初体験後に父から「静かにしなさい」と言われた逸話があり、母は撮影時にスタッフからもらったメッセージカードを見て、娘が月野かすみだと気づいている。
- 友人には自分から積極的に打ち明けており、異性の同級生から下ネタのDMが届くと、最新作のURLを添えて返すという。
- デビュー前から責め好きを自認し、デビュー後は「相手の頭の中を気持ちよくさせたい」という思いが強くなった。時間や空間の支配もセックスと考え、肌を触れ合わなくても心が通うこと、会話の間の沈黙、空気や香りも性愛の対象と捉えている。
- 2024年頃にバイセクシャルを公表。タチ役が多いため本音では男優をうらやみ、陰茎のあるハイエナに憧れている。
- 「月野かすみ」という芸名は自分で考えた。
- ライターのもちづき千代子は本人を「想像以上の傑物」、身体的特徴を「奔放に繁茂する陰毛がエロい」と紹介している。

## 作品の特徴

- DEEP'S専属期は巨乳、痴女、家庭教師と教え子などの設定が中心。企画単体転身後はh.m.p、MAXING、妄想族などにわたり、義姉、NTR、人妻、幽霊などの題材がある。
- 本人は「責め好き」を自認し、作品中では誘導、耳語、痴女役が多い。2024年前後にバイセクシャルを公表し、レズ作品にも出演。
- 2026年に本人が示した方向性は「ふわふわ系ダウナーお姉さん」。
