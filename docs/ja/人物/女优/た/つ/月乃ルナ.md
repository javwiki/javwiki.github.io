# 月乃ルナ

日本のAV女優、歌手。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 月乃ルナ
- **読み**: つきの ルナ
- **英語名**: Luna Tsukino
- **生年月日**: 1995年10月1日
- **出身地**: 日本 東京都
- **所属事務所**: エイトマン（2025年8月に再移籍、のちSO MODEL AGENTに改称）
- **主要メーカー**: DAHLIA（2026年〜）
- **活動期間**: 2019年〜

## プロフィール

月乃ルナは1995年10月1日生まれ、東京都出身の日本のAV女優、歌手。『週刊プレイボーイ』などのグラビアモデルを務めた。2018年、音楽ユニット「JC + The Mechanics」（ジュラシック・カッパーフィールド・アンド・ザ・メカニックス）を発足してボーカルを担当し、オリジナル楽曲を配信。同年、写真集オムニバス『天使集』に参加し、2019年には写真集『月の魔法』を出版した。以降はエイトマン所属となる。2019年2月、『新人 月乃ルナ ～最上●が激似のアノ子が衝撃のAVデビュー～』でAVデビューし、この作品をきっかけにブレイクした。

2021年前後にバンビプロモーションへ移籍。2021年8月、「読者300人が選んだFLASH 2021セクシー女優ランキング」読者投票30位。同月、月刊FANZA「このAV女優がすごい!2021年夏」6位、冬季女優編5位。2022年は4月だけで13本の作品を発売し、なかでも『凄テクを我慢できれば生中だしSEX』が大評判とされた。同年5月、『アサヒ芸能』「2022現役AV女優SEXY総選挙」24位。2022年8月よりアタッカーズと本中の2社専属となる。

2023年8月、NAXプロモーションに移籍し、同時期にXを開始。2024年3月、4月にSODクリエイトから発売予定だった『SNSで大炎上!? ファンにおっぱいを揉まれた金髪美人DJのセックス動画がヤバすぎて問題になっています。 月乃ルナ』が発売中止となった。SODは「諸般の事情」としている。『女性自身』によれば、韓国のDJ SODAが2023年に音楽フェスで性被害に遭った騒動のパロディとみられ、SNS上で批判の声があった。2024年4月、『アサヒ芸能』「2024現役AV女優セクシー総選挙」総合27位（東京46位、大阪19位）。2025年8月に再びエイトマン（のちSO MODEL AGENTに改称）へ移籍し、2026年3月（誌面表記は4月）からDAHLIA専属女優となった。

## 人物

- 少女時代は人見知りで引きこもりがちだったが、女子高に進学。ファミレスでのバイト先で出会った先輩に交際を申し込まれ、断ったところストーカー化。根負けして交際し、約半年かけて初体験に至った。束縛の強さから別れを切り出すと再びストーカー化し、その後の相手も同じ傾向だったため「メンヘラ製造機」の異名を持つ。AVデビューまでに7人ほど交際した。
- AV出演のきっかけは「興味があったことと、色々なことに挑戦してみたかったので、やってみたから」。2024年のインタビューでは、偶然AV女優と仲良くなり、彼とのセックスレスを相談したことを挙げている。
- 彼に相談すれば止められると思っていたが、「やりたいことならやったほうがいい」と受け止められ、面接、撮影と進んだ。内心では「私、ホントにAV撮りに行っちゃうよ～?」と思っていたという。
- デビュー後1年の専属期間は媒体に露出せずミステリアスなキャラクターを作っていたが、企画単体に移ってからはイメージを固定せず、様々な役柄を演じている。
- 憧れのAV女優は吉沢明歩。
- 2019年前後は最上もが似を売りとしており、自身もファンでチェキを撮ってもらったことがある。2021年には金髪をやめ、陰のあるスレンダー清純派系として売り出している。
- かつてはハード作品にも出ており、「SEXはズボズボ挿入される受け身」とも評される。アダルトメディア研究家の安田理央は2022年12月の記事で「芸能人激似というイメージから脱却し、『クールな表情でエロい』という独自路線を見事に確立した」と評した。

## 作品の特徴

- デビュー前はグラビアモデル兼音楽ユニットのボーカルで、2019年2月にAVへ転向。2022年4月だけで13本を発売した企画単体期の高産出が特徴。
- 2022年8月からアタッカーズと本中の2社専属、2026年からはDAHLIA専属作品が中心。
- 清純派のドラマ系からハード作品、企画単体の共演作まで幅広く、デビュー初期は「芸能人似」の話題性、2021年以降は陰のあるスレンダー清純派として売り出された。
- 写真集は2019年『月の魔法』、2026年『月に満ちて。』のほか、2018年のオムニバス『天使集』にも参加。
- 音楽では2018年に『Night Breeze』を配信し、JC + The Mechanicsのメンバーとして活動。2024年4月16日の「月で逢いましょう vol.91」では椎名林檎、B'z、BiSHの楽曲をカバーし、2025年5月8日にはワンマンライブを開催した。
- 2024年8月号『VIBES』Vol.370で表紙を担当。
