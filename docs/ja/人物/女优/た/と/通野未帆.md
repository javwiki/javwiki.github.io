# 通野未帆

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## プロフィール

通野未帆は1991年1月21日生まれ、東京都出身の日本のAV女優。現在はACT所属で、デビュー時はGREENに所属していた。身長160cm、スリーサイズはB87（E）-W59-H85で、サイズは2013年時点の公称値である。本人は「売りがない」「永遠の素人」と自称しており、この言葉には熟女から魔法少女まで幅広い役柄を演じられるという意味と、初心を忘れないという思いが含まれている。ライターのくろがね阿礼は「売りがないと自称しているが、引き締まったスレンダー体形と美脚が特徴で、それらを際立たせるパンストやハイレグ着用作品も多い」と評している。

2013年にデビューし、初期は素人ものやナンパ系の企画作品が中心だった。2014年7月にはセガのゲーム『龍が如く』シリーズのセクシー女優人気投票にエントリーし、同年8月24日の生放送で結果が発表され、47,561票で30位となり『龍が如く0 誓いの場所』への出演権を獲得した。2024年9月からマドンナ専属女優となり、2025年8月には約1年ぶりに企画単体へ戻ったことをSNSで報告した。

## 人物

- 愛称は「みっぽ」。
- 趣味はゲームで、『バイオハザード』や『龍が如く』シリーズをよく遊ぶ。
- 好物は紅茶で、動物好き。
- 2020年からYouTubeチャンネル「通野未帆がヤルってよ! 仮」を開設している。
- 「売りがない」「永遠の素人」という自称は、デビュー10周年の関連記事でも引用されている。

## 作品の特徴

- 2013年のデビュー当初は素人もの、ナンパもの、企画ものが中心で、SODクリエイトなどの素人シリーズにも出演している。
- 細身で脚のラインが際立つ体型で、パンストやハイレグを扱った作品が多い。
- VR作品にも出演し、2017年のVR作品はAV OPEN 2017のVR-1グランプリにエントリーした。
- 2024年9月から2025年8月までマドンナ専属で、その後は企画単体に戻った。
- AVのほかデジタル写真集（LOVEPOPシリーズ、2021年『めぞん未ノ刻』）を発表し、テレビ番組、映画、ゲームにも出演している。
