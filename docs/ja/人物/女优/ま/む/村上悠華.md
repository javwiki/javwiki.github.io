# 村上悠華

日本のAV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

- **名前**: 村上悠華
- **読み**: むらかみ ゆか
- **英語名**: Yuka Murakami
- **生年月日**: 2003年1月30日
- **出身地**: 日本 東京都
- **所属事務所**: LIGHT
- **主要メーカー**: S1 NO.1 STYLE
- **活動期間**: 2023年〜

## プロフィール

村上悠華は2003年1月30日生まれ、東京都出身の日本のAV女優。LIGHT所属。2023年9月12日にS1 NO.1 STYLE専属女優としてAVデビューし、同月22日にはテレビ東京『月ともぐら』に出演してテレビ初出演を果たした。デビュー作の初脱ぎシーンは、彼女が堂々としすぎていたために全カットされ、のちのインタビューで自分のせいであると述べている。

2023年12月には、デビュー作『新人NO.1 STYLE 村上悠華 AVデビュー』が週FANZA動画フロアランキング5位、イメージビデオ『ALL NUDE 村上悠華』が週FANZA通販フロアランキングで初登場9位となった。2024年12月には翌年3月までの休業予定を公表したが、2025年6月には仕事に復帰した。休業中はコンビニエンスストアでアルバイトをしていた。

2025年は共演作『食べごろ姉妹のからだ。親戚の娘2人を預かることになった変態おじ』がFANZAの各ランキングに繰り返し登場し、2月の週榜9位、4月には3位へ上昇、5月26日週にはレンタルフロアで1位を獲得して2週連続で首位を維持、7月には動画フロアで2位まで戻した。同年8月から撮影に復帰し（当該作品は2026年2月発売）、10月には石原希望とともに台湾を訪問、配信プラットフォーム「AV＋」の宣伝と『JKF』などの取材を受けた。

2026年2月23日週には2025年発売の『食べごろ姉妹のからだ〜』が週FANZA動画フロアランキングで再び1位となり、3月2日週は3位に下がったもののランキング入りを維持した。同年9月8日から13日まで、東京・渋谷のギャラリールデコでデビュー3周年写真展「YUKA'S MANUAL」（撮影：舞山秀一）を開催し、期間中は本人が在廊した。

## 人物

- 公式ニックネームは「ゆっか」で、本人考案。私生活で使われている本名由来のニックネームにも「っ」がつくため、それに合わせた。
- 芸名は三上悠亜と村上宗隆から。三上からは「上」「悠」の字を、村上からは姓を取り、「華」は当て字である。
- デビュー前はバスガイドで、高卒で入社し約2年半勤務した。転身のきっかけは三上悠亜への憧れ。事務所面接とデビュー作の撮影は前職在籍中に有休を消化して臨んだ。
- 元々旅行好きで、ある企業の会社説明会で見かけたバスガイドに「この人みたいになりたい」と思ったことが入行のきっかけ。2026年には、退職の原因が安月給に加え、1日2時間ほどの睡眠不足が慢性化した疲弊だったと明かしている。
- 高校時代は弓道部に所属。初体験は中学2年生の時で、相手は高校1年生の彼氏だった。
- 休業中はコンビニでアルバイトをし、上手くできず外国人店員に叱られたが、この経験が本業へのやる気を増した。
- 膣が後ろ側かつ下付きのためグラインド騎乗位を苦手とし（ペニスが外れてしまう）、自分で動く場合は杭打ち式。好きな体位はバック。AV女優になって上達した技術に手コキ、乳首舐め、フェラの3点を挙げている。

## 作品の特徴

- 2023年9月からS1 NO.1 STYLE専属で、デビュー作は「新人NO.1 STYLE」シリーズ。
- 初期は単独のデビュー作とイメージビデオが中心で、2024年以降は共演作やドラマ系が増えている。
- 2025年の共演作『食べごろ姉妹のからだ。親戚の娘2人を預かることになった変態おじ』はFANZAの動画フロアとレンタルフロアで繰り返し上位に入り、2026年には週榜1位に戻った。
- AVのほか写真集『YUKA'S MANUAL』、複数のデジタル写真集、2025年と2027年のカレンダーを発売し、『月ともぐら』や『ゴッドタン』系のバラエティ、FANZA TVの番組にも出演している。
- 2026年にはデビュー3周年写真展を開催し、活動が撮影やイベントにも広がっていることを示した。
