# 森日向子

日本の成人映像出演者。以下のデビュー情報は記載した出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 森日向子
- **英語名**: Hinako Mori
- **生年月日（公式資料）**: 2000-09-09
- **身長（公式資料）**: 166 cm

## プロフィール

森日向子は2000年9月9日生まれ、三重県出身、NAXプロモーション所属。2020年6月、SODクリエイトの「KMHR（キミホレ）」レーベルから専属女優としてデビューし、3作品に出演した後は企画単体女優として活動している。同月、講談社「ミスiD2021」のセミファイナリストに選出された。2021年4月に写真集『僕のわがまま』を刊行し、2024年9月にFANZA／HHHグループ「トリプルハッピーキャンペーン2024」のキャンペーンガールに就任、12月公開の映画『みゆきの結婚』で初主演を務めた。2025年4月からはMOODYZ内のレーベル「きれいなお姉さんは好きですか」の専属女優となる。別名「朝比奈えみり」名義のイメージビデオにも出演している。

## 作品の特徴

- デビュー作はSODクリエイト「KMHR」レーベルの専属作品で、3作品の後に企画単体へ移行。以降は複数メーカーの作品や総集編、VR企画にも出演する。
- 作品の設定には地雷系女子（『僕の可愛い彼女は地雷系女子◆□』）、唾液とキス、寸止めの射精コントロールなどがあり、2025年からはMOODYZの「きれいなお姉さんは好きですか」レーベルに出演。
- 「朝比奈えみり」名義では『ミス○教大学でモデル衝撃のデビュー』（2021-01-29）などのイメージビデオに出演。
- 2024年4月から7月までFANZA動画フロアの月間AV女優ランキングで連続してトップ10入り（5位、9位、4位、7位）。
