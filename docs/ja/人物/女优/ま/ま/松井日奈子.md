# 松井日奈子

## プロフィール

松井日奈子は2003年12月30日生まれの日本の元AV女優。身長146cmで、引退時の所属はアトラクティブだった。2021年頃から秋田県大仙市でローカルタレントとして活動し、「もっと全国で勝負がしたい」との思いからセクシー女優への転向を決意。2024年5月、kawaiiの『「私だってヒロインになりたい」 東北でローカルタレントしていた本物芸能人 いっっっっちばん自信のあるセックスで勝負したくて上京デビュー 松井日奈子』でデビューした。

同年8月6日発売作品をもってkawaii専属女優を卒業し、以降は企画単体女優として、無邪気な学生から妖艶な人妻まで幅広く演じている。2025年にはテレビ東京『ゴッドタン』への出演で注目を浴びた。ローカルタレント時代からメディア出演はしており、AV女優になった後も活動の幅を広げたいと述べている。

2025年11月3日週には、出演した2025年3月発売の『「寝起きでSEXしよ？」すっぴんだってカワイイ彼女を目覚ましイタズラ生中出しww』（ハラスメント）が再注目されて週FANZA動画フロアランキング7位に入り、12月8日週にも同作が7位まで再浮上した。2026年1月26日付でAV女優としての活動を終了し、3月16日にシティヘブン写メ日記で引退を報告、「これからはAV女優 松井日奈子ではなく新しい自分として活動していく」と述べた。約半年分の作品ストックがあるため、それらはその後も順次発売され、4月6日週には出演作『ホイホイキュート＃13素人ホイホイZ』が3位まで浮上した。

## 人物

- 趣味は料理とジム通い、オナニー。特技は料理、民謡、書道。民謡では秋田県大仙市「ドンパン節」を盛り上げるドンパン娘としての活動歴を持つ。
- テレビ番組で共演した劇団ひとりは「めちゃめちゃいいね。エロ面白いを極めてるかも」と評し、ウェブサイトLOVEPOPの担当者は「場を明るくする才能の持ち主」と人物評を記している。
- スタッフからは1度目に「本当にエロ好きだよね」と言われ、2度目には「もうエロじゃない!」と賛辞を贈られた。
- ライターのもちづき千代子は『ゴッドタン』での松井を見て「どう考えてもタダ者ではない」と感じ、インタビューを申し込んだ。
- AVライターの芝田カズは、デビューから早い段階での「舌を出して白目をむき、『グガァァァァ』と叫ぶアヘ顔＆オホ声のフルコンボ」に業界が騒然となったと評した。
- 身長146cmと小柄だが、身体のどこにこんなに入っていたのかと言われるほどの潮吹きが特技で、『週刊プレイボーイ』誌上では「潮吹きチャンピオン」と称された。芝田カズは、きれいな一直線のビーム潮から土砂降りのようなハメ潮まで所構わず吹き荒らすと解説している。
- ライターのさおりは「最長で30秒間吹き続けた」「飛距離も4メートルくらいある」と記録を解説し、撮影ではカメラに向かって潮吹きし破壊したこともあるという。「30秒4mビーム潮」は本人も代名詞的に用いている。
- 松井自身はおしっこと潮の区別がつかず、デビュー前から膀胱がたまった状態での性交を好み、これを「尿意ムラムラ」と呼んでいる。撮影では水分補給をまめにし、場合によっては5分おきに排尿する。
- AV好きは父のコレクションを小学2年生頃から見ていた影響。AV女優になったことは母親に伝えているが、父親が知っているかは直接聞いていない。
- 初体験は17歳で場所は車の中。見られてしまうかもしれない興奮からカーセックスにハマり、エンジン音や車用芳香剤でもムラムラするようになった。性癖はMだが、Sを自認する男性には逆に責めたくなるといい、作品内でも両面を演じることが多い。

## 作品の特徴

- 2024年5月にkawaii専属でデビュー。デビュー作は「東北のローカルタレントが上京」という人物設定で、「本物芸能人」と自信のあるセックスを打ち出した。
- 同年8月6日発売作品でkawaii専属を卒業し、企画単体へ転身。学生から人妻まで幅広い役柄を演じている。
- 潮吹きを売りにした作品が多く、本人も「30秒4mビーム潮」を代名詞として用いている。
- AVのほか「浅水紗香」名義でイメージビデオ『浅水紗香 侵せよ聖域』（2024年10月30日、スパイスビジュアル）に出演した。
- 2025年はバラエティ『ゴッドタン』で注目を集め、2026年の引退後も約半年分の作品ストックが順次発売されている。
