# 皆月ひかる

日本の成人映像出演者。

## 基本情報

- **名前**: 皆月ひかる
- **英語名**: Hikaru Minazuki
- **生年月日（公式・出版資料）**: 2000-01-11
- **身長（公式・出版資料）**: 148 cm

## プロフィール

皆月ひかるは2000年1月11日生まれ、秋田県出身、バンビプロモーション所属。2018年7月、DEEP'Sの専属素人娘「ひかる」としてAVデビューした。前月発売の作品にも出演しており、日本語版Wikipediaはその出演を正式なデビューのきっかけとしている。2018年9月に専属を離れ、企画単体女優として活動。2019年11月に体調を崩して休業し、2020年3月24日に活動再開を発表した。2022年12月にはDMM GAMES「クリムゾン妖魔大戦」新キャラクター声優公開オーディションにエントリーし、2024年以降、出演作がFANZAの週間ランキングで複数回トップ10に入っている。

## 作品の特徴

- デビュー作はDEEP'Sの専属素人娘シリーズで、パッケージには「ひかる」と記され、ECサイトなどでは「皆月ひかる」も使われた。イメージビデオにも複数の名義で出演している。
- 企画単体移行後の作品には女子校生、制服、NTR、媚薬、つるぺたなどの設定が多く、VR作品や総集編もある。
- 148cmの小柄な体型と音楽経験が設定に生かされることが多く、DEEP'S専属時は現役音大生として紹介され、デビュー作ではトランペットを演奏した。
- 2024年から2026年にかけて、『オジサンに没頭する発情コスプレイヤー…』『女子校生孕ませ民宿…』『つるぺた女子の男水着チャレンジ…』などの出演作がFANZA週間ランキングのトップ10に入り、『つるぺた女子…』は動画フロア1位を記録した。
