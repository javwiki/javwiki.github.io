# 水川スミレ

日本の元AV女優。以下の資料は日本語版Wikipediaと記載の出典に基づき、ランキングを人物資料の代わりには用いない。

## 基本情報

- **名前**: 水川スミレ
- **読み**: みずかわ すみれ
- **英語名**: Sumire Mizukawa
- **別名**: 水稀みり（旧名）
- **生年月日**: 1994年2月3日
- **出身地**: 日本 大阪府堺市
- **所属事務所**: LINX
- **活動期間**: 2016年〜2026年

## プロフィール

水川スミレは1994年2月3日生まれ、大阪府堺出身の日本のAV女優。LINX所属。ヤンキーとお笑いに囲まれて育ち、17歳で実家を出た。大阪ミナミでキャバクラ嬢を経験した後、2016年4月、プレステージ専属女優「水稀みり」としてAVデビューした。この頃のプロフィールは1996年5月5日生まれ、京都府出身とされていた。

2017年11月15日、彼女は「水喜れい」名義で新たにTwitterを開始し、活動の幅を広げるため事務所を移して改名したことを報告した。当初はロックオンに所属し、後にカロスエンターテインメントへ移った。2018年1月10日には「水川スミレ」名義でTwitterを開始し、LINX所属となって改名したことを報告した。この版のプロフィールは1995年2月3日生まれ、大阪府出身である。同年からは海外でも活動している。

2020年8月からPodcast番組「MI SO HORNY」を開始し、全体ランキングで100位以内に入ったほか、性教育コンテンツとして文春オンラインに取り上げられた。2021年からアメリカに在住し、SNSで知り合い数年前から遠距離恋愛をしていたアメリカ人男性と結婚した。しかし結婚後、相手が彼女の言う「史上最悪のサイコパス」な人物だったことが分かり、日本に逃げ帰ったが離婚はしていない。2023年11月、『Madonna電撃専属 真正痴女 水川スミレ 深く濃厚な接吻と寸止め中出しでM男クンを身も心もトロけさせる無限射精オーガズム』よりマドンナ専属女優となった。

2026年1月6日、台湾の自由時報が、日本国内の適正AV作品からの卒業と活動拠点の海外シフトを伝えた。3月9日には本人名義のXで引退作の撮影がポストされた。3月27日から29日にかけて台湾・メッセ桃園で行われた大人國成人展（ADULTOPIA）に登壇し、BEST POPULAR ACTRESS（XCITY最優秀人気女優賞）を受賞。7月8日、インスタグラムで結婚と引退を発表し、「Sorry…officially sold out.」「完売」と表現した。

## 人物

- 趣味はカラオケ。高校1年の春、中学生の時にSkypeで知り合った23歳の社会人男性と初体験した。
- 元キャバクラ嬢インフルエンサーのみゆうとは、AV女優になる前の10代後半からの親友で、彼女を「お姉さま」と呼んでいる。
- 仕事は両親公認で、父親はAbemaTV『給与明細』のインタビューに応じている。AVや性的なものに偏見のない家庭で、別のAV撮影で偶然父の営む店舗が使用されたこともある。
- ライターの芝田カズは、ほどよい筋肉質と53センチのくびれに目を奪われると評した。俳優の渋江譲二は、作品の7割が痴女ものであることに触れ、妖艶なルックスとエロさを論じた。
- 得意技は騎乗位。自身がイキやすいのは前後に動くグラインド式だが、ユーザーは上下に動く杭打ち式を好むため、作品内では概ねグラインド式で満足してから杭打ち式に移るという。渋江譲二は高速で振り続けるスタミナにも言及した。
- 芸名と公開プロフィールは何度も変わっており、生年は1994年と1995年の二説があり、デビュー時のプロフィールは1996年とされていた。

## 作品の特徴

- デビュー時はプレステージ専属、2023年11月からはマドンナ専属。単体作、共演作のほか、VR作品や配信作にも出演している。
- 痴女ものの比率が高く、渋江譲二は約7割と見積もっている。
- 2020年10月26日に写真集『甘い密と甘い罠』を発表し、2017年と2018年のカレンダー、複数のオリジナルグッズもリリースした。
- 2024年11月発売のアンソロジー『MOON FORCE CHEERS ぱこぱこしろうとコレクション。 ベリーベストオブベスツッ！』が2026年1月5日週にFANZA動画フロア1位となった。
- AVのほかテレビバラエティ、AbemaTVの番組、op映画2本に出演し、Podcast「MI SO HORNY」のMCも務めた。
