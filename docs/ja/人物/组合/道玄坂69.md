# 道玄坂69

## 概要

道玄坂69は日本のアイドルグループで、セクシー女優もメンバーに含まれる。非公式のメンバー紹介ページによると、一期生は2019年6月6日にBSスカパーの番組『田村淳の地上波ではダメ！絶対！』で発表された。
