# シリーズ

シリーズ（Series）とは、AV メーカーが展開する固定タイトルのシリーズ作品で、通常は統一された命名、ジャケットの作風、内容のテーマを持つ。同一シリーズには複数の作品があり、出演女優が異なることもある。

## シリーズとメーカーの関係

シリーズは通常、いずれかのメーカーやレーベルに属しているが、別のメーカーが似た名前のシリーズを持つこともある。シリーズ名はメーカー名ではない。
