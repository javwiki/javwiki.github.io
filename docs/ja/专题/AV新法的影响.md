# AV新法の影響

通称「AV新法」であるAV出演被害防止・救済法は、**2022年6月23日**に施行された。出演契約、撮影、公表のルールを変え、仕事の機会、制作費、産業の変化をめぐる議論も生んだ。影響を評価する際は、法律が直接定める変化、経営上の仕組みから推測される結果、データで裏付けられた実態を区別する必要がある。[内閣府：施行日と制度の概要](https://www.gender.go.jp/magazine/backnumber/2022/520_r4_6_24.pdf)

## 法律が変えた段階

| 段階 | 主な変更 | 業務の流れへの直接的な意味 |
| --- | --- | --- |
| 契約 | 契約書・説明書面等の交付と所定事項の説明 | 仕事内容や権利義務を事前に具体化する必要がある |
| 撮影 | 契約書等と説明書面等の両方の交付後、少なくとも1か月待つ | 新たに契約した人を直ちに撮影することはできない |
| 公表 | 全撮影終了後、少なくとも4か月待ち、公表前に映像確認の機会を設ける | 撮影終了と公表可能時点の間に法定の期間がある |
| 離脱と流通 | 法定の任意解除、条件を満たす場合の販売・配信停止請求 | 契約や撮影への同意が、離脱や救済の途を永久に失うことを意味しない |

これは現行制度の概略であり、解除期間は契約日によって異なる。全ての契約を「公表から2年以内に解除できる」と説明することはできない。[内閣府：法律のポイントと現在の解除期間](https://www.gender.go.jp/policy/no_violence/avjk/index.html) 時期別の期間と適用条件は[法律の項目](../资料/法律/AV出演被害防止・救済法.md)を参照。

## 出演者：行使できる選択肢と救済

内閣府の解説によれば、契約で定めた内容でも出演者は撮影を拒絶でき、そのことによる損害賠償責任を負わない。制作側は安全・衛生と拒絶の自由に配慮する必要がある。任意解除制度によって、離脱のために当初の強要を証明することが常に必要というわけでもなくなった。[内閣府：法律の解説](https://www.gender.go.jp/policy/no_violence/avjk/pdf/houritsu_gaiyou.pdf)

これは出演を選んだ人にも、もともと出演を望まなかった人にも意味を持ち得る。契約、現場への到着、撮影終了だけを「もう変えられない」理由にはできない。ただし、配信停止を請求する権利があっても、ネット上の全複製が自動的に消えるわけではない。権利、通知、プラットフォームの対応、侵害コピーの除去は別の段階である。

実効性は、本人が制度を知り、書面を入手し、支援にたどり着けるかにも左右される。解除請求をしただけで「悪意のある契約破棄」と決め付けることも、制度があるだけで出演強要がなくなったと考えることもできない。

## 制作側：日程、資金、リスクの配分

時間の規則から考えると、制作側は出演者、場所、発売予定をより早く調整する必要がある。当日の契約で代役を確保していた企画は、既に条件を満たす手配や撮影日の変更が必要になる。具体的な方法は契約と法律に照らして確認しなければならない。これは業務上の影響であり、業界全体の撮影停止を示す統計ではない。

費用を撮影時に払い、収入の多くを公表後に得る場合、待機期間は資金の回収までの時間を延ばし得る。影響の大きさは在庫、前払金、資金調達、支払契約で変わる。企画や出演者の選定が慎重になるという経営上の仮説は立てられるが、「新人が広く排除された」「全社の資金繰りが破綻した」とするには別のデータが必要である。

**公表までの待機期間は、出演料の法定支払猶予期間ではない。** 内閣府の解説は契約に報酬額と支払時期を明記するよう求める。4か月の公表制限を「法律上、女優は報酬を4か月待たなければならない」と言い換えることはできない。[内閣府：契約の報酬事項](https://www.gender.go.jp/policy/no_violence/avjk/pdf/houritsu_gaiyou.pdf)

## 仕事の減少：取材で語られたこと

集英社オンラインの**2022年12月18日**のインタビューで、男優しみけんは施行直後の仕事への支障を業界の準備不足と結び付けた。移行期に関する当事者の観察であり、数年後の業界全体を直接示すものではない。[集英社オンライン：しみけんへの取材](https://shueisha.online/articles/-/85032)

日刊SPA!の**2024年3月6日**の対談で、綾瀬麻衣子と佐々木あきは仕事の機会や急な代役出演の制限について語った。一部の出演者の職業経験であり、全出演者の所得調査ではない。[日刊SPA!：出演者の対談](https://nikkan-spa.jp/1981920)

「仕事の減少」は撮影件数、本人が得た仕事数、1件の報酬、年間所得に分けて見る必要がある。販売ページ数も新規撮影数とは異なり、総集編、再発売、同一内容の別版で変わり得る。定義がそろわなければ、少数の取材から業界全体の縮小率は求められない。

## 地下化、個人制作、海外就労をめぐる議論

同じSPA!の対談では、海外出稼ぎや別の撮影経路にも言及がある。これは出演者の伝聞や観察であり、調査すべきリスクを示すが、全ての仕事の移動が新法によるものとは証明していない。[日刊SPA!：仕事の移動に関する説明](https://nikkan-spa.jp/1981920)

因果関係を確認するには、誰がいつどの仕事を失い、実際に何へ移ったかを把握し、需要、プラットフォームの規則、債務、個人の選択なども検討する必要がある。「施行後に起きた」は「施行が原因で起きた」と同義ではない。海外活動も展示会や撮影の場合があり、売春と一括りにできない。

内閣府は個人制作も対象となり得ると示している。適用は法定の定義と具体的事実によって判断され、「同人」「個人撮影」は自動的な適用除外ではない。海外プラットフォームの利用だけでも適法性は証明されない。[内閣府：適用範囲の案内](https://www.gender.go.jp/policy/no_violence/avjk/index.html)

## 公的データから分かること

内閣府の**2025年10月**の会議資料によると、**2024年度末**までの施行後約2年9か月に、ワンストップ支援センターのAV出演被害相談は累計**500件**、同年度は**118件**だった。自治体からの相談報告であり、500件の有罪判決や配信停止成功を意味しない。[内閣府：相談・支援資料、2ページ目](https://www.gender.go.jp/kaigi/sonota/pdf/avjkkaigi_2510_09.pdf)

同会議の警察資料では、罰則施行日の**2022年7月12日**から**2024年12月末**までの新法違反検挙件数は**41件**とされる。検挙は有罪判決ではなく、相談件数で割って「処理成功率」を求めることもできない。[警察庁：取締りの状況](https://www.gender.go.jp/kaigi/sonota/pdf/avjkkaigi_2510_10.pdf)

これらは相談や取締りが実際に行われていることを示すが、新法がなかった場合との比較基準は提供しない。相談数は認知度、相談への意欲、被害の変化にも左右されるため、増減だけで成功・失敗は判断できない。

資料の不足も公的に記録されている。政府の**2025年11月18日**の答弁は、私人間の出演契約の締結や関連する取消しの状況を把握しておらず、その時点で質問者の求める調査を予定していないとした。その答弁の立場であり、政府が関連資料を一切集めていないという意味ではない。[衆議院：政府答弁書](https://www.shugiin.go.jp/internet/itdb_shitsumon.nsf/html/shitsumon/b219050.htm)

## 今後の調整をどう評価するか

規則の調整を評価するには、拒絶・解除が実行できるか、配信停止が迅速か、経験の異なる出演者の仕事と所得がどう変化したかを併せて見る必要がある。保護の効果と経営上の負担を共に議論しても、一方を他方の結論の代わりにはできない。

待機期間の短縮、例外の設定、解除制度の変更を主張する場合は、対象者、本人への圧力を防ぐ方法、被害リスクの検証方法を明確にする必要がある。現状維持の主張も、仕事の実態や支援へのアクセスに答える必要がある。改正案、提言、施行済みの条文は区別して確認すべきである。

資料確認日の**2026年11月10日**時点で、本稿の出典は制度と一部実務の変化を確認できるが、業界全体の所得、海外出稼ぎ、被害発生率に対する新法の純粋な効果を数量化するには足りない。
