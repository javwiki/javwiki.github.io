# 美谷朱里「引退させられた」騒動

美谷朱里（現名・美谷朱音）は2024年7月、2025年7月19日をもってAV女優を引退すると発表した。その後、中国語圏のネット上で「本人の意思ではなく、8社のプロダクションに共同で封殺され、共演を切られたから引退させられた」という説が広がった。この説は広く流通しているが、「引退させられた」は結論であり、確認された事実ではない。本稿は年表、説の出所、本人の発言、確認できる証拠を分け、何が言えて何が言えないかを整理する。

## 年表：美谷朱里から美谷朱音へ

| 時期 | 出来事 | 性質 |
| --- | --- | --- |
| 2017年7月 | 美谷朱里名義でAVデビュー | 公開された経歴 |
| 2023年1月13日 | Allproへの移籍を発表 | 本人のX |
| 2023年11月17日 | LiStarへ移籍、美谷朱音に改名 | 本人のX |
| 2024年7月5日 | 2025年7月19日の引退を発表 | 本人のX |
| 2025年4月22日 | 引退作の撮影完了 | 本人のX |
| 2025年7月19日 | AV女優を引退 | 公開報道 |
| 2025年11月24日 | 63ANGELのダンサーとしてデビュー | 63ANGELの発表 |

年表を見ると、突然消えたわけではない。約1年前に発表し、引退作を撮り、別れの場を設け、舞台へ移っている。この流れは計画的なキャリア転換に見える。ただし、これは「引退が前もって決められていた」ことしか示さず、本人が圧力を受けていなかったことの証明にはならない。圧力の下で決めた「計画」もあり得る。

## 「引退させられた」説はどこから来たのか

中国語圏の長文はこう主張する。彼女の所属するAllproとCRUSE GROUPが引き抜きをめぐって衝突し、8社のプロダクションがAllproを共同で封殺、所属女優との共演を拒否した。美谷の共演作が影響を受け、仕事が制限されたため、引退するしかなかった、と。記事は他の女優の移籍や第三者の調停にも触れている。[網易号：美谷朱音引退と8社封殺](https://www.163.com/dy/article/J6JIB0TQ0553XLZG.html)

これらの説は主に中国語圏のセルフメディア（自媒体）と台湾のAV評論家の伝聞に由来する。本稿では、日本主流メディアの対応報道も、プロダクション、業界団体、本人の公開確認も見つけられなかった。「8社」という数字には検証可能な名簿も文書もなく、封鎖の範囲、時期、実行方法も公開されていない。

注目すべきは、そのセルフメディアの記事自体が、封鎖が引退の主因かは分からないと認めていることだ。記事は、彼女が引退を考える段階に来ていたのであり、封鎖は引き金の一つかもしれない、という見方に傾いている。つまり、説の広め手でさえ、「引退させられた」を確定事実とはしていない。

## 本人は何と言っているか

2025年12月、日刊SPA!のインタビューで、彼女は引退理由を語っている。自分にはいわゆる「営業用のキャラクター」がなく、素の自分でできるところまでやった、天井に到達した感覚がある、という。引退日の約1年前に宣言し、ファンにきちんと別れを告げられたことを、幕の引き方としてよかったと振り返っている。[日刊SPA!：美谷朱音が引退理由を語る](https://nikkan-spa.jp/2132401)

2025年4月、彼女はXで引退作の撮影が終わったと述べ、「AV女優になれてよかった、しっかりとした終わりが作れて幸せ」と書いた。[美谷朱音X：引退作の撮影完了](https://x.com/akari_mitani17/status/1914549700746993997)

これは本人の公開発言であり、内幕の全てではない。しかし少なくとも、「させられた」は本人が示した理由ではない。プライバシー、契約、業界関係のために全てを話さないことはあり得るが、沈黙や別の説明を「引退させられた」に置き換えるのは、読み手が因果を補っていることになる。

## 何が確認でき、何が確認できないか

確認できること：彼女が実際に2回移籍したこと（CRUSE GROUP → Allpro → LiStar）と改名。2024年7月に引退を発表し、2025年7月に引退したこと。63ANGELに移ったこと。業界に移籍、引き抜き、共演制限といった競争手段が存在すること。

確認できないこと：8社の名簿と共同行動。封殺が実在したか。封殺が彼女個人に向けられたか。引退が封殺によって引き起こされたか。彼女が圧力を受けたか。プロダクション同士の衝突の詳細。公開された契約書、団体文書、警察・裁判記録、プロダクションの声明はなく、「8社封殺」の完全な物語を支える資料はない。「8」という数字は業界伝聞の単純化かもしれない。

仮に封鎖が存在しても、それは「引退させられた」と同義ではない。彼女は当時、本中とDas!のダブル専属であり、単体作品と専属契約は続けられた。共演制限は一部の仕事に影響しても、引退を単独で説明するには足りない。「共演が減った」を「仕事ができなくなった」に飛躍させるには、多くの段階が抜けている。

## なぜ「引退させられた」物語が魅力的なのか

人気女優が業界の権力闘争の犠牲になった、という単純な因果物語を提供するからだ。「天井に到達した」よりドラマチックで、広がりやすい。

ファンの「暗黒業界」への想像にも合う。プロダクション間の移籍、引き抜き、共演制限は実際にあり得るが、内部は不透明で、伝聞が空白を埋めやすい。セルフメディアにはアクセス稼ぎの動機があり、複雑な衝突を「8社対1社」に、個人の選択を「させられた」に圧縮するのが最も拡散しやすい。

これは説が必ず偽という意味ではない。ドラマ性を証拠にしてはいけない、という意味である。話が整いすぎているほど、出所を確認する必要がある。

## 業界背景：移籍、引き抜き、共演制限

AV女優とプロダクションの契約、専属と企画単体の働き方、共演作品のキャスティングは、プロダクション同士の関係に影響され得る。移籍は珍しくなく、引き抜き、共演拒否、イベント制限といった手段もあり得る。

ただし、その効果は女優の層、契約の種類、メーカーとの関係によって異なる。ダブル専属で単体作品が中心の女優にとって、共演制限は一部の作品やイベントに影響しても、収入の全てを断つとは限らない。公開資料に「8社封鎖」の業界ルールや名簿はなく、個別の伝聞を業界全体の仕組みとみなすことはできない。

より合理的な問いは、制限が実在するなら、どの仕事が、いつまで、誰によって制限され、彼女が会社やメーカーを変えることで回避できたのか、である。これらの公開回答がない以上、「引退させられた」という結論は宙に浮いたままになる。

## 事件のその後

彼女は予定通り引退作を完成させ、2025年7月19日に引退。2025年11月24日、63ANGELのダンサーとしてデビューした。2025年12月の取材では、AV時代の誕生日設定を本来の日に戻したことも明かしている。引退は「消失」ではなく、職業の転換であり、舞台、イベント、ファンとの交流は続いている。[63ANGELの発表](https://x.com/burlesque_rpg/status/1980258976647598275)、[63ANGEL個人ページ](https://rokusanangel.jp/talent/akanemitani/)

もし封鎖で仕事ができなくなったのなら、なぜ引退作を完成させ、別れの場を設け、大手舞台に移れたのか。これは封鎖説の反証にはならないが、説にはより具体的な説明が求められる。

## よくある誤解

- **「8社封鎖は事実」** 現時点では中国語圏のセルフメディアと評論家の伝聞だけ。名簿、文書、日本主流メディアの確認はない。
- **「引退させられた」** 本人は天井に到達した上での選択と説明している。封鎖が要因の一つである可能性はあるが、因果は確認されていない。
- **「移籍＝封鎖」** 移籍は珍しくない。2回の移籍は不安定さを示すが、全面封鎖の証明ではない。
- **「本人が説明しない＝認めている」** プライバシー、契約、業界関係で話せない場合がある。沈黙は確認ではない。
- **「セルフメディアの長文＝証拠」** 手がかりにはなるが、一次資料の代わりにはならない。契約、発表、本人、検証可能な報道が必要である。
- **「引退＝消失」** 彼女は63ANGELに移り、舞台で活動している。
- **「ランキングが高い＝封鎖されていない」** ランキングは残存人気と作品販売を測るもので、共演機会、イベント依頼、業界関係を測るものではない。

## 資料から言えること

本稿で確認できるのは、彼女の経歴、2回の移籍と改名、引退発表の日付、引退作の完成、63ANGELデビュー、本人による引退理由の説明である。中国語圏に「8社封鎖が引退を招いた」という説があり、それが主にセルフメディアと評論家の伝聞に由来することも確認できる。

確認できないのは、8社の具体的な名簿と共同行動、封鎖の実在、封鎖が彼女個人に向けられたか、引退が封鎖によって引き起こされたか、彼女が圧力を受けたか、プロダクション衝突の詳細である。公開契約書、団体文書、警察・裁判記録、プロダクション声明はない。

資料の偏りも明らかである。セルフメディアにはアクセス稼ぎの動機があり、ファンには「暗黒業界」の物語への需要があり、本人の公開発言は包装されている可能性があり、プロダクションには内部契約を公開する義務がない。「見えた伝聞」を「確認された事件」とみなすと、セルフメディアの信頼性を過大評価し、当事者の主体性を過小評価することになる。

資料確認日**2026年11月17日**の時点で、日本主流メディアによる「8社封鎖」の確認報道も、本人やプロダクションによる「8社封鎖」についての公開説明も見つかっていない。したがって、「引退させられた」は検証待ちの説であり、事実として書くことはできない。
