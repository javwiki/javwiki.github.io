# 自殺が報じられたAV女優

本特集は、自殺による死去が公開メディアで報じられた日本のAV女優の事例を、出典が裏づける範囲とともに整理する。**メディアの報道、正式な調査結果、死因非公表は、それぞれ異なる証拠の状態である。**以下は出典を確認できる一部の事例であり、網羅的な一覧でも、死因の独自鑑定でもない。

表の日付は出典が記す死亡時期である。あいだ飛鳥についての2019年6月24日は記事の公開日であり、死亡日として扱えない。出典で言及された恋愛、収入、心理状態も、立証された自殺の原因としてそのまま扱うことはできない。

## 自殺の一覧に含めるべきでない場合

訃報だけでは自殺の証拠にならない。病死、事故、死因非公表、見解が分かれる事件はそれぞれ区別する必要がある。更新停止、引退、追悼文、ネット上の噂だけで、死亡や自殺を認定することはできない。

例えば、[紅音ほたる](../人物/女优/か/く/红音萤.md)は2016年8月15日に亡くなった。[J-CAST、2016年8月29日](https://www.j-cast.com/2016/08/29276365.html?p=all)は所属事務所代表の説明として、自殺や事件性はなく、喘息の急性発作が疑われるものの、当時は死因未確定だったと伝えている。そのため、自殺による死去の事例には含められない。

## 資料を読む際の留意点

- **個別事例から業界の自殺率は算出できない。**本ページには全従事者を対象とする統計、観察期間、比較対象がなく、AV女優の自殺率が他の職業より高いと判断する根拠にはならない。
- **死因と動機を区別する。**報道、親しい人の回想、ネット上の推測は医療診断や調査結果に代わるものではなく、職業だけを理由に死をAVの仕事に帰することもできない。
- **故人と遺族を尊重する。**自殺の方法、現場画像、未確認の私的関係に関する非難は掲載しない。追記には追跡可能な出典を添え、出典の限定的な表現を維持する。
