# メーカー概要

会社、ブランド、販売プラットフォームは異なる記録対象である。ブランド公式サイトは作品目録や名称を確認できるが、それだけで資本関係、設立年、出演者の現行専属契約を証明することはできない。

## 会社資料

WILL の公式サイトは現法人の設立日を2016年7月13日と記載する。北都・CA の沿革は歴史資料で別途記録し、ブランドの歴史を現法人の年齢と同一視しない。 [WILL](https://will-hp.jp/company/)

SOD の会社情報は Soft On Demand（1995年11月設立）と SOD Create（1999年3月設立）を別に掲載する。前者の販売業務と後者の制作業務を区別する。 [SOD](https://corporate.sod.co.jp/about_us/info/)

Prestige の企業採用ページは有限会社プレステージの設立を2002年5月と記載する。各ブランドとの関係には具体的な発売記録が必要である。 [Prestige](https://arwrk.net/recruit/prestige-av/)
