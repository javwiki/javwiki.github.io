# 制作会社とグループの関係

作品のパッケージにある「メーカー」名は、法人、社内制作ブランド、販売提携先のいずれかを示す場合がある。会社の歴史を読む際にはまずこの階層を区別し、同じプラットフォームで販売される作品を一つの制作グループにまとめないことが必要である。

## 歴史的な変化の読み方

北都、CA、WILLには事業承継の関係があるが、CAの吸収合併と現法人の設立は別の出来事である。2017年の売却報道からも、かつてDMMと同じグループだったことをもって現在も「DMM子会社」と記載することはできない。[WILLの沿革](../产业/制作公司/WILL.md)

SODでは制作と販売を分業している。1995年設立のソフト・オン・デマンドと1999年設立のSODクリエイトが、販売物流と企画制作をそれぞれ担う。SODをすべて「SODクリエイト」と表記すると、グループと制作会社、販売会社を混同してしまう。[SODの沿革](../产业/制作公司/SOD.md)

## 配信プラットフォームと制作グループ

FANZAは成人向け事業のプラットフォームブランドである。DMMは2018年の公式発表で事業承継とブランド変更を説明している。これらは制作メーカーの買収、合併、持株関係とは別々に記録する必要がある。[DMM公式発表](https://prtimes.jp/main/html/rd/p/000003114.000002581.html)

会社間の関係を読む際は、資料が**出資・買収、ブランド運営、販売代理、配信での取り扱い**のどれを示すか確認する。一つの作品でも、制作ブランド、発売法人、複数の販売プラットフォームが関わりうる。女優の専属メーカーと所属する[プロダクション](../产业/经纪公司/index.md)も異なる関係である。
