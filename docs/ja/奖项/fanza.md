# FANZAアダルトアワード

FANZAアダルトアワードは、日本の電子商取引サイトFANZA（旧DMM.R18）が主催する毎年恒例のAV賞であり、日本AV業界でもっとも重要な賞の一つである。2014年に開始され、2019年にDMMからFANZAへ名称が変更された。**2020年以降は諸事情により開催されていない**。

名称の変遷：
- 2014年：DMMアダルトアワード
- 2015-2018年：DMM.R18アダルトアワード
- 2019年：FANZAアダルトアワード
- 2020年〜現在：未開催
