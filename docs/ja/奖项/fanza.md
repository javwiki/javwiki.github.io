# 安城 アダルトアワード

PANZA 大人賞は、日本電子商取引のウェブサイト、PANZA(旧DMM)です。 ) R18(R18) 日本AV業界において最も重要な賞の一つである年次AV賞は、日本外務省主催のものです。 受賞は2014年に開催され、DMの「ファンザ」を2019年に改称しました。 ** 2020年以降、さらにリマインダーは様々な理由で作られていません**。

名称変更:
- 2014: DMM 少年たち
- 2015-2018年:DMM. R18、デュデ。
- 2019年: 銀座五重
- 2020年～日付:リマインダーなし
