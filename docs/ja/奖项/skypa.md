# スカパー!アダルト放送大賞

スカパー!アダルト放送大賞は、日本のSky PerfecTV!が主催する成人向け放送業界の賞である。2005年に開始され（初期の名称は「日本アダルト放送大賞」）、2008年に現在の名称へ変更された。2020年は感染症の流行により延期され、2022年からはEXガールズ選抜方式に変更された。2024年からは投票形式が廃止され、EXガールズ選抜に一本化された。

## 賞の部門

### 個人賞（2006-2020）

| 賞 | 説明 |
| --- | --- |
| 女優賞 | 年間最優秀AV女優 |
| 新人女優賞 | 年間最優秀新人女優 |
| 熟女女優賞 | 年間最優秀熟女系女優 |
| 最多出演女優賞 | 年間の出演作品数がもっとも多い女優 |
| メディア賞 | 各メディアが授与する賞 |
| スカパー!オンデマンドアダルト賞 | オンデマンド部門の最優秀女優 |

### EXガールズ（2022年〜現在）

2022年からはEXガールズ選抜方式に変更され、各チャンネルが女優を推薦し、最終的にMVA（Most Valuable Actress）などの称号が選出される。
