# 女子マネージャーは、僕達の性処理ペット。

## 概要

PRESTIGE（プレステージ）による超長寿の人気シリーズで、2014年11月に ABP-210（鈴村あいり）で始動した。基本コンセプトは、女子生徒が運動部のマネージャーを務めながら、男子部員の「性処理ペット」に堕ち、集団での性行為を強いられるというものである。

シリーズタイトルは「女子マネージャーは、僕達の性処理ペット。XXX 女優名」に統一され、1本につき女優1名が主演する。初期の第1弾の一部作品は「部活の先生は、僕達の性処理ペット。」というタイトルで本シリーズに含まれている。ブルマ、汗、羞恥のシーンがシリーズを象徴する要素である。

番号は 001 から 041 まで十数年にわたって発売が続き、ほかに BEST 総集編がある。2014年から2022年までは ABP 番号を、2022年からは ABW 番号を使用している。

## シリーズの特徴

- 中心的なプレイ：女子マネージャーが男子部員たちに集団で性処理される
- 全作品が単体作品で、1本につき女優1名が主演
- 象徴的な衣装：ブルマ、体操服、ジャージ
- 初期のサブタイトルに「部活の先生は、僕達の性処理ペット。」を含む
- ジャケットの様式は運動シーンと羞恥の表情で統一
- 収録時間：ABP は約170分、ABW は約195分
- 一部の作品には無修正の流出（クラック）版が存在
