# 淫魔に精子が空になるまで毎晩吸い尽くされる

## 概要

h.m.p によるサキュバス（淫魔）題材のシリーズで、2017年3月に HOMA-011 で始動した。中核となるコンセプトは、「淫魔（サキュバス）」が毎晩現れて男性の精液を吸い、精子が完全に空になるまで搾り尽くすというものである。ファンタジー設定を背景に、淫魔に扮した女優が男優から繰り返し射精を搾り取るテーマを強調している。

シリーズ名は「毎晩、淫魔に精液を空になるまで吸い尽くされる」の意で、h.m.p を代表するファンタジー色の強いシリーズの一つである。2020年には BEST 総集編 HOMA-066 が発売された。

## シリーズの特徴

- 中心的なプレイ：淫魔（サキュバス）役の女優が繰り返し射精を搾り取る
- 全作品が単体作品
- ファンタジーの世界観設定
- 一部作品には中国語字幕が付く
