# SOD（Soft On Demand）

SODはグループの通称、販売会社の略称、制作ブランドの表示に使われる。**ソフト・オン・デマンドとSODクリエイトは別法人**であり、設立時期を混同してはならない。[グループ会社情報](https://corporate.sod.co.jp/about_us/info/)

## 沿革

| 時期 | 出来事 | 資料 |
| --- | --- | --- |
| 1995年11月 | ソフト・オン・デマンド株式会社が設立。 | [会社情報](https://corporate.sod.co.jp/about_us/info/) |
| 1999年3月 | SODクリエイト株式会社が設立。公式サイトは1999年の分業を企画・制作の強化と説明し、販売・物流をソフト・オン・デマンドが担当したとしている。 | [会社情報](https://corporate.sod.co.jp/about_us/info/)、[販売事業の説明](https://corporate.sod.co.jp/business/softondemand/) |
| 2004年1月 | 映像編集を担うSODアートワークス株式会社が設立。 | [会社情報](https://corporate.sod.co.jp/about_us/info/) |
| 2022年10月 | バックオフィス業務を受託するSODコーポレート株式会社が設立。 | [会社情報](https://corporate.sod.co.jp/about_us/info/) |

## 会社と事業の関係

| 名称 | 区分 | 主な役割 |
| --- | --- | --- |
| Soft On Demand | 法人／流通・販売 | メーカーと小売店、配信事業者をつなぎ、販売と物流を担当。 |
| SOD Create | 法人／制作 | グループ内のコンテンツ企画、映像制作、ブランド開発。 |
| SOD Artworks | 法人／編集 | 映像編集。 |
| SOD Corporate | 法人／管理業務 | バックオフィス業務の受託。 |

会社と役割は[会社情報](https://corporate.sod.co.jp/about_us/info/)、[販売事業の説明](https://corporate.sod.co.jp/business/softondemand/)、[制作事業の説明](https://corporate.sod.co.jp/business/sodcreate/)に基づく。公式サイトに記載されたグループ会社と分業を示しており、各社の持株比率は推定していない。

## 「グループメーカー」の意味

公式の事業紹介では流通網に関して「グループメーカー」という表現を使う。会社情報に記載された法人とは区別して読む必要があり、SODが作品を販売することだけで完全子会社であるとは判断できない。[グループの事業紹介](https://corporate.sod.co.jp/business/)

資料確認日：2026-10-09。年月は現行のグループ公式サイトに基づく。旧資料の分社月や旧商号を扱う場合は、出来事の種類を明記し、法人設立日と混同しない。
