# メーカー

JAVメーカーは作品の制作・発行元であり、メーカーごとに内容の傾向、制作品質、市場での位置づけが異なる。主要メーカーを把握しておくと、作品のジャンルと品質の水準をすばやく判断する助けになる。

## 主要メーカー

## メーカーの分類

### 内容タイプ別

| タイプ | 代表メーカー | 特徴 |
| --- | --- | --- |
| 美少女系 | S1、IdeaPocket、kawaii* | 清純派、高品質な制作 |
| ドラマ性 | Attackers、Madonna | ストーリーが豊富、演技力が求められる |
| 企画系 | Moodyz、Prestige、SOD | ジャンルが多彩、アイデアが豊富 |
| 熟女系 | Madonna | 熟女、人妻もの |
| 中出し系 | 本中、ダスッ! | 中出しもの |
| スタイル系 | E-BODY | スタイル重視、巨乳系 |

### 制作品質別

| 等級 | 代表メーカー | 特徴 |
| --- | --- | --- |
| トップクラス | S1、IdeaPocket | 高品質な制作、トップクラスの陣容 |
| 一流 | Moodyz、Prestige、Attackers、FALENO | 安定した品質、豊富なジャンル |
| 二流 | その他のメーカー | ジャンルが多彩、手頃な価格 |

## メーカーと女優の関係

### 専属女優

一部の女優は特定のメーカーと専属契約を結び、そのメーカーでのみ作品をリリースする。専属女優は通常、より良いリソースとプロモーションを得られる。

### 非専属女優

多くの女優は非専属であり、複数のメーカーから作品をリリースできる。この場合、女優の作品の作風はより多様になる。
