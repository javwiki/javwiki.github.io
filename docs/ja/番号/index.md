# 品番システム

品番はJAV作品を識別する番号で、通常はメーカー、レーベル、または配信チャンネルによって設定される。百科事典の記事では「出演作品」の主キーとして品番を用い、検索・重複の排除・サイト間の照合をしやすくしている。

## 基本構造

一般的な品番は「英字の接頭辞＋数字の連番」で構成される：

```text
IPZ-901
```

このうち：

- `IPZ` は接頭辞で、通常はメーカー、レーベル、または販売シリーズに対応する。
- `901` は連番で、通常はそのシリーズ内での発売順を表す。
- 中央のハイフン `-` が一般的な表記だが、サイトによっては `IPZ901` と書かれることもある。

## 主な種類

| 種類 | 例 | 説明 |
| --- | --- | --- |
| 有修正品番 | IPZ-901、MIDE-123、SSIS-001 | 日本の主要メーカーが発売する有修正作品の番号。 |
| 無修正品番 | HEYZO-1168、CARIB-012516-001 | 無修正メーカーや海外配信サイトが使用する番号。 |
| FC2 番号 | FC2-PPV-1234567、FC2-1234567 | FC2 PPV作品の番号で、数字のIDを核とすることが多い。 |
| 総集編・ベスト | BEST、総集編、COMP 等 | 元のメーカーの番号を流用することもあれば、総集編専用の番号を用いることもある。 |
| 配信番号 | 041614_791、1PONDO-012516_001 | 日付やアンダースコア、プラットフォーム内部のIDを含むことがある。 |

## 接頭辞とメーカー

品番の接頭辞は、必ずしもメーカー名と一致するわけではない。むしろ、あるメーカーの下にあるレーベルやシリーズ、発売ラインを表すことのほうが多い。たとえば同じメーカーが複数の接頭辞を併用することもあれば、年代によって命名規則が変わることもある。

主な対応関係の例：

| 接頭辞 | 主な関連 |
| --- | --- |
| IPZ、IPX | IdeaPocket |
| SSIS、SSNI | S1 NO.1 STYLE |
| MIDE、MIDV | MOODYZ |
| ABP、ABW | Prestige |
| ATID、SHKD、RBD | Attackers |
| ADN | 本中、溜池ゴロー、Attackers などドラマ系レーベルのいずれにも現れることがあり、発売情報と合わせて判断する必要がある。 |
| JUL、JUQ | Madonna |
| WANZ | Wanz Factory |
| FSDSS | FALENO |
| HMN、HUNBL | 本中 |

## 登録ルール

百科事典に品番を登録する際は、次のルールに従うことを推奨する：

- 接頭辞は大文字で表記する。たとえば `IPZ-901` とし、`ipz-901` とは書かない。
- 公式サイトや主要な資料サイトで一般的なハイフンはそのまま残す。たとえば `IPZ-901`。
- FC2 作品は `FC2-PPV-数字` と表記するのを優先し、資料元が `FC2-数字` とのみ記載している場合はその表記をそのまま用いてよい。
- メーカーが判明しない場合は品番とタイトルのみを登録し、所属を無理に推測しない。
- 総集編作品は登録してよいが、タイトルにはできるだけ「総集編」「ベスト」または主な共演者を明記する。
- 同一作品に複数の表記がある場合は、主要な資料サイトまたはメーカー公式サイトの表記に従う。

## 検索のヒント

品番を検索する際は、次の表記を併せて試すとよい：

```text
IPZ-901
IPZ901
ipz 901
```

サイトによってはハイフンを省略したり、アンダースコアや日付番号を別の形式で表記したりする。検索しても見つからない作品は、まず接頭辞が同じレーベルのものかどうかを確認し、そのうえで女優名やタイトルのキーワード、発売日を組み合わせて横断的に検索するとよい。

## 注意事項

- 品番は作品を識別するだけで、出演者の身元やメーカーへの所属を意味するものではない。
- 同じ女優が複数のメーカーやレーベルに出演することがあるため、記事内の作品一覧は作品そのものを基準とする。
- 旧作や再発版、総集編版は素材を再利用しつつ新しい品番が付くことがあるため、登録の際に総集編を元の初出作品と取り違えないよう注意する。
- 無修正プラットフォームや海外プラットフォーム、FC2の番号規則は大きく異なるため、有修正メーカーの接頭辞の考え方をそのまま当てはめることはできない。
