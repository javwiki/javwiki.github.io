# エクシーJ

日本でのAV女子の象徴的なグループであるSEXY-Jが2014年12月7日、ストリートを左折。 2017年12月19日、最終公演の後には、グループが立ち向かう。チェストナット・リーリーのメンバーは、非公式に解散されていないというポストプレイノートでクリアにしました。 グループは、メンバーの**個人**と**グループ**によって支配される。ほとんどのグループは、1970年代と1980年代の人気曲の再生である。 白色の木材や香りを除き、アクセス時に残ったメンバーは数を割り当てました。
