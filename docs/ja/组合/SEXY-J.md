# SEXY-J

SEXY-JはAV女優で構成された日本のアイドルグループで、2014年12月7日にデビューした。2017年12月19日の最終公演を最後に活動休止となり、公演後の説明でメンバーの栗林里莉は正式な解散ではないと明言している。作品はメンバーの**ソロシングル**と**ユニットシングル**が中心で、多くは1970年代・1980年代の流行曲のカバーである。白木優子と一条綺美香を除き、加入時にメンバーへ番号が割り当てられた。
