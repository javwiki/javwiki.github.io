# BLACK DIAMOND

BLACK DIAMONDは日本のダンス＆ボーカルユニットで、2023年3月に現役4名と引退した1名のAV女優によって結成された。結成時のコンセプトは「女性のエンパワーメント」で、メンバーは各プロダクション所属またはすでに引退したAV女優が中心であり、アイドルと音楽グループの両方の性格を併せ持つ。

## 沿革

- **2023年3月**：グループを結成し、「女性のエンパワーメント」を掲げてデビュー。
- **2023年6月**：追加メンバーのオーディションを開始。
- **2024年2月**：ARISが自主脱退し、MARIAがサポートメンバーとして加入。
- **2024年11月**：MIIROが脱退。
- **2025年1月**：ACE1が音楽プロデューサーとして参加。公式が新メンバー当てクイズを実施し、3月20日に発表すると予告。
- **2025年3月**：MARYが脱退し、Marilynが新メンバーとして加入。
- **2025年5月**：RENAが加入。
- **2025年7月**：RIONA、RUNAが加入。
- **2025年11月**：RENA、ANRIが脱退。
