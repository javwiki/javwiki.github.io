# ブラックダイヤモンド

日本でのダンスと歌のグループであるBLACK DIAMOND(ブラック・ディアモンド)は、現在4名のアクティブメンバーで構成され、2023年3月にAV女性を退職しました。 グループは「女性」のエンパワーメントでターゲットを絞っており、そのメンバーは主にAVの女性で、仲介会社から引き離され、象徴的かつ音楽的な所属の両方でいます。
