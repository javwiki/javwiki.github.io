# 熟ザイル

熟ザイル（じゅくザイル）は、内田美奈子、加納綾子、一条綺美香、白木優子、松嶋友里恵の5人で構成された日本の美熟女ユニットである。2013年7月31日に31秒のプロモーション映像で「誕生」を公開しただけで、公開されている資料はこれのみであり、その後の活動や作品の記録はない。
