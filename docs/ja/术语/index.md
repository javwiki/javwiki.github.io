# 用語

本ページでは、AV女優百科でよく使われる専門用語と略称をまとめています。

## 女優関連

| 用語 | 説明 |
| --- | --- |
| 専属女優 | 特定のメーカーと専属契約を結び、そのメーカーのみで作品をリリースする女優 |
| 企画単体女優 | 専属契約を持たず、複数のメーカーで作品をリリースできる女優 |
| グラビアアイドル | グラビア写真集やイメージビデオに出演するモデル |
| 引退 | 女優がAVの活動を終えること |
| 活動休止 | 女優が活動を休止しているが、正式には引退していない状態 |
| 移籍 | 女優が所属事務所を移ること |
| 復帰 | 引退後に活動を再開すること |
| 新人 | デビューしたばかりの女優 |
| 専属移籍 | 専属女優が別のメーカーへ移ること |

## 作品関連

| 用語 | 説明 |
| --- | --- |
| 専属 | 女優が特定のメーカーのみで作品をリリースすること |
| 企画 | 作品のアイデアと内容の設計 |

| 共演 | 複数の女優が一緒に出演する作品 |
| 総集編 | まとめ・ベスト作品 |

| VR | バーチャルリアリティ作品 |

| 配信 | ネット配信によるデジタル販売 |
| レンタル | レンタル版 |
| セル | 販売版（買い切り） |
| デジタルモザイク | デジタルモザイク処理 |

| 企画 | 企画・立案 |

## メーカー関連

| 用語 | 説明 |
| --- | --- |
| メーカー | AV作品の制作と発売元 |
| 事務所 | 女優を管理するプロダクション、仲介機関 |
| レーベル | メーカー傘下のブランドやシリーズ |

## 番号関連

| 用語 | 説明 |
| --- | --- |
| 番号 | 作品を一意に識別する番号 |
| プレフィックス | 番号の英字部分。通常はメーカーやシリーズを表す |
| シリアル番号 | 番号の数字部分。発売順を表す |
