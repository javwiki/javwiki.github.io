# WILL（北都／CA）

WILLは日本の映像制作会社である。「北都」「CA」「Outvision」は事業の歴史を理解するうえで登場する名称だが、法人の沿革とブランドの歴史は区別する必要がある。現法人の公式サイトは設立日を **2016年7月13日** としている。[会社概要](https://will-hp.jp/company/)

## ブランドの関係

[S1](../厂牌/S1%20NO.1%20STYLE.md)、[MOODYZ](../厂牌/MOODYZ.md)、[IdeaPocket](../厂牌/IdeaPocket.md)、[Attackers](../厂牌/Attackers.md)はこの制作系統に属する。歴史資料の「内部メーカー」は社内制作ブランドの場合があり、それぞれが独立した法人であることを意味しない。[CAのメーカー資料（二次資料）](https://ja.wikipedia.org/wiki/CA_(アダルトビデオ))

歴史上のOutvisionには直営ブランドと販売を扱うメーカーの両方が含まれる。そのため、過去の「Outvisionグループ」という呼称を、ある時点の完全子会社一覧として扱うことはできない。

## DMM／FANZAとの関係

CAはかつてDMMとグループ関係にあったが、2017年の売却報道はその変化を示している。歴史的なつながり、作品の販売協力、現在の資本関係は別々に考える必要がある。[withnews](https://withnews.jp/article/f0170111002qq000000000000000W05s10701qq000014542A)

DMMの2018年7月19日付発表によると、成人向け事業は同年3月1日にデジタルコマースへ承継され、DMM.R18は8月1日にFANZAへ改称した。DMMはシステム提供を継続した。これはプラットフォーム事業の変更であり、制作メーカーの株式をFANZAが保有する証拠にはならない。[DMM公式発表](https://prtimes.jp/main/html/rd/p/000003114.000002581.html)

## 資料の範囲

資料確認日：2026-10-09。法人の設立日は公式サイトに基づき、初期のブランド史と合併月は二次資料と明記した歴史資料による。公開資料から現在の資本構成全体を確認できないため、旧称から現在の支配関係を推定していない。
