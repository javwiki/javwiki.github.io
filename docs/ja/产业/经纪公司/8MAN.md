# SO MODEL AGENT（旧称 8MAN）

So Model Agency は当サイトでは本記事に対応する。公式サイトの名称は **SO MODEL AGENT**（トップページでは SO MODELAGENT とも表記）。

## 基本情報

- **現名称**: SO MODEL AGENT（ソウ モデルエージェント）
- **旧名称**: 8MAN（エイトマン）
- **創業**: 公式サイトによると、2006年に大阪で創業
- **所在地**: 大阪本社は大阪市中央区南船場、東京支社は東京都千代田区神田神保町
- **業務**: AV女優、モデル、タレント、グラビアアイドルのマネジメントおよびテレビ、映画、雑誌などでの活動支援
- **協会**: 日本プロダクション協会（JPG）会員
- **公式サイト**: <https://so-agent.jp/>
- **旧サイト**: <https://www.8man.jp/> は現在上記公式サイトへ転送される
