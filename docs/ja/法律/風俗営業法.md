# 風俗営業法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 風俗営業等の規制及び業務の適正化等に関する法律 |
| 通称 | 風俗営業法、風営法 |
| 法令番号 | 昭和23年法律第122号 |
| 施行 | 1948年7月1日 |
| 所管 | 警察庁、厚生労働省 |

## 概要

風俗営業法は、AVの制作・販売に係る許可制度、営業所の制限、広告の規制など、日本の風俗営業に関する行為を規律する法律である。

## 主な内容

### 許可制

- AVの制作・販売を行うには、地方公安委員会の許可が必要である
- 一定の設備・場所の基準を満たす必要がある
- 許可は毎年更新する

### 営業の制限

- 営業時間の制限
- 営業所の制限
- 広告出稿の制限

### 広告の規制

- 誇大広告・虚偽広告を禁止する
- 必要な情報を表示する必要がある
- 未成年者への宣伝を禁止する

## AV業界との関連

AVの制作・販売は風俗営業の範疇に属し、同法の許可、営業、広告などの規律を守る必要がある。
