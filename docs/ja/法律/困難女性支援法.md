# 困難女性支援法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 困難な問題を抱える女性への支援に関する法律 |
| 通称 | 困難女性支援法 |
| 法令番号 | 令和3年法律第46号 |
| 施行 | 2021年10月1日 |
| 所管 | 厚生労働省 |

## 概要

同法は、さまざまな困難を抱える女性に対し、経済的援助、就労支援、心理的ケア、法的援助などを含む総合的な支援を提供するものである。AV出演者は、出演歴によって社会的な関係が損なわれたり、精神的健康に問題を抱えたりした場合に、同法によって支援を受けられる。

## 主な内容

### 支援の対象

- 暴力、虐待、貧困などの困難を抱える女性
- 保護と支援を必要とする女性
- AV出演後に社会的差別やネット上の誹謗中傷を受けた女性も含む

### 支援措置

- 経済的援助
- 就労支援
- 心理的ケア
- 法的援助
- 一時的な避難場所

## AV業界との関連

AV出演者は、作品の拡散によってネット上の誹謗中傷、社会的差別、心的外傷などの問題に直面することがあり、同法によって政府の総合的な支援を受けられる。
