# 児童買春・児童ポルノ禁止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 児童買春・児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律 |
| 通称 | 児童買春・児童ポルノ禁止法 |
| 法令番号 | 平成11年法律第82号 |
| 施行 | 1999年5月1日 |
| 所管 | 厚生労働省、警察庁 |

## 概要

この法律は児童を性的搾取から保護するための法律で、児童買春や児童ポルノの製造、所持、頒布などの行為を禁止しています。

## 主な内容

### 禁止行為

- 児童買春（児童と対価を伴う性行為を行うこと）
- 児童ポルノの製造、所持、頒布、展示
- 児童買春の媒介、あっせん
- 児童買春を目的とした誘引

### 罰則

- 児童ポルノの製造：3年以上の懲役
- 児童ポルノの所持：1年以上の懲役
- 児童ポルノの頒布：3年以上の懲役
- 児童買春：5年以上の懲役または罰金

## AV業界との関連

この法律がAV業界に及ぼす影響は、出演者の年齢の真実性を確保する点にあります。AVの制作側は出演者の年齢を厳格に確認し、この法律に触れないようにしなければなりません。未成年者がAVに出演した場合、児童ポルノに関連する犯罪が成立する可能性があります。
