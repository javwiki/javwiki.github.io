# 職業安定法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 職業安定法 |
| 法令番号 | 昭和22年法律第141号 |
| 施行 | 1947年10月15日 |
| 所管 | 厚生労働省 |

## 概要

職業安定法は、職業紹介や労働者派遣などの雇用サービスを規律し、労働者の正当な権利利益を保護する法律である。

## 主な内容

### 職業紹介

- 職業紹介を行うには、厚生労働大臣または都道府県知事の許可が必要である
- 不当な職業紹介行為を禁止する
- 求職者のプライバシーを保護する

### 労働者保護

- 強制労働を禁止する
- 不当な解雇を禁止する
- 労働者の正当な権利利益を保護する

## AV業界との関連

AV制作には、出演者やスタッフといった労働者の権利利益の保護が関わる。出演者は労働者として、強制労働の禁止やプライバシーの保護など、同法が定める各種の保護を受ける。AV制作側が同法に違反した場合、出演者は法に基づいて権利を主張できる。
