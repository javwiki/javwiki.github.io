# AV出演被害防止・救済法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 性をめぐる個人の尊厳が重んぜられる社会の形成に資するために性行為映像制作物への出演に係る被害の防止を図り及び出演者の救済に資するための出演契約等に関する特則等に関する法律 |
| 通称 | AV出演被害防止・救済法、AV被害救済法、AV新法 |
| 法令番号 | 令和4年法律第78号 |
| 成立 | 2022年6月15日 |
| 公布 | 2022年6月22日 |
| 施行 | 2022年6月23日 |
| 所管 | 内閣府男女共同参画局 |

## 概要

AV出演被害防止・救済法（以下「AV新法」という）は、2022年6月23日に施行された日本の法律です。AV（アダルトビデオ）への出演によって生じる被害の防止と救済を専門に扱う、日本で初めての法律です。

この法律は、2022年の日本民法の改正（成年年齢を20歳から18歳に引き下げ）を背景に成立しました。AV出演者が脅迫、欺瞞、強要などの不当な扱いを受けないように保護し、被害者に法的な救済の道を提供することを目的としています。

### 適用範囲

- **適用対象**：性別や年齢を問わず、すべてのAV出演者が保護される
- **適用作品**：正規のAV、個人撮影のAV、同人AVなど、各種の性行為映像作品
- **主管機関**：内閣府男女共同参画局
- **相談窓口**：#8891（内閣府AV出演被害相談電話）

## 主な内容

### 事業者の義務

AV制作に関わる事業者は、以下の規定を守らなければなりません。

- 出演契約を締結する際に、以下の内容を書面で明示すること：
  - 出演作品の名称、内容、販売方法
  - 出演者の氏名、年齢などの基本情報
  - 出演料およびその支払方法
  - 出演者に同意を撤回する権利があること
- 出演者に撤回権があることを告知すること
- 脅迫、欺瞞、強要などの不当な契約行為を行わないこと
- 出演者の人格の尊厳を尊重すること

### 出演者の権利

出演者は以下の法定の権利を有します。

- **撤回権**：作品の公開日から1年以内であれば、出演者は出演の同意を無条件で撤回できる
- **撤回後の販売禁止**：撤回後、事業者は当該作品を販売し続けてはならない
- **損害賠償請求権**：違法行為によって損害を受けた場合、事業者に賠償を請求できる
- **削除請求権**：インターネットなどから関連する映像の削除を求めることができる

### 法的責任

本法に違反した事業者は、以下の処分を受ける可能性があります。

- 行政指導、行政上の勧告
- 違反者情報の公表
- 刑事罰（情状に応じて）

## 設立の経緯

### 立法の背景

AV新法が成立する以前、日本のAV業界には数多くの問題が存在していました。

- 若い女性が騙され、脅されてAVに出演させられる
- 出演者が契約済みの作品を撤回できない
- インターネット上に拡散されると完全に削除することが難しい
- 被害者に有効な法的救済の手段がない

2022年の民法改正で成年年齢が18歳に引き下げられたことで、18〜19歳の若者も契約能力を持つようになりましたが、それに見合う保護の仕組みを早急に整える必要がありました。

### 立法の経過

- 2022年2月：法案を国会に提出
- 2022年6月15日：参議院で可決
- 2022年6月22日：正式に公布
- 2022年6月23日：即日施行

### 成立後の改正

施行後の実情を踏まえ、この法律には「成立から2年以内に評価を行う」とする規定が設けられており、執行の効果に応じて必要な改正と整備が行われることになっています。

## 関連する論点

### 賛成の意見

- **人権の保護**：この法律はAV出演者に対する法的保護の空白を埋めた
- **救済の仕組み**：脅迫や欺瞞を受けた出演者に、撤回と賠償の法的根拠を提供する
- **業界の規範化**：AV業界の規範化を促進する

### 反対と疑問

- **正規のAVへの影響**：この法律が正常に運営されているAV制作に影響を及ぼす可能性があるとの見方もある
- **個人撮影AVの規制**：個人撮影や同人AVなど、非正規のAVに対する規制の実効性には疑問が残る
- **法律の適用範囲**：撤回権の行使が第三者の利用者に影響を与える可能性がある

### 民法改正の影響

2022年4月に施行された民法改正により、成年年齢は20歳から18歳に引き下げられました。改正以前は、20歳未満が契約するには親権者の同意が必要でした。改正後は18〜19歳が単独で契約できるようになりましたが、それに伴う消費者保護とAV出演者保護が新たな課題となっています。
