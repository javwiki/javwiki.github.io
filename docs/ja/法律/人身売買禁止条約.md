# 人身売買禁止条約

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 人身売買及び他人の売春からの搾取の禁止に関する条約 |
| 通称 | 人身売買禁止条約、パレルモ条約 |
| 日本批准 | 2004年1月25日 |

## 概要

この国際条約は、人身取引と性的搾取を禁止し、被害者を保護することを目的としています。日本は締約国として、人身取引を防ぎ、被害者を保護するための措置を講じる義務を負っています。

## 主な内容

### 禁止行為

- 人身取引（搾取を目的とした募集、運搬、移転）
- 性的搾取
- 強制労働
- 奴隷状態

### 締約国の義務

- 人身取引を刑事犯罪とする
- 被害者を保護する
- 人身取引を予防する
- 国際協力

## AV業界との関連

AV業界には、欺瞞や強要によって他人に出演を強いる行為が存在し、人身取引に当たる可能性があります。この条約は、AV業界における搾取行為を防ぐための国際法上の根拠を提供します。
