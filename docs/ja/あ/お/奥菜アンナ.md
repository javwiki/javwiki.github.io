# 奥菜 アンナ

## 基本情報

- **名前**: 奥菜 アンナ
- **読み**: おきな あんな
- **英語名**: Anna Okina
- **別名**: 姫野ゆうり（ひめの ゆうり、旧芸名）、市来美保（いちき みほ、旧芸名）、岩下桃華、仲間あずみ（なかま あずみ、現名）

## プロフィール

奥菜 アンナは日本のAV女優。神奈川県出身で、Mカップ（B105）の超乳スタイルで知られる。2011年に「姫野ゆうり」名義でグラビアアイドルとしてデビューし、初のイメージビデオは6月に発売された。2012年4月に同名義でS1からデビュー。その後、事務所の変更により「市来美保」と改名して活動し、さらに「奥菜 アンナ」と改名（2016年頃まで活動）。その後は「仲間あずみ」と改名して活動を続けている。

## 人物

- 混血系の女優で、105cmのMカップ爆乳と56cmの細いウエストというギャップのあるスタイルがトレードマーク。
- 改名が多く、姫野ゆうり → 市来美保 → 奥菜 アンナ → 仲間あずみ（ほかに「岩下桃華」名義の作品もある）。
- かつてLotus Group（ロータスグループ）に所属していた。

## 作品の特徴

- デビュー作は「リアルフィギュアボディ」を打ち出し、身体の曲線を売りとした。
- S1時代は単体企画が中心（痴漢、風俗、フェラなど）。市来美保時代は本中、中出し、黒人解禁、アナル解禁などハードな企画に集中した。
- 奥菜 アンナ時代は熟女・人妻、女捜査官、拷問系、レズ作品（秋野千尋との共演によるオペラ10周年作など）に多く出演した。
