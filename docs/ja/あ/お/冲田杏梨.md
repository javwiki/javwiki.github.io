## プロフィール

沖田杏梨は元AV女優、タレント、歌手、クリエイター。イギリス・バーミンガム出身。2010年11月に「人類最強body」の触れ込みでデビューを予告し、2011年2月にS1専属女優として正式にAVデビューした。デビュー時に胸部に1億円の保険をかけた。Lカップ（後にPカップまで発展）の爆乳が最大の特徴である。2016年4月にAV界を引退してクリエイター兼歌手へ転身し、2023年にダンスボーカルグループBLACK DIAMONDを結成、2025年11月に卒業した。SNSの総フォロワーは約700万人。2021年には5年条項を行使し、すべての作品を各AVサイトから取り下げた。

## 人物

- イギリス・バーミンガム生まれ。英語とポルトガル語が堪能で、BBCのインタビューでは終始英語で応じた。趣味はほかにイラスト、料理。
- Lカップの爆乳はCT検査で純天然と確認されている。
- 胸筋の力だけで胸を自由に動かすことができ、番組で披露したこともある。
- 2018年に結婚し、娘を出産した。
- 2019年からYouTubeクリエイターとして「ATELIER Anri」の活動を始め、チャンネルは急速に登録者2万人を突破した。
- SNS（Instagram、Weibo、Twitterなど）の総フォロワーは約700万人で、著名なインフルエンサーである。
- 2023年にダンスボーカルグループBLACK DIAMONDに加入し、「ANRI」名義で活動。
- 2024年に『週刊SPA!』グラビアン魂アワードみうらじゅん大賞を受賞。

## 作品の特徴

- 超大カップの爆乳を核とした売りで、作品中の乳房プレイが非常に豊富。
- 初期はS1で専属として活動し、後にSOD（観月あかね名義）とMOODYZへ移った。
- 作品はドラマ系、痴女、中出し、VRなど多様なジャンルに及ぶ。

## 年表

| 年 | 出来事 |
| --- | --- |
| 2010 | 11月から「人類最強body」の触れ込みで匿名予告。12月11日号の『週刊大衆』で初グラビア、12月15日に初のヌード写真集『A-TRIP』を発売。 |
| 2011 | 1月8日にDMMでカバーを公開、2月7日にS1専属として正式にAVデビューし、デビュー時に胸部に1億円の保険をかけた。 |
| 2012 | 10月に「観月あかね」名義でSODからデビュー（SODでの活動はこの名義、それ以外は沖田杏梨）。10月14日にMilky Pop Generationのライブに参加（仁科百華、琥珀うた、栗林里莉と共演）。 |
| 2014 | 1月にMOODYZ専属女優となる。4月に香港映画『大性豪』（原題『豪情3D』/Naked Ambition 2。Chapman To、Josie Hoと共演し、ポスターに彼女とChapman Toが起用された）に出演。 |
| 2015 | 9月24日に恵比寿★マスカッツに加入。 |
| 2016 | 2月4日に恵比寿★マスカッツを脱退（同グループ初の自主脱退者）。4月13日にブログでAVからの引退を発表。映画『SCOOP!』『14の夜』に出演。 |
| 2018 | 2月17日にブログで前年12月の結婚と妊娠を公表、4月30日にInstagramで女児の出産を報告。 |
| 2021 | 5年条項を行使し、すべてのAV作品を各公式サイトから取り下げ、広く議論を呼んだ。 |
| 2022 | 7月にTwitterで安倍晋三を追悼し、偉大な首相と称えた。 |
| 2023 | 3月21日にダンスボーカルグループBLACK DIAMONDを結成し、「ANRI」名義で活動、2枚のシングル『Super Duper』『hungry spider』でデビュー。5月17日にZepp Hanedaで初のショーケースを開催。 |
| 2024 | 5月15日にグループ初のアルバム『SHINING DIAMONDS』を発売。12月24日に『週刊SPA!』グラビアン魂アワード2024みうらじゅん大賞を受賞。 |
| 2025 | 7月19日に体調不良のため舞台出演を休止。11月にBLACK DIAMONDを卒業。 |
