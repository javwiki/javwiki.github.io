## 索引方法

本百科の女優記事は、**五十音**の行ごとに分類する：

| 行 | 段 |
|---|---|
| **あ行** | あ い う え お |
| **か行** | か き く け こ（が ぎ ぐ げ ご を含む） |
| **さ行** | さ し す せ そ（ざ じ ず ぜ ぞ を含む） |
| **た行** | た ち つ て と（だ ぢ づ で ど を含む） |
| **な行** | な に ぬ ね の |
| **は行** | は ひ ふ へ ほ（ば び ぶ べ ぼ、ぱ ぴ ぷ ぺ ぽ を含む） |
| **ま行** | ま み む め も |
| **や行** | や ゆ よ |
| **ら行** | ら り る れ ろ |
| **わ行** | わ を ん |

各女優の記事は、その名前の**先頭の仮名**が属する段のサブディレクトリに配置する。
