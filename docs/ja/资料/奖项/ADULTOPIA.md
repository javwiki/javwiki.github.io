# ADULTOPIA 大人国

XCITYが発表した2026年ADULTOPIA ADULT CEREMONYの全17部門と掲載受賞者を収録する。確認日は2026-10-11、審査対象期間は2024-11-01〜2025-10-31。作品賞の氏名は受賞作品に添えて掲載された主演女優であり、個人賞と混同しない。

## イベント日付

| イベント | 日付 | 出典 |
| --- | --- | --- |
| 授賞式 | 2026-03-27 | [XCITY](https://xcity.co.jp/award_result/) |
| 展示会の女優交流イベント | 2026-03-28–2026-03-29 | [FunOne Tickets](https://tickets.funone.io/activity/activity_detail/adultopiaevent) |

交流イベントのチケットページが確認するのは当該イベントの日付であり、展示会全体の開幕日は推定しない。過去の展示会を連続して確認できる資料はまだない。
