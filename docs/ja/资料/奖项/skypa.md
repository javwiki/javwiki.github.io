# スカパー!アダルト放送大賞

スカパー!アダルト放送大賞は、2005年に始まった成人向け衛星放送分野の表彰企画である。従来の女優賞・新人女優賞などの個人賞と、SPOOX EXなどをPRするEXガールズのメンバー選抜は、区別して記録する。

## 賞の部門

### 個人賞（2006-2020）

| 賞 | 説明 |
| --- | --- |
| 女優賞 | 年間最優秀AV女優 |
| 新人女優賞 | 年間最優秀新人女優 |
| 熟女女優賞 | 年間最優秀熟女系女優 |
| 最多出演女優賞 | 年間の出演作品数がもっとも多い女優 |
| メディア賞 | 各メディアが授与する賞 |
| スカパー!オンデマンドアダルト賞 | オンデマンド部門の最優秀女優 |

## EXガールズ（確認済みの2022–2024年の記録）

2022年はMVAを受賞した本郷愛が、波多野結衣・篠田ゆうによるPRユニットに加入。2023年はオーディション形式へ大幅に刷新され、審査とファン投票を経てセンター1名とメンバー2名が決定した。2024年の報道では3代目の4名と6月26日のお披露目会が確認できる。メンバー就任は従来の女優賞と同一ではない。[2022年の報道](https://www.nikkansports.com/entertainment/news/202203140000428.html)、[2023年の公式レポート](https://note.com/sptv_note/n/n34b625094de0)、[2024年のイベント案内](https://www.menscyzo.com/2024/05/post_227377.html)

| 年 | メンバー |

| 2024 | 川上ゆう、新村あかり、森沢かな、吉根ゆりあ |
