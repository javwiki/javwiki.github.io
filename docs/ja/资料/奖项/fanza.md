# FANZAアダルトアワード

FANZAアダルトアワードは、FANZA（旧DMM.R18）が女優や作品を表彰する賞である。2014年に始まり、2019年からFANZAの名称を使用した。2019年の個人賞では販売データを基に候補者を選び、ユーザー投票などで受賞者を決定した。授賞式は2019年5月12日、東京・新木場のSTUDIO COASTで開催された。[2019年の報道](https://www.art-techne.com/entertainment/news201905151345.amp)

名称の変遷：

- 2014年：DMMアダルトアワード
- 2015–2018年：DMM.R18アダルトアワード
- 2019年：FANZAアダルトアワード

2026-10-20の確認では、2020年以降の正式な開催記録は見つかっていない。恒久的な廃止やその理由を断定するものではない。
