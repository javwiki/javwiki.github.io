# 困難女性支援法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 困難な問題を抱える女性への支援に関する法律 |
| 法令番号 | 令和4年法律第52号 |
| 施行 | 2024-04-01 |

## 概要

女性の福祉、人権の尊重、男女平等を基礎に、本人の意思と状況に応じた包括的支援の体制を整える法律。第2条は、性的被害、家庭の状況、地域社会との関係性などによって日常生活・社会生活が困難な女性と、そのおそれがある女性を対象とする。

## AV業界との関係

出演に伴う性的被害、暴力、生活上の困難は相談の背景となり得る。女性相談支援センターなどが個別のニーズに応じて支援を調整し、出演歴だけで特定の給付を受けられるとは限らない。
