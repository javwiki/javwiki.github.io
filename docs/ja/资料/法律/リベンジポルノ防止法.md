# リベンジポルノ防止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 私事性的画像記録の提供等による被害の防止に関する法律 |
| 法令番号 | 平成26年法律第126号 |
| 施行 | 2014-11-27 |
| 段階的施行 | 第3条の罰則：2014-12-17、第4条：2014-12-27 |

## 概要

撮影対象者を特定できる私事性的画像を不特定・多数の者へ提供、公然陳列する行為や、その公表目的で提供する行為について罰則を設け、インターネット上の削除に関する制度を定める。無断転載された画像すべてが定義に該当するわけではない。

## AV業界との関係

警察庁は、第三者に見られることを認識して撮影を許可した画像（AV、グラビアなど）を「私事性的画像記録」から除外すると説明する。出演者の私的画像は撮影事情に応じて判断されるが、公表作品の流通に関する争いにはAV新法なども確認する必要がある。
