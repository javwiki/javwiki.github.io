# リベンジポルノ防止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 私事性的画像記録の提供等による被害の防止に関する法律 |
| 通称 | リベンジポルノ防止法 |
| 法令番号 | 平成26年法律第128号 |
| 施行 | 2015年1月1日 |
| 所管 | 法務省、警察庁 |

## 概要

この法律は、リベンジポルノによって被害者が受ける害を防ぐことを目的とし、同意なく他人の私的な画像を拡散する行為を禁止しています。

## 主な内容

### 禁止行為

- 同意なく第三者に他人の私生活上の画像を提供する行為
- インターネット上で他人の私生活上の画像を拡散する行為
- 他人に害を与える目的で画像を提供する行為

### 罰則

- 違反者は刑事罰（懲役または罰金）を受ける
- 拡散した者は刑事責任を問われることがある

### 被害者の権利

- 拡散した者に拡散の停止を求めることができる
- 関連する画像の削除を求めることができる
- 損害賠償を請求することができる

## AV業界との関連

AV出演者が同意のない画像の拡散（流出や転載など）に遭った場合、この法律によって法的な保護を受けることができます。AV出演被害防止法と互いに補完し合い、出演者に包括的な法的救済を提供します。
