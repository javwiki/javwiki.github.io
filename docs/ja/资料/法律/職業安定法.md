# 職業安定法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 職業安定法 |
| 法令番号 | 昭和22年法律第141号 |
| 施行 | 1947-12-01 |

## 概要

職業紹介、労働者の募集、募集情報の提供、労働者供給などを規律する。職業紹介と労働者派遣は異なる制度で、派遣は別途労働者派遣法が規律する。第44条は労働者供給を原則禁止し、第45条に例外があり、第63条は強制的な紹介や有害業務への紹介などの罰則を定める。

## AV業界との関係

事務所の募集・紹介が本法に違反するかは、事業の性質、紹介の経緯、実際の業務内容に基づいて判断する。事務所という名称や契約書の名称だけでは適法性を判断できない。
