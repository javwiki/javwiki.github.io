# 民法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 民法 |
| 法令番号 | 明治29年法律第89号 |
| 施行 | 1898年7月16日（一部改正後施行） |
| 所管 | 法務省 |

## 概要

民法は日本の民事法の基本法であり、契約、不法行為、親族、相続といった基本的な法制度を含む私人間の法律関係を定めている。2022年4月に施行された改正により成年年齢が20歳から18歳に引き下げられ、AV出演者の契約締結能力に大きな影響を与えた。

## 主な関連条文

### 成年年齢

- 2022年4月1日より前：成年年齢は20歳
- 2022年4月1日以降：成年年齢は18歳
- 18〜19歳は法定代理人の同意なく単独で契約を締結できる

### 契約能力

- 未成年者（18歳未満）が契約を締結するには法定代理人の同意が必要
- 成年者は単独で契約を締結できる

### 不法行為

- 故意または過失により他人の権利を侵害した者は、損害賠償責任を負う
- AV出演における不法行為（同意のない映像の拡散など）にも適用される

### 取消権

- 詐欺・強迫により締結された契約は取り消すことができる
- AV出演における不当な契約行為にも適用される

## AV業界との関連

| 関連点 | 説明 |
| --- | --- |
| 契約能力 | 成年年齢の引き下げにより18〜19歳が単独で契約できるため、特別な保護が必要 |
| 契約の取消し | AV出演者は詐欺・強迫を理由に契約を取り消すことができる |
| 不法行為による賠償 | 出演者は不法行為を理由に損害賠償を請求できる |
