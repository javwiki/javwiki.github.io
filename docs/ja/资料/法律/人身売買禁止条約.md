# 人身売買禁止条約

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 人身売買及び他人の売春からの搾取の禁止に関する条約 |
| 国連総会での採択 | 1949-12-02 |
| 国際発効 | 1951-07-25 |
| 日本の加入書寄託 | 1958-05-01 |

## 概要

他人の欲望を満たすために他人を売春させること、他人の売春から搾取すること、売春宿の経営や資金提供などを対象とする条約。国連条約集は日本の加入書寄託を1958年5月1日と記録する。寄託日と国際発効日は区別する。

## AV業界との関係

2000年採択の「人身取引議定書」（パレルモ議定書）とは別の条約である。外務省は日本による同議定書の受諾書寄託を2017年7月11日とする。出演に欺罔や強制が伴う場合も、具体的行為と国内法に基づいて判断し、業界に属するだけで人身取引と認定しない。
