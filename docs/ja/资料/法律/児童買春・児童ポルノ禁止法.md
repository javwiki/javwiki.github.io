# 児童買春・児童ポルノ禁止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 児童買春、児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律 |
| 法令番号 | 平成11年法律第52号 |
| 施行 | 1999-11-01 |

## 概要

第2条は児童を18歳未満と定義する。児童買春や実在の児童に係る児童ポルノなどを規制・処罰し、児童保護の措置を定める。製造、提供、自己の性的好奇心を満たす目的での所持などには、それぞれ法定の成立要件がある。

## AV業界との関係

民法の成年年齢引下げでも、本法の18歳未満という基準は変わらない。作品名、架空の役の年齢、制服だけでは出演者の実年齢を証明できず、実際の撮影対象と内容を確認する必要がある。
