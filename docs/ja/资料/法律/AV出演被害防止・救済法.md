# AV出演被害防止・救済法

## 概要

2022年6月23日施行。法定の「性行為映像制作物」への出演契約を規律し、性別・年齢を問わず出演者を保護する。適用は第2条の定義と契約事情に基づき、「正規」「個人撮影」といった表示だけでは判断しない。

## 制作側の義務

- 契約時に契約書等と説明書面等を交付し、所定の事項を説明する。
- 書面等の交付から少なくとも1か月は撮影できず、出演者は撮影や嫌な行為を断れる。
- 全撮影終了から少なくとも4か月は公表できず、公表前に出演者が映像を確認できるようにする。

## 契約解除と公表の停止

撮影前および撮影後から公表までの間も、無条件に契約を解除できる。公表後の期間は下表のとおり。法定の契約の任意解除であり、単に「出演同意の撤回」と説明しない。

| 契約締結日 | 公表後の任意解除期間 |
| --- | --- |
| 2022-06-23～2024-06-22 | 公表から2年間 |
| 2024-06-23～2025-06-22 | 公表から1年間または2026-12-22の遅い日まで |
| 2025-06-23以降 | 公表から1年間 |

2022年6月22日以前の契約には本法による取消し・解除は適用されないが、内閣府は撮影した性行為映像の公表の差止請求は可能と説明する。取消し・解除後や契約がないまま公表された場合は販売・配信の停止等を請求でき、救済ごとに適用条件がある。

## 罰則

罰則は任意解除を妨げる不実告知・威迫、所定の書面を交付しない行為や虚偽記載などの特定行為を対象とする。すべての義務違反に同じ罰則があるわけではない。第5章の罰則は2022年7月12日から施行。

## 相談と支援

`#8891` は性犯罪・性暴力被害者のためのワンストップ支援センターの全国共通短縮番号で、AV出演被害の相談も扱う。AV専用電話ではない。解除の通知様式や配信停止の資料は内閣府のページに掲載されている。
