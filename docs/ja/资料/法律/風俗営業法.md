# 風俗営業法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 風俗営業等の規制及び業務の適正化等に関する法律 |
| 法令番号 | 昭和23年法律第122号 |
| 施行 | 1948-09-01 |

## 概要

風俗営業や性風俗関連特殊営業などについて、営業類型ごとに許可、届出、営業区域、年少者保護などを規定する。原法は1948年施行で、現行規定は改正を重ねている。第2条は風俗営業、店舗型・無店舗型性風俗特殊営業、映像送信型性風俗特殊営業などを区別する。

## AV業界との関係

「AVの制作・販売はすべて風営許可が必要」と一括りにはできない。第2条第7項・第8項、第31条の2、第31条の7などは成人向け映像の販売・貸付や映像送信業務の定義と届出に関わる。実際の営業類型を確認する必要がある。
