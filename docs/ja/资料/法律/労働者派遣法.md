# 労働者派遣法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 労働者派遣法 |
| 法令番号 | 昭和60年法律第88号 |
| 施行 | 1986年7月1日 |
| 所管 | 厚生労働省 |

## 概要

労働者派遣法は、労働者派遣という就業形態を規律し、派遣労働者の正当な権利利益を保護するため、派遣元事業主と派遣先事業主の義務を定めた法律である。

## 主な内容

### 派遣許可

- 労働者派遣事業を行うには、厚生労働大臣の許可を取得する必要がある
- 一定の資質要件を満たす必要がある

### 労働者保護

- 不正な派遣を禁止する
- 派遣労働者の賃金・福利厚生を保護する
- 差別的取扱いを禁止する

### 派遣先の義務

- 派遣労働者に対して安全衛生上の義務を負う
- 強制労働を禁止する
- 労働者の正当な権利利益を保障する

## AV業界との関連

AV出演者は「モデル」「俳優」などの名義で制作に参加することが多く、制作会社との関係が労働者派遣に該当する場合がある。同法はAV出演者を労働者として保護し、不正な派遣と強制労働を禁止している。
