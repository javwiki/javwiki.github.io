# 売春防止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 売春防止法 |
| 法令番号 | 昭和31年法律第118号 |
| 施行 | 1957年4月1日 |
| 所管 | 厚生労働省 |

## 概要

売春防止法は、売春を防止するために日本が制定した法律である。同法はAV業界に直接適用されるものではないが、性風俗産業に関わる法律として、AV業界の規制を考えるうえで一定の参考になる。

## 主な内容

### 禁止行為

- 売春（対価を得る目的で性交を行う行為）
- 売春の周旋
- 強制売春
- 組織的な売春

### 罰則

- 違反者は刑事罰を受ける可能性がある
- 売春の周旋も同様に処罰される

## AV業界との関連

AV出演と売春は法律上の性質が異なる行為であるが、いずれも性行為を商業的に利用する点では共通している。同法は、対価を伴う性取引が違法となる境界を明確にし、適法なAV出演と違法な性取引を区別する法的根拠を与えている。
