# 売春防止法

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | 売春防止法 |
| 法令番号 | 昭和31年法律第118号 |
| 施行 | 1957-04-01 |
| 全面施行 | 1958-04-01（第2章など） |

## 概要

第2条は、対償を受け、または受ける約束で、不特定の相手方と性交することを売春と定義する。第3条は売春とその相手方となることを禁止するが、それだけを直接処罰する規定ではない。第2章は勧誘、周旋、強制、管理などの具体的行為を処罰する。

## AV業界との関係

報酬を伴う性行為すべてが本法の売春に該当するわけではなく、AVとして撮影されるだけで適法とも言えない。第2条の要件、実際の行為、他の適用法令を確認する必要がある。
