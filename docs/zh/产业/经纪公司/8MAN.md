# SO MODEL AGENT（旧称 8MAN）

So Model Agency 在本站对应本条目；官网使用名称 **SO MODEL AGENT**（首页也写作 SO MODELAGENT）。

## 基本信息

- **现名**: SO MODEL AGENT（ソウ モデルエージェント）
- **旧名**: 8MAN（エイトマン）
- **创立**: 据官网介绍，2006 年在大阪创立
- **所在地**: 大阪本社位于大阪市中央区南船场，东京支社位于东京都千代田区神田神保町
- **业务**: AV 女优、模特、艺人及写真偶像经纪，并支持电视、电影、杂志等领域的活动
- **协会**: 日本プロダクション協会（JPG）会员
- **官网**: <https://so-agent.jp/>
- **旧站**: <https://www.8man.jp/> 现跳转至上述官网
