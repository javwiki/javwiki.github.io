## 索引方式

本百科的演员条目按**五十音**的行归类：

| 行 | 段 |
|---|---|
| **あ行** | あ い う え お |
| **か行** | か き く け こ（含 が ぎ ぐ げ ご） |
| **さ行** | さ し す せ そ（含 ざ じ ず ぜ ぞ） |
| **た行** | た ち つ て と（含 だ ぢ づ で ど） |
| **な行** | な に ぬ ね の |
| **は行** | は ひ ふ へ ほ（含 ば び ぶ べ ぼ、ぱ ぴ ぷ ぺ ぽ） |
| **ま行** | ま み む め も |
| **や行** | や ゆ よ |
| **ら行** | ら り る れ ろ |
| **わ行** | わ を ん |

每个演员条目以其姓名的**首个假名**所在段归入对应子目录。
