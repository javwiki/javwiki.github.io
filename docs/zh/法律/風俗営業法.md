# 風俗営業法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 風俗営業等の規制及び業務の適正化等に関する法律 |
| 通称 | 風俗営業法、風営法 |
| 法令番号 | 昭和23年法律第122号 |
| 施行 | 1948年7月1日 |
| 所管 | 警察庁、厚生労働省 |

## 概要

風俗営業法规范日本的风俗营业行为，包括AV制作和发行的许可制度、营业场所的限制、广告规范等。

## 主要内容

### 许可制

- 从事AV制作、销售需获得地方公安委员会的许可
- 需满足一定的设备和场所标准
- 许可每年更新

### 营业限制

- 营业时间限制
- 营业场所限制
- 广告投放限制

### 广告规范

- 禁止夸张、虚假广告
- 需标明必要信息
- 禁止向未成年人宣传

## 与AV行业的关联

AV制作销售属于風俗営业的范畴，需遵守该法的许可、营业、广告等规范。
