# 制作公司与集团关系

作品封面上的“厂商”名称可能是法人公司、社内制作品牌或发行合作厂商。阅读公司历史时，需要先区分这几个层级，尤其不能把同一平台销售的作品都归入一个制作集团。

## 历史变化怎样理解

北都、CA 与 WILL 是有业务承继关系的历史名称，但 CA 被吸收合并与现法人设立是不同的事件。2017 年的出售报道也说明，曾经与 DMM 同属集团，不代表今天可以继续写成“DMM 子公司”。[WILL 沿革](WILL.md)

SOD 则采用制作与销售分工：1995 年设立的 Soft On Demand 与 1999 年设立的 SOD Create 分别承担销售物流和企划制作。将 SOD 一律写成“SOD Create”，会把集团、制作公司与销售公司混在一起。[SOD 沿革](SOD.md)

## 发行平台与制作集团

FANZA 是成人业务的平台品牌。DMM 在 2018 年的官方公告中说明了业务承继与品牌更名；这与制作厂商的收购、合并或持股关系应分别记录。[DMM 官方公告](https://prtimes.jp/main/html/rd/p/000003114.000002581.html)

判断一段公司关系时，应先看资料说的是**出资／收购、品牌运营、发行代理，还是平台上架**。同一作品可以由某制作厂牌推出，由另一法人发行，再通过多家平台销售。女优的专属厂牌与其所属[经纪公司](../经纪公司/index.md)也属于不同关系。
