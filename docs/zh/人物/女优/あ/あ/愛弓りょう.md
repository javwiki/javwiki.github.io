# 愛弓りょう

日本AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

愛弓りょう，1982年10月27日生，日本AV女优，ACT 所属。她于2019年1月以「三浦歩美」名义在 SOD クリエイト 的「本物人妻」厂牌专属出道，当时所属事务所为 ARROWS；同年7月转为マドンナ专属。2019年11月，配合11月19日「いい熟女の日」，她被选为「アダルトビデオ人妻熟女キャンペーン」形象女孩。

2021年5月7日，她在自己的 Twitter 上报告改名为「愛弓りょう」，所属事务所为 ACT。2022年8月22日周，她在 FANZA 租赁区周榜以《汗ほとばしる人妻の圧倒的な腰振りで、僕は一度も腰を動かさずに中出ししてしまった。愛弓りょう》获得第1位。2024年8月发售的《月刊FANZA》同年10月号公布的「FANZA2024年上半期女優ランキング」中，她列第12位。2025年2月17日周，她出演的《マドンナALL専属バスツアー2025 ハーレムを掴み取った男たちが極上の美女を独占!! 酒池肉林のお祭りはまだまだ続く!! 夢の大共演 & 大乱交FESTIVAL!! 後編》在通贩区周榜初登场第8位。

除影像作品外，她于2023年6月23日发行写真集《清澄～せいちょう～》，并在2019年至2022年间多次登上《周刊アサヒ芸能》《周刊ポスト》《周刊実話》等杂志的写真页；2025年5月参加在埼玉县しらこばと水上公园举行的「TREND GIRLS撮影会2025」。2026年1月4日起，她的网络电台节目《愛弓りょうのLovely Time♡》开播。

## 人物

- 维基正文称其生年月日未公开，出道时被介绍为36岁的人妻、有一名4岁儿子、原为糕点师；信息框则记为1982年10月27日，两处不一致，本条并列保留。
- 进入业界的契机是经熟人介绍认识的人邀请，她当初认为「我这种人大概不行」。
- 阅读电子台本时眼睛负担大、记台词也变差，因此拍摄前会把电子台本打印出来做成纸质台本。
- 以「三浦歩美」名义出道时的所属事务所为 ARROWS；2021年改名后所属事务所为 ACT，改名理由未在维基正文说明。
