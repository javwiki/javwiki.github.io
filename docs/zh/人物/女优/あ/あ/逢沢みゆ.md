# 逢沢みゆ

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 基本信息

- **日文名**: 逢沢みゆ
- **英文名**: Miyu Aizawa

## 简介

逢沢みゆ（2001年1月25日—），日本成人影像演员，原偶像。2013年以「坂本マリア」名义加入偶像组合「フラップガールズスクール」，2018年组合毕业后取得保育士资格，从事保育工作两年。2023年12月12日以 S1 NO.1 STYLE 专属出道；2024年11月表明转为企划单体，12月所属转为 NAX。2025年12月《FLASH》「FLASHセクシー女優ランキング2025」第5位。2026年1月，她经事务所许可公布实际生日为2001年1月25日。

## 作品特征

- 出道作为 S1 专属，标题即《新人NO.1STYLE 逢沢みゆ AVデビュー 本物アイドルのAV転身、その全記録ー》，以元偶像经历为宣传点。
- S1 专属期至2024年11月；转企划单体后出演 SOD クリエイト、ロイヤル、プレミアム、h.m.p、グローリークエスト 等厂牌，题材涵盖共演、义亲、看护、风俗等。
- 2024年至2026年发行四本写真集：《相逢 sou-ai》（双葉社）、《me=you》（徳間書店）、《プレミアムヌードポーズブック》（ジーオーティー）、《Miyutopia》（彩文館出版）。
- 自称擅长高速骑乘位；AV 写手東風克智评价其「処女役が上手い」，导演レミレミ・ニューワールド评价其「プロ意識が高く、自己プロデュースと努力の天才」。
- 2026年9月在东京涩谷 Gallery Le Deco 举办写真展「未完成。」。
