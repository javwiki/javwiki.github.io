# 有村のぞみ

日本AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

有村のぞみ，1997年2月14日生于静冈县，日本AV女优，アトラクティブ所属。2018年1月，她以プレステージ专属女优身份AV出道；2019年1月离开专属，转为企划单体女优。

2019年3月1日，她获 FANZA アダルトアワード2019 最优秀新人女优赏提名。2020年6月就任メンズサイゾー形象女孩；同年8月起，她开始以自己设计、缝制的服装拍摄写真连载《ハレンチのんちゃん》。2021年1月22日，她启动与りょう的合作写真集企划；2022年10月以ワイルドワンモデル身份参加同人颁布会「ゆるケット」。

2022年12月20日，她获《スカパー!アダルト放送大賞2023》新EXガールズオーディション提名，同月创立角色扮演时装品牌「nonnonstyle」；2023年3月经评审推荐成为新EXガールズ成员。2023年6月25日，她在レフカダ新宿举办首次谈话活动「のんちゃんといっしょvol.1」，嘉宾为浜崎真緒，两人谈了2小时40分。2025年2月10日周，她出演的《MOODYZファン感謝祭 バコバコバスツアー2025》在 FANZA 通贩区以预约阶段初登场第3；同年10月20日周，出演的《ダスッ!プレゼンツ WELCOME TO THE ようこそ!ズコバコキングダム》在视频区初登场第9。

## 人物

- 静冈县出身；兴趣是海外旅行、看搞笑节目与喝酒。
- 喜欢的女优是浜崎真緒，2019年在女同作品中实现共演。
- 特长是Y字平衡与前后180度开脚；喜欢的角色是ミニオン。
- 初次自慰在小学三年级，初次性体验在初一，对象是当时交往的、小她一岁的六年级男生。
- 出道前从事时尚相关工作，因此能独力完成服装从设计到缝制；2020年8月起以自制服装拍摄写真连载。
- 她是体液爱好者，会以潮吹、失禁、母乳类作品作为自慰素材。
- 她认为AV女优是「天职」，能以自己出演的作品实现作为观众想看的画面，令她高兴且兴奋。

## 作品特征

- 2018年1月至2019年1月为プレステージ专属，此后以企划单体作品为主，题材涵盖恋爱、共演与剧情类。
- 除AV外拍摄大量形象DVD（2019年至2026年），并有女性向AV、VR 与配信作品；2019年的《本物マルチタレント 着エロデビュー》以「早川ひとみ」名义发行。
- 电视方面出演《ケンコバのバコバコテレビ》（2018年6月至2019年7月、2020年1月起，サンテレビ）与《アトラクティブ女学園》（2020年8月起，エンタ!959）。
- 2019年8月26日出版写真集《honey sugar》；2020年8月起在メンズサイゾー连载《ハレンチのんちゃん》，自行设计并缝制拍摄服装。
- 2022年12月创立角色扮演时装品牌「nonnonstyle」，2023年起担任 BIKINIS TOKYO 模特。
- 2025年起出演 OP PICTURES 电影，包括《セックス指南物語 理性をこえた腰づかい》与2026年的《エロちょろギャル》（饰ジュリア）。
