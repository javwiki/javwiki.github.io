## 简介

うんぱい，8月1日生，日本AV女优、主播、网红与写真偶像。她4岁起学钢琴，就读于洗足学园音乐大学钢琴课程古典钢琴专攻。18岁被星探发掘而开始艺能活动，却被事务所（与后述各艺能事务所并非同一公司）骗走300万至400万日元，一度放弃成为艺人的梦想。经朋友介绍把空闲时间用于直播，作为17LIVE主播曾在主播排行中创下世界第2位（当时名义为伊藤彩），由此意识到自己适合做网红；2018年入围「Miss iD 2019」最终名单。

2019年她以写真偶像出道，以H罩杯为卖点，2021年1月19日发行影像作品《うんぱいしか勝たん!》（リバプール）。2021年12月TikTok粉丝突破340万。2022年1月25日，她宣布于同年2月以「うんぱい」名义AV出道，此后AV相关工作归属マインズ。出道作《うんぱい》成为该年S1 NO.1 STYLE最大的热作；2月8日与22日发售的光文社《FLASH》分别刊出半裸与全裸写真。同年3月她与S1签订大型合约，18日第2作开始配信。

2024年12月，她通过个人社交账号宣布移籍MOODYZ专属。2025年9月，她以《むっちり未亡人 暴かれた秘め事》（后改题《あかねの一週間》，小关裕次郎导演）首次出演电影并首次主演。除影像作品外，她还持续举办免费生日活动，并参与写真展、水上公园摄影会与定制车活动。

## 人物

- 旧档案记载为宫城县仙台市出身、1995年7月17日生、O型血；后年改为现行公开资料，现行资料只公开8月1日生，未公开年份。
- 兴趣是TikTok与视频直播。
- 身高166cm，三围B92（H罩杯）-W60-H96；因「美胸妆」受到关注，在女性中人气也高。
- 她认为性不是需要羞耻或隐藏的事，主张「性是艺术」；这一取向的契机是泳装视频反响很大，此后改为「以性感为轴」发布内容，经过自我打磨后对露出也不再有抵触。
- 音乐大学时代周围多是比赛获奖者，她曾感到被压倒、险些受挫；自评靠品味取胜的作曲能力不强，但靠学习与努力修到不至于挂科的程度，四年毕业成为日后的自信来源。
- 会一些中文和韩语。
- 转向AV的契机之一是对AV本就有兴趣，此外听了女优与粉丝交流的Clubhouse；2022年受访时称女优收入月约100万日元，付费粉丝俱乐部的收入高于此数。
- 常与她共演的石原希望评价她「平时是温和温柔的姐姐」，但角色开关一开就变得凌厉，甚至有人来商量「这样没问题吗」。

## 作品特征

- 2022年2月以S1专属出道，出道作成为该年S1最大热作；同年3月与S1签订大型合约。
- 出道作在2022年1月24日周FANZA视频区周间AV排行第1；2022年12月《アサヒ芸能》统计的「2022AV年间销售排行」中出道作第10位。
- 2023年6月19日周，出演作《エスワンファン感謝祭》Blu-ray版在FANZA通贩区周榜初登场第1（DVD版第4），6月26日周Blu-ray维持第1（DVD第5），7月17日周又在视频区周榜第1。
- 2024年12月移籍MOODYZ专属后，2025年11月10日周出演作《MOODYZ初専属超ハーレム MOODYZ ONLY ONE STARS みんな好きだ。》在FANZA通贩周榜初登场第1。
- 作品之外还发行写真、影像、日历、卡牌与成人玩具，并出演电视、电影与舞台；2025年首次主演电影。
