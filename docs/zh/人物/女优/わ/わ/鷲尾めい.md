# 鷲尾めい

日本成人影像演员。

## 基本信息

- **日文名**: 鷲尾めい
- **英文名**: Mei Washio
- **曾用名**: 筧ジュン
- **身高（官方／出版资料）**: 164 cm

## 简介

鷲尾めい，1997年10月20日生，神奈川県出身，エイトマン所属。2019年4月以「筧ジュン」名义在 S1 NO.1 STYLE 专属出道，当时所属アローズ。2019年7月首次在《週刊プレイボーイ》（2019年7月22日号）刊登写真。2020年3月移籍エイトマン并改名「鷲尾めい」；《週刊ポスト》2020年4月10日号刊登其裸体写真，讲谈社同时发行电子写真集《sugar》《milk》。2021年8月发表的「読者300人が選んだFLASH 2021セクシー女優ランキング」读者投票中列第50位；2023年《アサヒ芸能》「2023現役AV女優SEXY総選挙」第36位，2024年同榜综合第11位。2025年11月发表的「FLASHセクシー女優ランキング2025」列第32位。

## 作品特征

- 2019年出道起为 S1 NO.1 STYLE 专属，改名后继续在该厂牌出演。
- 作品以爆乳身材为核心设定：维基所列片名从J罩杯写到K、L罩杯，题材包括上司相部屋、OL、NTR、义父、痴女与骂倒风俗等。
- 2025年5月发售的《罵倒風俗 全編【めい様に見下されアングル】…》获《スポーツニッポン》「スキっとスポニチ」栏目评价「M男は垂涎必死」「突き放すような視線と疑似体験できる見下しアングル（が贅沢）」。
- 影像与平面方面，2022年12月举办写真展「。」（アトリエY原宿），2025年8月由マックスファクトリー推出 PLAMAX 手办；电视剧出演包括《世にも奇妙な物語 2020年 秋の特別編》（2020-11-14，フジテレビ）与 Netflix《全裸監督2》第6话（2021-06-24）。
