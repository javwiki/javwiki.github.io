# 友田真希

日本AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

友田真希，1972年8月20日生，日本AV女优。她于2002年在スタークラフト（Star Craft）旗下AV出道，此后长期以熟女题材为中心，在マドンナ、ドグマ、クリスタル映像、ビッグモーカル等众多厂牌留下大量作品。2010年3月她宣布引退，2016年8月25日以マドンナ专属女优身份复出，活动延续至2020年代。

她曾说明，AV出道的起因是当时交往对象以她的名义欠下债务；为了结束这段关系、摆脱困境，她选择这一行作为收入来源。出道初期的作品十分密集，2002年至2010年间的原创作品涵盖人妻、义母、未亡人、女教师等设定。

2006年，她出演ドグマ主办的D-1 CLIMAX作品《レズフィスト・ドラッグ〜少女の夢はいつだってフィストファック〜》（TOHJIRO导演），该作销量排名第1，她与長谷川ちひろ共同获得第2届D-1 CLIMAX「エロシンデレラ」奖，并成为TOHJIRO主导的「TOHJIRO・M女軍団」成员。同年，以她为对象的纪录片《影の光》制作完成。2008年，ミル发行的《人間酷包 友田真希》在AVグランプリ2008获得SM・陵辱部门奖。

2010年3月她宣布引退，理由是怀孕并希望尝试育儿；同年6月与8月仍有引退作与引退纪念作发行。2014年7月29日她开设Twitter。2016年8月25日，她以「専属復活 友田真希」在マドンナ复出，此后作品基本为该厂牌专属；2019年5月发行首部VR作品。

2022年7月，她成为要求修改AV出演被害防止・救济法的署名运动「女優・男優・スタッフが働きやすい『AV新法』にしてください」的共同发起人之一。2024年8月发行的《月刊FANZA》同年10月号公布FANZA 2024年上半年女优排行，她位列第14。2025年11月26日，写真集《真希》由ジーウォーク出版。

## 人物

- 私下有一个女儿。
- 她称AV出道的理由是当时交往对象的债务，债务名义为友田；她结束了这段关系，并把这份工作当作脱离困境的收入来源。
- 2010年引退的原因是怀孕，以及想尝试育儿。
- 2006年获得D-1 CLIMAX「エロシンデレラ」奖后，成为TOHJIRO「TOHJIRO・M女軍団」的一员。
- 2014年7月29日开始使用Twitter；2022年7月参与AV新法署名运动，为共同发起人之一。

## 作品特征

- 可确认的最早作品为2002年8月3日由センタービレッジ发行的《人妻慕情》；初期以熟女、人妻题材为主，参与厂牌众多。
- 2006年D-1 CLIMAX获奖作《レズフィスト・ドラッグ〜少女の夢はいつだってフィストファック〜》由TOHJIRO执导，属女同、SM取向作品，销量排名第1。
- 2008年《人間酷包 友田真希》获AVグランプリ2008 SM・陵辱部门奖，显示其在SM、陵辱题材中的评价。
- 2016年复出后以マドンナ专属为主，作品标题多围绕人妻、义母、不伦与背德关系展开。
- 2019年5月发行首部VR作品；2020年4月的《友田真希×熟れコミ!!》同时发行Blu-ray版。
- 2025年11月26日发行写真集《真希》。
