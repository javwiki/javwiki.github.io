# 月野かすみ

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 基本信息

- **日文名**: 月野かすみ
- **英文名**: Kasumi Tsukino
- **出生日期**: 2002年1月26日
- **出生地**: 日本神奈川县镰仓市
- **经纪公司**: リスタープロ（曾属オールプロ、アローズ）

## 简介

月野かすみ，2002年1月26日生于神奈川县镰仓市。曾属オールプロ、アローズ，现属リスタープロ。2020年10月作为DEEP'S专属女优出道，出道作DVDMS-585于10月7日实体发行，FANZA列配信开始日为10月3日。2021年5月离开专属，转为企划单体。2026年本人提出的方向为「ふわふわ系ダウナーお姉さん」。

## 人物

- 镰仓市出身；兴趣是茶道、料理，特长是书法、着装（着付け）。
- 小学5年级已有D罩杯，中学时长为G罩杯。
- 初体验是17岁时与同级生男友。
- 出道契机是在镰仓被DEEP'S工作人员搭话，对方以「マジックミラー便」提出拍摄请求；她当时未意识到是AV拍摄而拒绝，下车后又被另一名工作人员以杂志采访为名约见，后来才被告知是AV厂商并受邀出演。她起初受到冲击，但因对方称赞她一直自卑的大胸，觉得「也许能把自卑变成自信」，于是决定出演。
- 父母管教严格但并非过度干涉，性方面只要不给家人添麻烦即可；父亲在她于老家初体验后曾提醒「静かにしなさい」，母亲则因看到工作人员给她的信息卡而知道她就是月野かすみ。
- 她主动向朋友坦白身份，偶尔收到男同学的下流私信，会附上新作链接回覆。
- 自认「責め好き」，认为性不只是性交，也包括心灵相通、对话间的沉默与放松；也把空气与气味视为性爱对象。
- 2024年前后公开双性恋身份；因多演「タチ」役，私下羡慕男优，并憧憬有阴茎的鬣狗。
- 「月野かすみ」这个艺名是她自己想的。
- 写手もちづき千代子称她「想像以上の傑物」，并提及其体毛特征。

## 作品特征

- DEEP'S专属时期的作品以巨乳、痴女、家庭教师与教え子等设定为主；转企划单体后跨h.m.p、MAXING、妄想族等厂牌，题材包括义姐、NTR、人妻与幽霊。
- 本人自认「責め好き」，作品中主动诱导、耳语与痴女役较多；2024年前后公开双性恋身份，并出演レズ作品。
- 2026年本人提出的方向为「ふわふわ系ダウナーお姉さん」。
