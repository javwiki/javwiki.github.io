# 月野かすみ

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 基本信息

- **日文名**: 月野かすみ
- **英文名**: Kasumi Tsukino

## 简介

月野かすみ，2002年1月26日生于神奈川县镰仓市。曾属オールプロ、アローズ，现属リスタープロ。2020年10月作为DEEP'S专属女优出道，出道作DVDMS-585于10月7日实体发行，FANZA列配信开始日为10月3日。2021年5月离开专属，转为企划单体。

## 作品特征

- DEEP'S专属时期的作品以巨乳、痴女、家庭教师与教え子等设定为主；转企划单体后跨h.m.p、MAXING、妄想族等厂牌，题材包括义姐、NTR、人妻与幽霊。
- 本人自认「責め好き」，作品中主动诱导、耳语与痴女役较多；2024年前后公开双性恋身份，并出演レズ作品。
- 2026年本人提出的方向为「ふわふわ系ダウナーお姉さん」。
- 写手もちづき千代子称其「想像以上の傑物」，并提及其体毛特征。
