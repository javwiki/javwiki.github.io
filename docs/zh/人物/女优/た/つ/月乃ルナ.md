## 简介

月乃ルナ，1995年10月1日生于东京都，日本AV女优、歌手。她早年担任《周刊Playboy》等杂志的写真模特，2018年组建音乐组合「JC + The Mechanics」（ジュラシック・カッパーフィールド・アンド・ザ・メカニックス）并担任主唱，在网络上发行原创歌曲，同年参与写真合集《天使集》，2019年出版写真集《月の魔法》，此后隶属エイトマン。2019年2月，她以《新人 月乃ルナ ～最上●が激似のアノ子が衝撃のAVデビュー～》AV出道，并凭此作走红。

2021年前后，她移籍バンビプロモーション。2021年8月，她在「读者300人选出的FLASH 2021性感女优排行」读者投票中列第30位；同月《月刊FANZA》「このAV女優がすごい!2021年夏」第6位，冬季女优篇第5位。2022年仅4月一个月就发行13部作品，其中《凄テクを我慢できれば生中だしSEX》评价甚高；同年5月《アサヒ芸能》「2022现役AV女优SEXY总选举」第24位。2022年8月起，她成为アタッカーズ与本中两家片商的专属女优。

2023年8月，她移籍NAXプロモーション，同期开设 X 账号。2024年3、4月，SODクリエイト预定发售的《SNSで大炎上!? ファンにおっぱいを揉まれた金髪美人DJのセックス動画がヤバすぎて問題になっています。 月乃ルナ》中止发售，公司称「因诸般事由」；据《女性自身》，该作被指戏仿韩国DJ SODA于2023年在音乐节遭性骚扰的事件，社交网络上出现批评。2024年4月《アサヒ芸能》「2024现役AV女优性感总选举」综合第27位（东京第46位、大阪第19位）。2025年8月她再次移籍エイトマン（后改称 SO MODEL AGENT），2026年3月（杂志标注为4月）起成为DAHLIA专属女优。

## 人物

- 少女时代怕生、长期闭居家中，后升入女子高中。在家庭餐厅打工时被前辈告白，拒绝后对方变成跟踪者，她最终让步答应交往，花约半年完成初次性体验；因对方束缚太强而提出分手后又被跟踪，此后交往的对象也有同样倾向，因而有「メンヘラ製造機」的别称，AV出道前交往过约7人。
- 出演AV的动机，她说是「有兴趣，也想挑战各种事情，所以就试试看」；2024年的采访则提到，偶然与一位AV女优成为朋友后，因与男友陷入无性关系而向她咨询，是契机之一。
- 她原以为向男友说明会被阻止，对方却认为「想做就去做」，于是她一路完成面试与拍摄，内心还想着「我真的要去拍AV了哦～？」。
- 出道后约一年的专属期间她很少在媒体曝光，刻意营造神秘形象；转为企划单体后不再固定形象，饰演各种角色。
- 憧憬的AV女优是吉沢明歩。
- 2019年前后以「长得像最上もが」为卖点，她本人也是其粉丝，曾请对方拍拍立得；2021年不再染金发，转向带有阴郁气质的纤细清纯派路线。
- 过去也出演过硬调作品，被评「性爱中是承受深插的被动方」；AV研究者安田理央在2022年12月的文章中写她「摆脱了艺人相似的形象，确立了以冷酷表情呈现情色的独特路线」。

## 作品特征

- 出道前是写真模特兼音乐组合主唱，2019年2月转入AV，2022年4月单月发行13部作品，属企划单体时期的高产阶段。
- 2022年8月起为アタッカーズ与本中两家专属，2026年起以DAHLIA专属作品为主。
- 作品横跨清纯派剧情、硬调与企划单体共演，出道初期主打「长得像艺人」的话题性，2021年后转向阴郁纤细的清纯派定位。
- 写真集有2019年《月の魔法》与2026年《月に満ちて。》，另参与2018年的合集《天使集》。
- 音乐方面2018年发行《Night Breeze》，并以JC + The Mechanics成员身份活动；2024年4月16日在「月で逢いましょう vol.91」翻唱椎名林檎、B'z、BiSH 的歌曲，2025年5月8日举办个人演唱会。
- 2024年8月号《VIBES》Vol.370 由她担任封面。
