# 椿りか

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 基本信息

- **日文名**: 椿りか
- **英文名**: Rika Tsubaki

## 简介

椿りか，1999年6月5日生（日文维基的记载；资料站记为1996-06-05，见「资料范围」）。2017年4月1日以「大島ひな」名义出道，仅出演两部作品，此后在川崎的肥皂浴场工作。2019年在风俗综合网站「ヘブンネット」的全国Miss Heaven总选举2019中获神奈川泡泡浴部门第1位、全国泡泡浴部门第5位。2020年6月13日改名「椿りか」再出道，至2022年出演作品（含未署名作品）超过1000部。2021年前后另以「りかしゃふちゃん」名义接弹珠机店头活动，2024年起出演电影。

## 作品特征

- 以企划单体身份跨厂牌出演。ROOKIE 官方作品页所列作品包括《美女と野獣 ギャルとキモオタ》系列、痴女题材合集、放尿／潮吹合集与中出BEST等。
- 2024年2月配信的《サンバでエロすぎギャルをナンパ！…》（DOC）以街头搭讪、巨乳、中出为设定，2024年6月与8月两次进入 FANZA 视频周榜第10位。
- 2024年以后出演 h.m.p、マドンナ、MOODYZ、KMPVR 等厂牌作品，含 VR 与多人共演企划。
- 影视出演包括 OP 映画《密着巨乳姉妹 おっぱいは知っている》（2024-11-29，サヤ 役）与《さあやとこはる 最終章》（2025-11-21，高橋桃花 役）。
