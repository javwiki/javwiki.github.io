# 橘メアリー

## 简介

橘メアリー，1993年7月7日生，日本歌手、艺人，前AV女优，LIGHT 所属，是俄罗斯人与日本人的混血。2014年，她在大三时以高挑、巨乳的企画单体女优出道，最初出演所谓素人作品，还戴着假发。

她以首席成绩大学毕业，并在校内担任演讲，因此身份很快被同学发现。她说当时被说「落ちた」等坏话，偏见随之传开，懊悔之下与当时的朋友关系全部切断；她也后悔在无法下定决心的状态下出道，而且曝光的作品是假发造型、显得奇怪。不过她认为出一部与出一百部是一样的，毕业后一年与齿科卫生士工作并行，之后抱着「把人生赌在成为有名AV女优上」的决心转为专职，但此后约八年一直未能走红。

她参加了AV女优向亚洲进军的项目 AVA888 而在亚洲活动，也参加了由虚拟世界「ANGELIUM」衍生的 AiVy project，在日本与亚洲活动。2016年1月，她在涩谷道顿堀剧场首次登台脱衣舞；2018年7月30日加入ギンギン♂ガールズ，2019年3月21日以「女子社員酒場」的接待表现获 SOD AWARD2019「Best of 接客賞」，为上位3位之一。

疫情期间她减重约10公斤，加上AV新法使中坚女优的起用增多，以配信作品为中心的邀约增加。2022年10月，她希望出演的朝雾净导演作品《バイト先の人妻と不倫性交に燃え上がった日々 橘メアリー》（アリスJAPAN）发售，长期停留在销售榜前列，她后来在访谈中也把它列为演员生涯的转机，此后不伦对象、情人等角色大增。2023年3月她组成舞蹈歌唱组合 BLACK DIAMOND，2024年9月起成为マドンナ与ダスッ!的双专属。2025年5月15日，她宣布将在一年后的2026年5月从AV女优引退，引退后继续音乐与其他媒体工作。

## 人物

- 兴趣是DJ（DJ活动时名义为「DJ MARY」），特长是中文检定1级与绝对音感。
- 她在自己的 Twitter 上称特长是「膣圧コントロール」与「ハイパー手コキ」。
- 爱称为「めめたん」，粉丝称「めめふぁむ」；出道前是齿科卫生士。
- 是独生女，从2岁起接受钢琴、长笛等音乐英才教育；曾以特待生升入高中，但父母反对她靠音乐谋生，她放弃已获推荐的音乐大学，靠奖学金进入大学。
- 大学学习齿科卫生，与年长的研修医成为性伴侣；大三被星探发掘，就这样出道。
- 在ギンギン♂ガールズ出演的节目（2018年《矢口真里の火曜The NIGHT》）中，她说明是在新宿被星探发掘，加上打工处的上司说「我的前女友成了AV女优」，才决定AV出道。
- 父亲以收集AV为兴趣，老家有大量VHS录像带，这也是她亲近这类媒介的原因；她向父母仍称自己在做齿科卫生士，没有被发现。
- 小学六年级左右第一次买带钢圈、C罩杯的胸罩，高中时已是G罩杯；小时候为大胸感到自卑，现在觉得大了很好。初体验是高二。
- 天生是HSP，感受性比常人高；她不认为这是障碍，反而觉得这一特质活用在演技上。
- AV撰稿人芝田カズ评价她「以自然的演技，适合打工处人妻、朋友母亲等充满色气的大人女性」，同为撰稿人的さおり则评她「随着年龄增长愈发闪耀」。
