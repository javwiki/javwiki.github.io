# 神宮寺ナオ

## 简介

神宮寺ナオ，1997年2月15日生于神奈川县。曾属クルーズグループ，现属ARMプロモーション。2017年10月以《処女卒業 AVデビュー 神宮寺ナオ 20歳 経験人数は0人 緊張の初撮影完全ノーカット》出道。2019年6月起为マドンナ专属，同年11月兼为本中专属；2020年5月从本中移籍ムーディーズ，形成マドンナ与ムーディーズ双专属。

## 作品特征

- 出道作以20岁、经验人数0人为设定；此后长期在マドンナ与ムーディーズ两家厂牌专属发行，题材以人妻、义父等家庭关系、NTR与痴女为主。
- 2019年首次主演电影《バージン協奏曲 それゆけ純白パンツ!》，2020年出演《悪女の色仕掛け カモって快感!》等成人电影，并有舞台和游戏配音。
- 写真集有《Muse》（2019）、《Gimme!》（2022）、《Stilla》（2025）等；形象DVD与数字写真数量较多，2026年6月首次登上《週刊プレイボーイ》的拍摄页。
- 演员松本洋一评其「目で演技ができる」；监督さもあり称其「無軌道なエロさ」，并提到她在指示之外即兴加戏的逸事。制作人智子也提到她在镜头外即兴咬男优等不可预测之处。
