# 沙月恵奈

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 基本信息

- **日文名**: 沙月恵奈
- **英文名**: Ena Satsuki

## 简介

沙月恵奈，1999年6月11日生于千叶县，所属LINX。2020年9月以FALENO旗下配信特化厂牌「FALENOstar」专属出道。2021年10月离开专属，转为企划单体，此后每月拍摄约20至25部作品。2026年1月成为KMP旗下Million内新厂牌「sugar」专属，为约四年两个月后再次获得专属合约。

## 作品特征

- FALENOstar时期为配信特化厂牌的专属女优；转企划单体后跨厂牌出演，题材覆盖人妻、NTR、痴女、レズ、アナル、緊縛与SM。
- 2022年1月解禁レズ，此后常以搭档角色出演；2023年起挑战アナル，2025年解禁緊縛与SM。本人称「できそうだから断らなかった感じ」。
- 以アへ顔与淫語为标识，另有专门围绕アへ顔的企划；本人称アへ顔从出道起就没有抵触。
- 监督矢澤レシーブ评其为「戦闘員のような（自分でグイグイ行く）女優」；《夕刊フジ》专栏称其「万人受けするタイプで、オヤジキラー資質アリ」，并称其为「キカタンの女王」。
