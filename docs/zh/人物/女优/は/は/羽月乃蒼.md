# 羽月乃蒼

日本AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

羽月乃蒼，2001年11月13日生，日本AV女优。艺名读作「はるな のあ」而非「はづき」，据条目说明，这是为了让人不易通过搜索找到本人。2023年6月20日，她以 E-BODY 的《誇張抜きの神乳 奇跡のおっぱいを持つ素人女子大生が顔出しNGを条件にAVデビューするまでの3ヶ月ドキュメント 羽月乃蒼》出道，作品以「素人女大学生」「不愿露脸」为设定，她因此在片中和包装上都戴着口罩。

该作的缘起被描述为：她在私下认识男优フランクフルト林，对方以「胸部实在太厉害」为由通报，促成了拍摄。制作期正值新冠疫情，遮住嘴部的口罩作品在其他厂牌也大量出现，但这一部属于销量顶尖的作品。她后来在采访中承认，拍摄当时自己其实已经是所属事务所的AV女优。

她在 E-BODY 只出演了这一部，2023年12月在 MOODYZ 忘年会上获得最优秀 E-BODY 赏。出道作之后她改为不戴口罩出镜，AV撰稿人東風克智以「原蒙面摔角手常被说蒙面时代更有华彩」的现象作比，认为她的脸比胸部更被评说为朴素，作为企划单体女优一度进入低迷期。

转机是2024年6月 BeFree 发行的《発育の良過ぎる妹が裸族で無防備に誘惑してきて中出しセックスしまくった。》。该作让她戴上眼镜、进一步强化朴素角色，反而成功突出了胸部；此后「眼镜巨乳、随叫随到的方便炮友」一类角色增多，2025年8月 million 的《いつでもどこでも呼びつけたらすぐに駆け付ける 抱き心地最高の都合のいい地味セフレ》在用户评论中获得好评，她表示这个角色最接近本来的自己，也接近出道前的自己。

2025年下半年，她在 FANZA 女优排行中列第40位，进入前50名。2026年2月23日当周，2025年发行的《いつでもどこでも呼びつけたらすぐに駆け付ける 抱き心地最高の都合のいい地味セフレ》在 FANZA 视频区周榜回升至第7位；同年7月6日当周，2025年的《一度ハマると抜け出せない全裸露出沼》升至第6位。

## 人物

- 爱好是吃，特长是大胃王。
- 初体验为19岁，她自认偏晚，理由是当时体形偏丰满，不想让对方失望，也无法真实地想象这件事。对象是久未见面的女性朋友与搭讪同行的两名男子这类「像AV一样」的场合认识的第一个男人；她因着急而没有拒绝，顺势去了酒店，此后对方再有联络她也未回复，称是一夜情。
- 胸部从小学四年级左右开始发育，因显得体形偏胖而长期自卑，也曾被男生取笑，学生时代只与女性朋友来往。母亲给她宽松的衣服，要她「藏起来」，高中毕业前她一直穿运动内衣，从未戴过有钢圈的内衣；毕业后第一次去内衣柜台，买了最大的罩杯（G），仍觉得不合，才重新意识到自己的尺寸超出常规。
- 她表示能肯定自己的胸部是在AV出道之后，性格也变开朗了。她喜欢拍摄，但把拍摄中的性另作一回事：正因为工作里有刺激的性，反而更想要与同一对象、同一情境下的稳定性爱，这也成为她思考性生活与性偏好的契机。
- 出道时对家人隐瞒，2026年的采访中承认「很久以前就被母亲发现了」。2025年她正式与母亲谈过，母亲说「吃了一惊，但你不讨厌（AV）的话就没问题」并支持她；弟弟也早已知道。
- 撰稿人もちづき千代子评价她不仅有大胸的肉体魅力，还有从学生演到人妻的角色转换潜力，正因她的来历完全不明才提出采访。
- AV撰稿人東風克智称她为「AV界第一的朴素眼镜巨乳」。

## 作品特征

- 出道作以 E-BODY 的「素人」「戴口罩」「三个月纪录片」为设定，宣传语称其胸为「（即使在 E-BODY 拍摄过的15年里）大小、弹性、形状、乳晕颜色全部在100分以上的最高峰神乳」。
- 出道后在 E-BODY 仅有一部，随后以企划单体身份在 MOODYZ、OPPAI、ABC/妄想族、million、BeFree、ナチュラルハイ、アリスJAPAN 等多家厂牌出演，Boin「羽月乃蒼」Box 系列延续至 Box10。
- 2024年6月起以眼镜加朴素角色为标志，作品多为「地味」设定下的巨乳角色，并包含 VR、8K VR 与总集编。
- 作品标题中的罩杯与胸围表记在 J、I、H 与 100cm、103cm 之间并不一致，本条不将其作为确定的身体数据。
- 2026年起发行形象视频《Pure Beauty》《羽月乃蒼/Noah》与写真集《Noah》。
