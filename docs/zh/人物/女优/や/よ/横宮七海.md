# 横宮七海

日本前AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

横宮七海，2002年2月17日生，日本AV女优，クローネ 所属。2021年4月10日出道，以「萝莉系」定位为人所知。

2022年2月，在「这个ERO VR很厉害!」评选中，她出演的《【VR】天井特化アングルVR ～何もない休日に彼女とヤリまくる～ 横宮七海》获得2021年下半年作品排行第1位。

2023年12月10日，友人在社交平台公布她的死讯。日本国内几乎没有报道，台湾等亚洲地区的报道篇幅较大。她的确切离世日期未见公开确认，维基以12月10日作为卒日记载，而公开报道只能确认该日是讣告公开的日期，此点在本条中保留分歧。

## 人物

- 兴趣与特长是吃遍各地美食、料理，也用圆珠笔作画，喜欢水枪。
- 喜欢的花是芝樱、勿忘草与向日葵；是尾崎豊的粉丝。
- 自述经验人数超过100人。
- 导演太田みぎわ在谈到「虐待看起来虚幻」的女优时举出横宮，认为「面对那样的对象容易产生依赖，而这非常色情」。
- 另以「真島奈央」「宇佐ましろ」「白石もえ」等名义发行过形象DVD，维基未把这些名义列为别名。

## 作品特征

- 2021年4月起以萝莉系定位出道；维基记有 DVD、VR 与配信三类作品。
- VR 作《天井特化アングルVR ～何もない休日に彼女とヤリまくる～ 横宮七海》获「这个ERO VR很厉害!」2021年下半年作品排行第1。
- 形象DVD三部均以其他名义发行：《放課後えっちズム》（真島奈央）、《セーラー服を脱がさないで…》（宇佐ましろ）、《もえもえキュン》（白石もえ）。
- 2021年9月24日发行数字写真集《娘に喰わせてもらってます。》（WAAP photo）。
