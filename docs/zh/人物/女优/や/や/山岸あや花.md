# 山岸あや花

日本女演员、原AV女优、原地方电视台播音员。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

山岸あや花，1992年11月30日生，日本女演员、原AV女优，曾为地方电视台播音员。2017年7月，她以「山岸逢花」（やまぎし あいか）的名义作为 PREMIUM 专属女优AV出道，当时所属事务所为クルーズグループ。2023年5月15日，她在迎来30岁时宣布移籍リスタープロ并改名为「山岸あや花」；据其说明，考虑到「山岸」这个姓氏在粉丝以外的认知度较高，新艺名保留了姓氏，名字则在「あや花」与「あやめ」两个方案中，因她想留下「花」字而定为「あや花」。

2018年5月19日的 DMM 成人奖2018中，她获得新人奖提名。2020年2月她作为恵比寿マスカッツ新成员最终候选出演，同年3月31日在该节目直播中宣布加入；5月，作品《綺麗なお姉さんがチ○ポバカになるまでヌイてくれる種搾りメンズエステ 山岸逢花》在 FANZA 视频周榜连续两周第1，2020年上半年女优别排行销量第9，12月「FLASH 2020年现役最强性感女优BEST100」读者投票第31位。2021年1月1日，业界首次的 Ultra HD Blu-ray 规格软件由アイデアポケット、PREMIUM、ダスッ!三家同时发行，她主演了其中 PREMIUM 的作品；同年6月17日，她以《橘アヤコは見られたい》等作品在粉红电影十佳2020中同时获得新人女优奖与桃熊新人女优奖。

2022年1月，她与同事务所的美谷朱里组成组合「ぎしたに」，开设 YouTube 频道「山岸と美谷。」，5月起在《周刊アサヒ芸能》连载对谈专栏。2022年8月她举办个人写真展「縁-circle-」，同月在恵比寿マスカッツ的毕业公演后随团体解散而毕业。2023年5月《アサヒ芸能》「2023现役AV女优SEXY总选举」第45位；10月至11月，作品《お義父さん、そんなに強く抱かれたら…若妻が絶倫義父との中出しセックスに溺れた日々。山岸逢花》在 FANZA 租赁周榜连续4周第1，并获当月月间女优排行第1。2024年她两次出任 FANZA 活动形象女孩，12月与美谷朱音同获「アサ芸セクシーアワード2024」共演奖。2025年2月她出席台湾「TOP女神台北感謝祭」；9月10日，事务所在 X 宣布她于9月末退所并结束AV女优活动，10月起以自由身活动。

## 人物

- 她曾任东海地区地方电视台播音员，但因理想与现实的落差在短期内辞职；此后从事其他工作，仍无法忘记那个华丽的世界，于是决定AV出道。
- 出道后一段时间她只抱着「悄悄做」的心态，没有刻意求红，也没有开设 Twitter 等社交账号。
- 她提到播音员时代虽然没有实况经验，私生活中却常被要求「实况」。
- 她最初的自我安慰在小学四年级，初体验在初中三年级，对象是大一岁的前辈。
- 兴趣是逛咖啡馆，自认没有文化类爱好，但凭播音员经历对音乐、杂志、时尚等拥有较全面的知识。
- AV 写手末吉みちお评价她「无论演多么变态的玩法，都不会变得下流，这一点很出色」。
- 改名时她曾表示，希望新名字仍能让老粉丝认出「山岸」，而「花」字是她坚持保留的部分。

## 作品特征

- 2017年起长期以 PREMIUM 专属身份出演，作品类型涵盖人妻、义父题材与共演企划，2023年的义父题材作曾在租赁周榜连续4周第1。
- 2021年主演业界首款 Ultra HD Blu-ray 规格作品之一（PREMIUM 发行），属于该规格的早期参与者。
- 写真集有《花と逢》（2020年）、《Reflection》（2021年）、《duende》（2022年）、《Cosplay Fetish Book 山岸あや花》（2024年）、《斐色》（2024年），另有《プレミアムヌードポーズブック Model 山岸あや花》（2023年）。
- 除AV外还出演粉红电影、原创录像、舞台与网络剧，包括 Netflix《全裸監督》第七集与多部 fempass Cinema 作品。
- 2025年9月末AV引退后仍以女演员身份活动，此前的VR共演作在2025年11月仍登上 FANZA 视频周榜第1。
