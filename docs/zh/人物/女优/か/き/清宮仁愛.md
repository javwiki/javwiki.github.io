# 清宮仁愛

日本AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

清宮仁愛，3月15日生，日本AV女优，バンビプロモーション所属。2024年4月出道，出道时的宣传语是「このカラダ、ラスボス。」。她原本就是AV的重度用户，出道理由是出于单纯的兴趣——想试试自己很喜欢的东西。

2025年5月，她以拍摄模特身份参加在埼玉しらこばと水上公園举行的泳池摄影会「TREND GIRLS撮影会2025」；9月又参加在神奈川大磯ロングビーチ举行的同系列摄影会。夏天她染金发、塑造辣妹形象并出演痴女角色，内心其实担心「痴女作品推出时能否被接受」，之后把头发改回沉稳的颜色。她认为有辣妹经历的时期，正是确立作品中「清宮仁愛」形象的时期。

2025年10月28日，她在东京三轩茶屋グレープフルーツムーン举办首次个人Live「月で逢いましょう vol.130 清宮仁愛」，演唱了9首翻唱曲。2026年2月8日，她在秋叶原书泉ブックタワー举办写真集《プレミアムヌードポーズブック 清宮仁愛》的发售纪念活动。

2026年2月9日週，原定4月发售的出演作《MOODYZファン感謝祭バコバコバスツアー2026 25周年専属大集合!大乱交!大感謝スペシャル!》在 FANZA 通贩周榜初登场第4；该作发售日延期至5月19日，但仍在2月16日週升至第1。4月13日週，该作开始配信后在视频周榜列第3。

## 人物

- 初中低年级时被男学长说「你胸部很大吧」，第一次意识到自己胸大；起初因被反复这么说而自卑，后来把它当作女性的武器，才变得积极。
- 她喜欢的身体部位是「从臀部到腰部的线条」。
- 特长是乳交与口交，性癖是M。
- 当AV迷时属于「看封面买」的一派；出道后仍看AV，但会浮现认识的导演的脸，已不为情色而看，而是当作「学习的一环」。
- 撰稿人もちづき千代子称她是「把『女体』这个词体现到这种程度的女优」。
- 酒量好，2025年8月《ギャルと呑むと楽しいしエロがってくれる!》（E-BODY）中她在作品里喝到失去记忆，也有按她的嗜好制作的作品；她说喝酒后会喊「想做爱!」、变成「超开心酱」。
- ボイン学園ハマノ理事長评价她「胸围与腰围差达50厘米，乳首位置也高」，并分析因身体柔软「骑乘位时胸部会画圆般摇晃」。
