# 倉本すみれ

日本成人影像演员。

## 基本信息

- **日文名**: 倉本すみれ
- **英文名**: Sumire Kuramoto
- **出生日期**: 2001年9月14日
- **出生地**: 日本东京都
- **身高**: 153cm
- **经纪公司**: ボディコーポレーション

## 简介

倉本すみれ，2001年9月14日生于东京，所属ボディコーポレーション。2021年10月以MOODYZ的新人作《新人20歳 女子アナにいそうなほど可愛い! 渋谷区にあるお洒落なカフェで働く敏感スレンダー美少女 エッチが好きすぎてAVデビュー!!》出道，并在《月刊FANZA》「このAV女優がすごい!2021年冬 新人編」列第3位。此后以企划单体身份在MOODYZ、MAXING、h.m.p等厂牌发行作品，2022年11月度FANZA月度女优排行第2、2022年度第8。2023年11月任「みんなあつまれ MOODYZキャンペーン2023」宣传女郎；2024年10月15日宣布离开企划单体，自11月起成为無垢、本中、ダスッ!三家厂牌专属。2025年与松本いちか组成双人组合「fleuЯR」，发行单曲《好きすぎる / 明日くもりのち》。

## 作品特征

- 出道作为MOODYZ新人作；此后长期以企划单体形式跨厂牌出演，角色覆盖女友、妹妹、姐姐、人妻、恶女与高强度企划。
- 2021年冬起多次进入FANZA及《月刊FANZA》女优排行：2021年冬新人篇第3位、2022年夏女优篇第2位、2022年年度第8位、2023年上半期第11位、2023年年度通贩第10位/租赁第2位。
- 2024年2月12日当周，出演的《MOODYZファン感謝祭 バコバコバスツアー2024》在FANZA通贩周榜初登场第1；2024年2月度动画月度女优排行第3。
- 2025年10月13日当周，出演的《【MOODYZ創立25周年記念】 MOODYZ 大ハード学園》在FANZA动画周榜第1。
- 身形偏瘦，早期以自然体毛为标识之一；2024年末发行剃毛作品，2025年又恢复原状，《週刊プレイボーイ》称剃毛也是其角色塑造的一环。
- AV写手泽木毅彦称她能胜任优等生、劣等生、小恶魔、恶女、女儿、姐姐、妹妹等角色，并称其为「AV界的令和怪物」。
