# 倉本すみれ

日本成人影像演员。

## 基本信息

- **日文名**: 倉本すみれ
- **英文名**: Sumire Kuramoto

## 简介

倉本すみれ，2001年9月14日生于东京，所属ボディコーポレーション。2021年10月以MOODYZ的新人作《新人20歳 女子アナにいそうなほど可愛い! 渋谷区にあるお洒落なカフェで働く敏感スレンダー美少女 エッチが好きすぎてAVデビュー!!》出道。此后以企划单体身份在MOODYZ、MAXING、h.m.p等厂牌发行作品，2024年11月转为無垢、本中、ダスッ!三家厂牌专属。2025年与松本いちか组成双人组合「fleuЯR」，发行单曲《好きすぎる / 明日くもりのち》。

## 作品特征

- 出道作为MOODYZ新人作；此后长期以企划单体形式跨厂牌出演，角色覆盖女友、妹妹、姐姐、人妻、恶女与高强度企划。
- 2021年冬起多次进入FANZA及《月刊FANZA》女优排行：2021年冬新人篇第3位、2022年夏女优篇第2位、2022年年度第8位。
- 身形偏瘦，早期以自然体毛为标识之一；2024年末发行剃毛作品，2025年又恢复原状，《週刊プレイボーイ》称剃毛也是其角色塑造的一环。
- AV写手泽木毅彦称她能胜任优等生、劣等生、小恶魔、恶女、女儿、姐姐、妹妹等角色，并称其为「AV界的令和怪物」；本末ひさお、渋江譲二则评其体型。
