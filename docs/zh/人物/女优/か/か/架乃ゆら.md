# 架乃ゆら

日本艺人、演员、YouTuber、前AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

架乃ゆら，1998年12月28日生于冈山县，日本艺人、演员、YouTuber、前AV女优。高中时代开始模特活动，18岁起从事裸体模特工作。2017年11月19日以「無限の透明感」为宣传语在 S1 NO.1 STYLE 专属出道；出道前曾在《週刊大衆ヴィーナス》刊登裸体写真。

2018年6月29日，她以研修生身份加入恵比寿マスカッツ1.5，同年8月24日升为正式成员。2020年3月10日，她与まいてぃ、三上悠亜、吉澤友貴组成团体「SCANTY4」，公开歌曲《パンチラリズム》；2021年2月3日市川まさみ、山岸逢花加入，改组为「SCANTY6」。2021年12月6日，她在恵比寿マスカッツ的线上演唱会中宣布毕业。

2021年8月，她在「読者300人が選んだFLASH 2021セクシー女優ランキング」读者投票中列第31位，同月在《月刊FANZA》「このAV女優がすごい!2021年夏」列第5位；2023年5月在《アサヒ芸能》「2023現役AV女優SEXY総選挙」列第25位，2024年4月同选举综合第36位。

2024年5月7日，她宣布于7月底从AV女优引退，AV以外的活动继续；同月16日在 YouTube 说明引退是为转向一般女演员，并非因病或结婚，也不考虑回归AV。引退作于同年2月拍摄完成。10月，她出演舞台《バック・トゥ・ザ・うんちゃん〜ドライバーの消える日〜》，这是她AV引退后的首部舞台。

2025年5月1日，她离开 LINX，改为业务提携继续合作；同年9月25日因身体不适暂停活动，11月复归。此后她以演员与艺人身份出演舞台、网络剧与电视节目。

## 人物

- 冈山县出身，2017年时仍居住在冈山县；有一名兄长，小时候曾偷偷读他持有的成人漫画。
- 兴趣与特长是骑行；中学在演剧部、高中在美术部，因此偏好剧情式作品。
- 是昭和歌谣与特摄爱好者，平成假面骑士系列全部看过，最爱《假面骑士OOO》，并持有成人用变身腰带。
- 喜欢的类型是年长、温柔、微胖的人；被问及S还是M时回答「变态」，后来多答「偏M」。
- 高中时首次体验，对象是社团前辈；出道前的经验人数只有这一人。
- 艺名由事务所取「哪里都没有的名字」，姓氏的汉字逐字都有含义；昵称经粉丝募集后定为「ゆららん」。
- 尊敬的AV女优是つぼみ、麻美ゆま、友田彩也香；与七海ティナ是好友，引退前最先与她商量。
- 养有一只雄性曼基康猫「シンバ」，也曾养过仓鼠；与二叶エマ互称「双胞胎姐妹」，两人被认为长相与声音相似。

## 作品特征

- 2017年11月起为 S1 NO.1 STYLE 专属，出道宣传语为「無限の透明感」。
- 2023年6月，她出演的《エスワンファン感謝祭》Blu-ray 版在 FANZA 通贩周榜初登场第1，DVD 版第4，次周维持第1；该作还在7月17日周 FANZA 视频榜列第1。
- 2021年作品《童貞君の成績と射精を徹底管理してくれる世話焼き家庭教師の献身的筆おろし講習 架乃ゆら》于2023年12月11日周重回 FANZA 视频榜第8；同月25日周，VR 作《彼女に振られ引きこもっていたら… 僕のことが心配すぎておせっかいでセックス練習させてくれた筆おろしブラコンお姉ちゃん 架乃ゆら》初登场第10。
- 引退作《かのゆらすと 架乃ゆら》于2024年7月15日周在 FANZA 通贩榜初登场第6，次周升至第5。
- 演技评价较高，撰稿人鷲谷憲樹称其即兴台词与表情为「史上最高」，在 NTR 作品中尤为突出。
- 除AV外还出演原创视频、电影、舞台与网络剧，并发行多本写真集与数字写真。
