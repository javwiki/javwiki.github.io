# 楓カレン

日本AV女优、前写真偶像。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

楓カレン，1999年8月25日生于东京都，日本AV女优、前写真偶像，ライフプロモーション 所属。2018年9月以写真偶像身份出道，同年12月作为アイデアポケット（IdeaPocket）创立20周年纪念女优，以该片商专属身份AV出道。

2021年4月《周刊アサヒ芸能》「2021现役AV女优SEXY总选举」列第9位；8月「FLASH 2021性感女优排行」读者投票第23位，同月与9月连续登上 FANZA 租赁区月间女优排行第1位。她并未参与业界奖季的角逐，却被视为アイデアポケット的台柱。

2022年3月28日，她在 Twitter 上宣布引退。2023年4月20日以「田中レモン」名义在 FALENO 专属再出道，所属エイトマン，发行5部作品，台湾等地报道称与楓カレン为同一人。同年6月27日她以楓カレン名义宣布完全复出，重回ライフプロモーション；11月14日发售复归作并回到アイデアポケット专属；12月获「アサ芸AV大賞2023」回归大奖。2024年4月，《周刊アサヒ芸能》「2024现役AV女优性感总选举」列综合第3位。

## 人物

- 东京都出身；特长是料理，尤其拿手肉じゃが（土豆炖肉），主食则是粗点心。
- 公开表示憧憬的AV女优是桥本ありな，常被评价相貌近似女演员川口春奈；写真偶像时期憧憬的是中村静香。
- 饲养一只狆犬「うし」和一只异国短毛猫「かに」。
- 外表之外是动画迷，曾经常去アニメイト，因在店内接触 BL 作品，此后把读 BL 漫画当作兴趣。
- 长期留长发，2023年再出道时改为短发。
- 日本国内有「女版・吉村卓」的异名；华语圈写作「楓花戀」，台湾因其神似川口春奈而以「暗黑版川口春奈」报道。
- 搞笑艺人青柳貴哉评价她「外表清纯，却会算计好小梗时不时抛出来」。
- ゴールデンボンバー 的鬼龍院翔公开表示是其粉丝，称她的复出「就像解散的乐队突然重组，日本还有梦」。

## 作品特征

- 出道即为アイデアポケット专属，契机是该片商创立20周年纪念女优；2023年复出后仍为该片商专属。
- 作品中有单体作与共演作，维基另列多部 VR 作品，2024年发行8K VR长片。
- 2023年2月13日周，《楓カレン-純美の終焉- COMPLETE BEST 48時間BOX 豪華37作品12枚組》登 FANZA 通贩周榜第1。
- 2025年1月13日周，与新ありな共演的《楓カレンと新ありな。最強のふたり。女神ハーレム 今世紀最も美しいお姉さんに挟まれ痴女られSpecial》FANZA 通贩周榜初登场第3，并进入アサヒ芸能「2025年最も売れたAVはコレだ!!」年度第18位。
- 除AV外发行多部形象视频与写真集（2019年至2026年共6册），并出演电视综艺与游戏角色。
