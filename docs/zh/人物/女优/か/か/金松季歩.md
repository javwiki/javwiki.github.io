# 金松季歩

日本AV女优、前写真偶像，AKB48前研究生。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

- **日文名**: 金松 季歩
- **读音**: かねまつ きほ
- **英文名**: Kiho Kanematsu
- **别名**: 金子さとみ、金子智美（旧艺名，读音均为 かねこ さとみ）
- **出生日期**: 1989年12月22日

## 简介

金松季歩，1989年12月22日生于爱知县丰桥市，日本AV女优、前写真偶像，AKB48前研究生（4期生）。旧艺名为金子さとみ、金子智美，两者读音均为「かねこ さとみ」。她2007年通过AKB48第一期研究生（4期生）甄选，但在同年11月15日之前辞退，研究生时期未曾登台。此后她以金子さとみ名义于2010年主演V电影《マン・ハンティング》并首次裸体出镜，2014年转为写真偶像。

写真时期她于2017年7月18日获得「ミスアクショングランプリ2017」，2018年2月24日在东京电视台《ゴッドタン》的第1回「腐りグラドルグランプリ」中夺冠。经纪事务先后由 PIGROOM（至2020年7月31日）、リップ（2020年9月1日至2023年6月24日）经手；2021年10月发售的写真集《美しい人》在一周内重版。2023年6月24日，她宣布同月末退出リップ并引退，25日举行引退式。

2024年2月27日，她改名为金松季歩，并在光文社《FLASH》的写真与访谈中复出；3月5日宣布于4月2日由 MUTEKI 发行AV出道作《18Gold》。同年6月11日她宣布成为 S1 专属女优、7月9日发行 S1 出道作，同时开设 YouTube 频道「KIHO Channel」，公布 Bstar 所属与7月18日首本裸体写真集。2024年12月24日，她在《FLASH》独自统计的「FLASHセクシー女優ランキング2024」中列第4位；2025年10月号《月刊FANZA》的「FANZA2025年上半期女優ランキング」列第5位。

## 人物

- 自称不擅长即兴表演（アドリブは苦手）。
- 初体验为19岁，对象是打工处认识的人。
- 媒体多称她为「元AKB」，但她表示自己「不是配得上这个头衔的人」，很早就停用该称呼。
- 研究生时期一次也未登台，首次以歌手身份登台是改用金松名义后的2025年5月26日；2026年4月8日的个人演唱会中首次演唱AKB48的《夕陽を見ているか?》。
- 写真时期因影像作品的尺度遇到瓶颈，曾把AV当作教材观看，研究哪些情境与设定受欢迎。
- 21岁时曾被AKB时期起照顾她的人带到AV事务所，临门止步；她后来回顾称当时被骗、受到某种程度的洗脑。
- 宣布引退时表示「『リタイア』这个词最贴切」；另一篇访谈中说，「18禁グラドル」的形象过于普及，一般写真偶像的工作邀约锐减，因而决定为写真活动划下句点。
- 2024年复出时曾因「34岁这个年龄」而犹豫，最终表示「相信在写真上努力了8年的自己」，并称「找到了自己的天职」。
- 艺名由她本人决定：为保留旧名而留下「金」字，取金銀銅与松竹梅皆居首位之意合成「金松」；「季歩」则因憧憬两字名并参考姓名判断。
- 父亲在铁工厂工作，母亲为家庭主妇，有姐姐与哥哥，哥哥是舞者。
- AV撰稿人兼制片人いんごま认为她的魅力除「美人、笑容、身材」外，还在于敢正面迎向难题的「豪胆」。

## 作品特征

- AV出道作《18Gold》（2024年4月2日、MUTEKI）以「写真影像的延长战」为设定，刻意不加入访谈段落。
- 2024年7月起为 S1 NO.1 STYLE 专属，作品以「グラビア芸能人」系列为轴，题材涵盖上司、不伦、教师、痴汉等成人向设定。
- 2024年至2025年参与 S1 20周年纪念的大型共演，与河北彩伽、本郷愛、七ツ森りり等多人同作。
- 2026年出现跨厂牌共演：与長浜みつり的アイデアポケット作品、MOODYZ 创立25周年纪念作（与九野ひなの、桜空もも、伊藤舞雪）。
- 除AV外持续发行写真集与数字写真，并出演电视剧、综艺、广播及 Netflix《デスキスゲーム》。
- VR作品自2024年起陆续发行，包括「VR NO.1 STYLE」系列。
