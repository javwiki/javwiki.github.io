# 森日向子

日本成人影像演员。下列出道信息按所列来源记录，不以排名替代人物资料。

## 简介

森日向子，2000年9月9日生，三重县出身，NAXプロモーション所属。2020年6月在 SODクリエイト 的「KMHR（キミホレ）」厂牌以专属女优出道，出演3部作品后转为企划单体，同月入围讲谈社「ミスiD2021」准决赛。2021年4月发行写真集《僕のわがまま》，2024年9月出任 FANZA／HHHグループ「トリプルハッピーキャンペーン2024」宣传女孩，12月在电影《みゆきの結婚》首次主演。2025年4月起成为 MOODYZ 内厂牌「きれいなお姉さんは好きですか」的专属女优。另以「朝比奈えみり」名义出演写真影像。

## 作品特征

- 出道作为 SODクリエイト「KMHR」厂牌的专属作品，3部后转企划单体，此后跨厂牌出演并参与合集与 VR 企划。
- 作品设定包括地雷系女子（《僕の可愛い彼女は地雷系女子◆□》）、唾液与接吻、寸止め射精控制等；2025年起在 MOODYZ 的「きれいなお姉さんは好きですか」厂牌出演。
- 以「朝比奈えみり」名义出演写真影像，如《ミス○教大学でモデル衝撃のデビュー》（2021-01-29）。
- 2024年4月至7月连续进入 FANZA 视频月度女优排行前十（5位、9位、4位、7位）。
