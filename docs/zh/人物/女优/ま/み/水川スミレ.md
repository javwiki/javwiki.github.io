# 水川スミレ

日本前AV女优。以下资料据日文维基百科与所列来源整理，排名不作为人物资料使用。

## 简介

水川スミレ，1994年2月3日生，大阪府堺出身，日本AV女优，LINX 所属。她在不良与搞笑艺人环绕的环境中长大，17岁离开家，先在大阪ミナミ做陪酒女郎，2016年4月以「水稀みり」名义作为プレステージ专属女优AV出道；当时的公开资料写作1996年5月5日生、京都府出身。

2017年11月15日，她以「水喜れい」名义另开 Twitter，并报告为拓宽活动范围而更换事务所、改名，最初隶属ロックオン，后转投カロスエンターテインメント。2018年1月10日再以「水川スミレ」名义开设 Twitter，转属 LINX 并改名；该版资料写作1995年2月3日生、大阪府出身。同年起她也在海外活动。

2020年8月起开设 Podcast 节目「MI SO HORNY」，进入总榜前100，并因性教育内容被文春Online报道。2021年起移居美国，与通过社交平台认识、交往数年的美国男性结婚；婚后发现对方是她所称「史上最糟的精神病态者」，遂逃回日本，但离婚手续尚未办完。2023年11月，她凭《Madonna電撃専属 真正痴女 水川スミレ 深く濃厚な接吻と寸止め中出しでM男クンを身も心もトロけさせる無限射精オーガズム》成为マドンナ专属女优。

2026年1月6日，台湾《自由时报》报道她将自日本国内的适正AV作品毕业、把活动据点转向海外；3月9日她在本人 X 上发布引退作拍摄的消息。3月27日至29日，她出席在台湾桃园会展中心（メッセ桃園）举办的成人展 ADULTOPIA，并获 BEST POPULAR ACTRESS（XCITY 最优秀人气女优奖）。7月8日，她在 Instagram 宣布结婚与引退，并以「Sorry…officially sold out.」「完売」表述。

## 人物

- 兴趣是唱卡拉OK。高中1年级的春天，与初中时在 Skype 认识的23岁社会人男性初体验。
- 与陪酒女郎出身的影响者みゆう在入行前、十几岁后半起就是好友，称对方为「姐姐」。
- 家人对她的工作知情且不避讳，父亲曾在 AbemaTV《給与明細》中受访；另有一次其他AV拍摄偶然使用了父亲经营的店铺。
- 撰稿人芝田カズ称她肌肉线条恰到好处，53厘米的腰身引人注目；演员渋江譲二则指出她约七成作品为痴女题材，并谈及她的妖艳外形。
- 擅长骑乘位：她自述前后摆动的研磨式最容易高潮，但观众偏爱上下起落的打桩式，因此作品中多半先以研磨式满足再转打桩式。渋江譲二也提到她能长时间高速摆动。
- 艺名与公开资料几经变更，出生年有1994年与1995年两说，出道时的资料更写作1996年。

## 作品特征

- 出道时为プレステージ专属，2023年11月起为マドンナ专属；作品横跨单体作、共演作与 VR、配信作。
- 痴女题材占比高，渋江譲二估计约为七成。
- 2020年10月26日发行写真集《甘い密と甘い罠》；另发行2017年、2018年日历与多款原创周边。
- 2024年11月发行的合辑《MOON FORCE CHEERS ぱこぱこしろうとコレクション。 ベリーベストオブベスツッ！》在2026年1月5日周升至 FANZA 视频区第1。
- 除AV外出演电视综艺、AbemaTV 节目与两部 op 电影，并主持 Podcast「MI SO HORNY」。
