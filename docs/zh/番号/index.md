# 番号系统

番号是 JAV 作品的识别编号，通常由片商、厂牌或发行渠道设定。百科条目中的"参演作品"以番号作为主键，便于检索、去重和跨站点核对。

## 基本结构

常见番号一般由"字母前缀 + 数字序号"组成：

```text
IPZ-901
```

其中：

- `IPZ` 为前缀，通常对应片商、厂牌或发行系列。
- `901` 为序号，通常表示该系列下的发行顺序。
- 中间的连字符 `-` 是常见写法，但不同站点也可能写作 `IPZ901`。

## 常见类型

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 有码番号 | IPZ-901、MIDE-123、SSIS-001 | 日本主流片商发行的有码作品编号。 |
| 无码番号 | HEYZO-1168、CARIB-012516-001 | 无码片商或海外发行站点使用的编号。 |
| FC2 编号 | FC2-PPV-1234567、FC2-1234567 | FC2 PPV 作品编号，常以数字 ID 为核心。 |
| 合集/精选 | BEST、総集編、COMP 等 | 有时沿用原片商番号，有时使用合集专属编号。 |
| 流媒体编号 | 041614_791、1PONDO-012516_001 | 可能包含日期、下划线或平台内部 ID。 |

## 前缀与片商

番号前缀并不总是等同于片商名称。它更常表示某个片商旗下的厂牌、系列或发行线。例如同一片商可能同时使用多个前缀，不同年代也可能更换命名规则。

常见对应关系示例：

| 前缀 | 常见关联 |
| --- | --- |
| IPZ、IPX | IdeaPocket |
| SSIS、SSNI | S1 NO.1 STYLE |
| MIDE、MIDV | MOODYZ |
| ABP、ABW | Prestige |
| ATID、SHKD、RBD | Attackers |
| ADN | 本中、溜池ゴロー、Attackers 等剧情系厂牌中均可能出现，需结合发行信息判断。 |
| JUL、JUQ | Madonna |
| WANZ | Wanz Factory |
| FSDSS | FALENO |
| HMN、HUNBL | 本中 |

## 录入规范

百科中录入番号时建议遵循以下规则：

- 使用大写字母前缀，例如 `IPZ-901`，避免写成 `ipz-901`。
- 保留官方或主流资料站常用的连字符，例如 `IPZ-901`。
- FC2 作品优先写作 `FC2-PPV-数字`；若资料源仅写 `FC2-数字`，可沿用原写法。
- 不确定片商时只录入番号和标题，不强行推断归属。
- 合集作品可录入，但标题中应尽量标明"合集""精选"或主要共演者。
- 同一作品出现不同写法时，以主流资料站或片商官网写法为准。

## 检索建议

检索番号时可以同时尝试以下写法：

```text
IPZ-901
IPZ901
ipz 901
```

部分站点会省略连字符，或将下划线、日期编号改写为不同格式。遇到无法检索的作品，可以先确认前缀是否属于同一厂牌，再用女优名、标题关键词和发行日期交叉检索。

## 注意事项

- 番号只能标识作品，不等同于演员身份或片商归属。
- 同一女优可能跨片商、跨厂牌出演，因此条目中的作品列表应以作品本身为准。
- 旧作、重发版、合集版可能复用素材但使用新番号，录入时应避免把合集误当作原始首发作品。
- 无码平台、海外平台与 FC2 的编号规则差异较大，不能直接套用有码片商的前缀逻辑。
