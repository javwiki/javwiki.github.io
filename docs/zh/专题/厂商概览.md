# 厂商概览

公司、厂牌和销售平台是不同的记录对象。品牌官网能够确认作品目录和品牌名称，但不能单独证明持股关系、成立年份或演员的现行专属合约。

## 公司资料

WILL 官网记载现法人成立日为2016年7月13日。北都／CA 的业务沿革应另按历史来源记录，不能将品牌历史等同于现法人年龄。 [WILL](https://will-hp.jp/company/)

SOD 公司信息分别列出 Soft On Demand（1995年11月成立）和 SOD Create（1999年3月成立）；前者的销售业务与后者的制作业务应区分。 [SOD](https://corporate.sod.co.jp/about_us/info/)

Prestige 的企业招聘页记载有限会社プレステージ成立于2002年5月。各品牌与该公司的关系仍需具体发行记录支持。 [Prestige](https://arwrk.net/recruit/prestige-av/)
