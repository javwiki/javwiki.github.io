# 売春防止法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 売春防止法 |
| 法令番号 | 昭和31年法律第118号 |
| 施行 | 1957年4月1日 |
| 所管 | 厚生労働省 |

## 概要

売春防止法是日本为防止卖淫而制定的法律。虽然该法并不直接适用于AV行业，但作为与性风俗产业相关的法律，对AV行业的规范具有一定参考意义。

## 主要内容

### 禁止行为

- 卖淫（以有偿性交为目的的行为）
- 介绍卖淫
- 强迫卖淫
- 组织卖淫

### 处罚

- 违反者可能面临刑事处罚
- 介绍卖淫同样受到处罚

## 与AV行业的关联

AV出演与卖淫在法律性质上是不同的行为，但两者都涉及性行为的商业利用。该法明确了有偿性交易的违法性边界，为区分合法AV出演与非法性交易提供法律依据。
