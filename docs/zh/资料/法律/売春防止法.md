# 売春防止法

| 项目 | 内容 |

| 全面施行 | 1958-04-01（第2章等） |

## 概要

第2条将卖淫定义为收受或约定收受报酬，与不特定对象进行性交。第3条禁止卖淫及成为其对方，但并未仅为违反第3条的行为设定直接罚则；第2章另对招徕、介绍、强迫及经营等具体行为规定处罚。

## 与AV行业的关联

不能将所有有报酬的性行为自动等同于本法定义的卖淫，也不能仅凭作品以AV名义拍摄认定其合法。判断应结合第2条的构成条件、实际行为及其他适用法律。
