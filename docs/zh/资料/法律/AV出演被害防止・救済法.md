# AV出演被害防止・救済法

## 概要

本法于2022年6月23日施行，规范法定“性行为影像制作物”的出演合同，保护不分性别、年龄的出演者。是否适用应按第2条的定义及合同情况判断，不能仅按“正规”“个人拍摄”等发行标签认定。

## 制作方义务

- 签约时交付合同及说明文书，并说明规定事项。
- 合同及说明文书交付后至少等待1个月才能拍摄；出演者可以拒绝拍摄或不愿进行的行为。
- 全部拍摄结束后至少等待4个月才能公开，并给予出演者公开前确认影像的机会。

## 合同解除与停止公开

出演者可在拍摄前及拍摄后至公开前无条件解除合同；公开后的期限见下表。这是法定合同任意解除制度，不宜简化为笼统的“撤回出演同意”。

| 签约日期 | 公开后任意解除期限 |
| --- | --- |
| 2022-06-23～2024-06-22 | 公开后2年内 |
| 2024-06-23～2025-06-22 | 公开后1年或2026-12-22，以较晚者为准 |
| 2025-06-23起 | 公开后1年内 |

2022年6月22日以前签订的合同不适用本法的合同取消或解除制度，但内阁府说明仍可请求禁止公开拍摄的性行为影像。取消或解除后、或者没有合同却公开时，可请求停止销售或配信；不同救济各有适用条件。

## 法律责任

本法罚则针对妨碍任意解除的不实告知、威迫，以及未交付规定文书或记载不实内容等特定行为；不能概括为所有违反本法义务均受同一种处罚。第5章罚则自2022年7月12日起施行。

## 咨询与支援

`#8891` 是性犯罪、性暴力受害者一站式支援中心的全国共通短号，受理包括AV出演被害在内的咨询，并非AV专用电话。相关解除通知范本和停止配信请求资料见内阁府页面。
