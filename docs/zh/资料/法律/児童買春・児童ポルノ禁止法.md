# 児童買春・児童ポルノ禁止法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 児童買春、児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律 |
| 法令番号 | 平成11年法律第52号 |
| 施行 | 1999-11-01 |

## 概要

第2条将儿童定义为未满18岁者。该法规范并处罚儿童买春及涉及真实儿童的儿童色情影像等行为，同时规定儿童保护措施。儿童色情的制造、提供及以满足自身性好奇心为目的的持有等，各有法定构成条件。

## 与AV行业的关联

民法成年年龄下调不改变本法的未满18岁标准。作品标题、虚构角色年龄或制服造型不能单独证明演员实际年龄；判断是否属于儿童色情须结合真实拍摄对象与内容。
