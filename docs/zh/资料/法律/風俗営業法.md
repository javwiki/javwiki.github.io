# 風俗営業法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 風俗営業等の規制及び業務の適正化等に関する法律 |
| 法令番号 | 昭和23年法律第122号 |
| 施行 | 1948-09-01 |

## 概要

该法对风俗营业及性风俗相关特殊营业等按营业类型规定许可、申报、营业区域和未成年人保护等制度。原法于1948年施行，现行规定经历多次修订。第2条区分风俗营业、店铺型及无店铺型性风俗相关特殊营业、影像发送型性风俗特殊营业等。

## 与AV行业的关联

不能概括为“所有AV制作与发行都须取得风营许可”。第2条第7、8项和第31条之2、第31条之7等分别涉及成人影像销售或出租、影像发送业务的定义及申报；是否适用须核对实际营业类型。
