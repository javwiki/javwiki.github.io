# 困難女性支援法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 困難な問題を抱える女性への支援に関する法律 |
| 法令番号 | 令和4年法律第52号 |
| 施行 | 2024-04-01 |

## 概要

该法以女性的福祉、人权尊重及男女平等为基础，建立根据个人意愿和处境提供综合支援的制度。第2条的对象包括因性侵害、家庭状况或社会关系等因素难以维持日常或社会生活的女性，以及有此风险的女性。

## 与AV行业的关联

出演经历带来的性侵害、暴力或生活困境可成为寻求咨询的背景。支援由女性咨询支援中心等机构依具体需求协调，不能仅凭出演身份推定一定获得某项补助。
