# リベンジポルノ防止法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 私事性的画像記録の提供等による被害の防止に関する法律 |
| 法令番号 | 平成26年法律第126号 |
| 施行 | 2014-11-27 |
| 分阶段施行 | 第3条罚则：2014-12-17；第4条：2014-12-27 |

## 概要

该法针对可识别拍摄对象的私事性影像被向不特定或多数人提供、公开展示，以及为此目的提供影像的行为设定刑事责任，并规定网络删除相关制度。并非所有未经同意转发的影像都属于本法定义。

## 与AV行业的关联

警察厅明确说明：拍摄对象知道影像将被第三人观看并同意拍摄的影像（如AV、写真）排除在“私事性的画像记录”之外。出演者的私人影像仍需按实际拍摄情况判断；公开作品的发行争议不能直接套用本法，应结合AV新法等制度核查。
