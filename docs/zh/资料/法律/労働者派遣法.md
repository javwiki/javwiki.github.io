# 労働者派遣法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 労働者派遣事業の適正な運営の確保及び派遣労働者の保護等に関する法律 |
| 法令番号 | 昭和60年法律第88号 |
| 施行 | 1986-07-01 |

## 概要

劳动者派遣的法定定义，核心为使自己雇用的劳动者在雇用关系持续期间，接受他人指挥命令为其劳动。该法规范派遣事业及派遣劳动者保护；适用与否依据实际雇用和指挥命令关系判断。

## 与AV行业的关联

出演合同、经纪合同或“模特”名称不会自动成立劳动者派遣关系。应先核查谁雇用出演者、谁指挥工作，再结合本法及职业安定法判断。
