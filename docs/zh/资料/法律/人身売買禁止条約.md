# 人身売買禁止条約

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 人身売買及び他人の売春からの搾取の禁止に関する条約 |
| 联合国大会通过 | 1949-12-02 |
| 国际生效 | 1951-07-25 |
| 日本加入书交存 | 1958-05-01 |

## 概要

本条约针对为满足他人欲望而促成他人卖淫、从他人卖淫中获利，以及经营或资助妓院等行为。联合国条约集记录日本于1958年5月1日加入；加入书交存日期与国际生效日期应分别标注。

## 与AV行业的关联

本条约不能与2000年通过的“人身取引议定书”（巴勒莫议定书）混称。外务省记录日本于2017年7月11日交存该议定书的受诺书。AV出演涉及欺骗、胁迫时，应依据具体行为和适用国内法判断，不能仅以行业身份认定人口贩卖。
