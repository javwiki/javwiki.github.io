# 職業安定法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 職業安定法 |
| 法令番号 | 昭和22年法律第141号 |
| 施行 | 1947-12-01 |

## 概要

该法规范职业介绍、劳动者募集、募集信息提供及劳动者供给等。职业介绍与劳动者派遣不是同一制度；劳务派遣另受劳动者派遣法规范。第44条原则上禁止劳动者供给，第45条设定例外，第63条涉及以强迫手段介绍劳动及有害业务的介绍等处罚。

## 与AV行业的关联

经纪公司的招募和介绍行为是否违反本法，要结合业务性质、介绍过程及实际工作内容判断。不能仅凭“经纪公司”名称或出演合同标签认定合法或违法。
