# FANZA 成人奖

FANZA 成人奖（FANZAアダルトアワード）是 FANZA（原 DMM.R18）举办的 AV女优及作品评选，2014年开始举办，2019年使用 FANZA 名称。2019年的个人奖以平台销售数据选出候选人，再由用户投票等方式评选。颁奖典礼于2019年5月12日在东京新木场 STUDIO COAST 举行。[2019年报道](https://www.art-techne.com/entertainment/news201905151345.amp)

名称变迁：

- 2014年：DMMアダルトアワード
- 2015–2018年：DMM.R18アダルトアワード
- 2019年：FANZAアダルトアワード

截至2026-10-20，本页核查未找到2020年以后的正式举办记录；不据此推定永久停办或具体原因。
