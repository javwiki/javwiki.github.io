# 奖项

本节收录日本AV行业相关奖项，以及台湾 ADULTOPIA 颁奖记录。个人奖、作品奖与宣传成员选拔分别说明。

## 主要奖项

| 奖项 | 本站收录范围 | 说明 |
| --- | --- | --- |
| [FANZA 成人奖](fanza.md) | 2014–2019年主要个人奖、2019年详细结果 | 原名 DMM／DMM.R18 成人奖；作品奖与个人奖分列 |
| [成人广播奖](skypa.md) | 2006–2020年女优奖、2020及2022年结果、2022–2024年 EXガールズ | EXガールズ 是宣传组合，成员选拔与历史个人奖分别记录 |
| [ADULTOPIA 大人国](ADULTOPIA.md) | 2026年颁奖典礼17个类别 | 台湾颁奖活动，含演员、导演及作品类别；典礼与展览互动活动日期分列 |

## 相关作品竞赛

[AV OPEN](https://av-open.com) 是另一项 AV作品竞赛，不能与 FANZA 成人奖混用。关于2018届的当年报道说明，该届跨年举办，结果于2019年5月发表，粉丝投票涵盖作品奖、女优奖及 VR-1 Grand Prix 作品奖。[TECHNÉ 报道](https://www.art-techne.com/entertainment/news201902030015.html)
