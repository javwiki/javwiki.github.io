# 成人广播奖（スカパー!アダルト放送大賞）

成人广播奖（スカパー!アダルト放送大賞）是日本成人向卫星广播领域的评选，2005年开始举办。历史上的女优奖、新人女优奖等个人奖，与后来为 SPOOX EX 等服务宣传的 EXガールズ 成员选拔，应分别记录。

## 奖项类别

### 个人奖项（2006-2020）

| 奖项 | 说明 |
| --- | --- |
| 女优奖 | 年度最佳 AV 女优 |
| 新人女优奖 | 年度最佳新人女优 |
| 熟女女优奖 | 年度最佳熟女系女优 |
| 最多出演女优奖 | 年度作品数量最多的女优 |
| 媒体赏 | 各媒体颁发的奖项 |
| スカパー!オンデマンドアダルト赏 | 点播部门最佳女优 |

## EXガールズ（已核实的2022–2024年记录）

2022年本郷愛在获得 MVA 后，加入波多野結衣、篠田ゆう组成的宣传组合。2023年官方将评选大幅改为试镜企划，经审查及粉丝投票决定一名中心成员和两名成员。2024年报道确认第三代四名成员及6月26日的亮相活动；这些宣传成员身份不等于传统的女优奖。[2022年报道](https://www.nikkansports.com/entertainment/news/202203140000428.html)、[2023年官方报道](https://note.com/sptv_note/n/n34b625094de0)、[2024年活动报道](https://www.menscyzo.com/2024/05/post_227377.html)

| 年份 | 成员 |
| --- | --- |
| 2022 | 波多野結衣、篠田ゆう、本郷愛（MVA） |
| 2023 | 夏目響（センター）、有村のぞみ、宮沢ちはる |
| 2024 | 川上ゆう、新村あかり、森沢かな、吉根ゆりあ |

核查日期：2026-10-20。此表仅列出已核实的代际记录，不表示每年持续举办同一种奖项；未核实的2025、2026年成员不作补列。
