# Data site accessibility test

Tested on 2026-10-31 from the current environment with `curl` (desktop Chrome user agent, 25-second timeout). Besides the HTTP status, each page was checked for Cloudflare verification, age confirmation and regional restriction, so that a "200 but blocked" page is not mistaken for usable.

## Criteria

- **Accessible**: returns 200 and shows real content rather than a verification page.
- **Age confirmation**: returns 200 but the content is hidden behind an age-confirmation page.
- **Cloudflare block**: returns 403 with a browser-verification page.
- **Regional restriction**: returns 200 but says the service is unavailable in the region.

## Usage notes

- JAVDatabase's "titles listed" is that site's coverage, not the total number of works; its Debut field does not state whether it means streaming or physical release, so it is a secondary record only.
- JAVDatabase sometimes treats different stage names as one person; figures must be kept alongside Wikipedia or agency profiles rather than overwriting them.
- Both Seesaa sites are fan-edited wikis, and name-change or alias identifications have not been confirmed by the subject or an agency. Their pages are EUC-JP and need conversion when fetched.
- JavDB actor pages give only title counts and title lists, with no height, measurements or other profile fields.
- Official agency pages are best for verifying affiliation and profiles, though some have age confirmation; label pages (Madonna, MOODYZ, DMM) are currently all behind age confirmation.
- The results reflect only the current network environment and must be retested if site policies change.
