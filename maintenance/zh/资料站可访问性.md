# 资料站可访问性实测

2026-10-31 在当前环境用 `curl` 实测（UA 为桌面 Chrome，超时 25 秒），除 HTTP 状态外还检查页面是否出现 Cloudflare 验证、年龄确认或地区限制，避免把「返回 200 的拦截页」误判为可用。

## 判定标准

- **可访问**：返回 200，且页面为实际内容而非验证页。
- **年龄确认**：返回 200，但内容被年龄确认页遮挡。
- **Cloudflare 拦截**：返回 403，页面为浏览器验证。
- **地区限制**：返回 200，但提示所在地区不可用。

## 使用注意

- JAVDatabase 的「收录作品数」是该站覆盖量，不等于作品总数；Debut 字段未注明配信或实体口径，只能作二手记录。
- JAVDatabase 存在把不同艺名混为同一人的情况，数值必须与维基百科或事务所档案并列保留，不能直接覆盖。
- Seesaa 两站均为爱好者协作 wiki，改名与别名对应未经本人或事务所确认；页面为 EUC-JP，抓取时需转码。
- JavDB 的演员页只有作品数与作品列表，没有身高、三围等档案字段。
- 官方事务所页最适合核实所属与档案，但部分页面有年龄确认；厂牌页（Madonna、MOODYZ、DMM）目前均被年龄确认页遮挡。
- 实测结果只代表当前网络环境，站点策略变化后需重新测试。
