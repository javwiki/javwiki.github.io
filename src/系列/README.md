# 系列

系列（Series）是 AV 厂商推出的固定标题系列作品，通常有统一的命名、封面风格或内容主题。同一系列下有多部作品，可能由不同女优出演。

## 系列与厂商的关系

系列通常隶属于某个厂商或厂牌，但不同厂商也可能有类似的系列命名。系列名不等于厂商名。
