# 厂商

JAV 厂商是作品的制作与发行方，不同厂商标代表不同的内容风格、制作品质和市场定位。了解主要厂商有助于快速判断作品类型和质量水准。

## 主要厂商

### S1 NO.1 STYLE

- **简称**: S1
- **所属**: エスワン ナンバーワンスタイル
- **特点**: 业界顶级厂商，以高品质制作和顶级女优阵容著称
- **风格**: 纯粹美少女系、清纯派、高品质制作
- **知名女优**: 三上悠亚、桥本有菜、河北彩花、石川澪、葵司等

### Moodyz

- **简称**: MD
- **所属**: ムーディーズ
- **特点**: 业界最大厂商之一，作品数量庞大，旗下有多个子品牌
- **风格**: 多元化，涵盖各种题材
- **知名女优**: 深田咏美、枫花等

### IdeaPocket

- **简称**: IP
- **所属**: アイデアポケット
- **特点**: 以高品质制作和美少女系著称
- **风格**: 美少女系、恋人感、高品质
- **知名女优**: 桃乃木香奈、希岛爱理等

### Attackers

- **简称**: AT
- **所属**: アタッカーズ
- **特点**: 以剧情向和凌辱系作品著称
- **风格**: 剧情向、凌辱系、暗黑系
- **知名女优**: 莲实克蕾儿等

### Prestige

- **简称**: PG
- **所属**: プレステージ
- **特点**: 以素人系和企划向作品著称
- **风格**: 素人系、企划向、多元化
- **知名女优**: 七泽美亚、小野六花等

### Madonna

- **简称**: JU
- **所属**: マドンナ
- **特点**: 以熟女系和人妻系作品著称
- **风格**: 熟女系、人妻系、剧情向
- **知名女优**: 风间由美、白石茉莉奈等

### Wanz Factory

- **简称**: WF
- **所属**: ワンズファクトリー
- **特点**: 作品风格多元化
- **风格**: 多元化，涵盖各种题材
- **知名女优**: 由爱可奈等

### FALENO

- **简称**: FL
- **所属**: ファレノ
- **特点**: 新兴厂商，以高品质制作著称
- **风格**: 高品质制作、多元化
- **知名女优**: 楪可怜、吉高宁宁等

### 本中

- **简称**: HM / HN
- **所属**: 本中
- **特点**: 以中出系作品著称
- **风格**: 中出系、剧情向

### SOD (Soft On Demand)

- **简称**: SOD
- **所属**: SODクリエイト
- **特点**: 以创意企划和素人系作品著称，旗下有多个子品牌
- **风格**: 企划向、素人系、创意丰富
- **知名女优**: 户田真琴、本庄铃等

### E-BODY

- **简称**: EB
- **所属**: E-BODY
- **特点**: 以身材出众的女优著称
- **风格**: 身材重视、巨乳系
- **知名女优**: 冲田杏梨等

### kawaii*

- **简称**: KW
- **所属**: カワイイ
- **特点**: 以可爱系、清纯系女优著称
- **风格**: 可爱系、清纯派、年轻系
- **知名女优**: 未步奈奈等

### MUTEKI

- **简称**: MK
- **所属**: MUTEKI
- **特点**: 无码厂商转有码的专属平台，出道作品关注度高
- **风格**: 新人出道、无码转有码
- **知名女优**: 曾为多位知名女优的出道平台

### MAXING

- **简称**: MX

- **特点**: 以多元化作品著称
- **风格**: 多元化、高品质

### MAX-A

- **简称**: MA
- **所属**: マックス・エー
- **特点**: 老牌厂商，以美少女系著称
- **风格**: 美少女系、清纯派

### Alice Japan

- **简称**: AK
- **所属**: アリスJAPAN
- **特点**: 老牌厂商，作品风格多元
- **风格**: 多元化、经典系

## 厂商分类

### 按内容类型

| 类型 | 代表厂商 | 特点 |
| --- | --- | --- |
| 美少女系 | S1、IdeaPocket、kawaii* | 清纯派、高品质制作 |
| 剧情向 | Attackers、Madonna | 剧情丰富、演技要求高 |
| 企划向 | Moodyz、Prestige、SOD | 题材多元、创意丰富 |
| 熟女系 | Madonna | 熟女、人妻题材 |
| 中出系 | 本中、ダスッ! | 中出题材 |
| 身材系 | E-BODY | 身材重视、巨乳系 |

### 按制作品质

| 等级 | 代表厂商 | 特点 |
| --- | --- | --- |
| 顶级 | S1、IdeaPocket | 高品质制作、顶级阵容 |
| 一线 | Moodyz、Prestige、Attackers、FALENO | 稳定品质、丰富题材 |
| 二线 | 其他厂商 | 题材多元、价格亲民 |

## 厂商与女优关系

### 专属女优

部分女优会与特定厂商签订专属合约，只在该厂商发行作品。专属女优通常能获得更好的资源和推广。

### 非专属女优

多数女优为非专属状态，可以在多家厂商发行作品。这种情况下，女优的作品风格会更加多元化。
