# JAV 百科

JAV（日本成人视频）综合百科。

## 索引方式

本百科的女优条目按**五十音**的行归类：

| 行 | 段 |
|---|---|
| **あ行** | あ い う え お |
| **か行** | か き く け こ（含 が ぎ ぐ げ ご） |
| **さ行** | さ し す せ そ（含 ざ じ ず ぜ ぞ） |
| **た行** | た ち つ て と（含 だ ぢ づ で ど） |
| **な行** | な に ぬ ね の |
| **は行** | は ひ ふ へ ほ（含 ば び ぶ べ ぼ、ぱ ぴ ぷ ぺ ぽ） |
| **ま行** | ま み む め も |
| **や行** | や ゆ よ |
| **ら行** | ら り る れ ろ |
| **わ行** | わ を ん |

每个条目以其姓名的**首个假名**所在段归入对应子目录。例如：

- 朝桐光 → あ行 → **あ**段 → [`あ/あ/朝桐光`](./あ/あ/朝桐光.md)
- 波多野結衣 → は行 → **は**段 → `は/は/波多野結衣`
- 三上悠亜 → ま行 → **み**段 → `ま/み/三上悠亜`
- 吉沢明歩 → や行 → **よ**段 → `や/よ/吉沢明歩`
