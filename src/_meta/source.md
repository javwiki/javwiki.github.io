## 使用规范

### 女优信息采集

| 信息类型 | 推荐来源 | 备注 |
| --- | --- | --- |
| 基本资料（姓名、生年月日、身長等） | Wikipedia、JAVDB、Xslist | 以维基百科为主，其他来源交叉验证 |
| 三围、罩杯 | 各厂商官网、JAVDB、minnano-av | 不同来源数据可能有差异 |
| 所属事务所 | Xslist、JAVDB、厂商官网 | 事务所信息变动频繁，注意时效性 |
| 专属厂商 | 厂商官网、JAVDB | 以厂商官网为准 |
| 出道日期 | Wikipedia、JAVDB、厂商官网 | 以出道作品发售日为准 |
| 引退/活动状态 | Twitter/X、Wikipedia、JAVDB | 以本人公开发言为准 |
| 获奖记录 | Wikipedia、FANZA 官网 | 以官方网站公布为准 |
| 经历年表 | Wikipedia | 日语维基百科通常最详细 |
| 写真/形象照 | Instagram、Twitter/X、厂商官网 | 官方渠道优先 |

### 信息验证

- 多源交叉验证，确保准确性
- 官方来源优先
- 注意时效性，优先使用最新数据

### 引用格式

维基百科:
```
- <https://ja.wikipedia.org/wiki/女優名>
- <https://zh.wikipedia.org/wiki/女優名>
```

Wikidata:
```
- <https://www.wikidata.org/wiki/Q编号>
```

专业资料库:
```
- <https://www.iafd.com/女優名.rme>
- <https://javdb.com/女優名>
```
