# 五十音排序规则

本文档定义本百科女优目录系统与 `list.yaml` 的排序规则，确保条目索引、文件系统、列表文件三处一致。

## 五十音行段

目录结构使用**五十音图的两层索引**：

| 行 (row) | 段 (col) |
|----------|----------|
| あ行 | あ・い・う・え・お |
| か行 | か・き・く・け・こ |
| さ行 | さ・し・す・せ・そ |
| た行 | た・ち・つ・て・と |
| な行 | な・に・ぬ・ね・の |
| は行 | は・ひ・ふ・へ・ほ（含浊音 ば・び・ぶ・べ・ぼ、半浊音 ぱ・ぴ・ぷ・ぺ・ぽ） |
| ま行 | ま・み・む・め・も |
| や行 | や・ゆ・よ |
| ら行 | ら・り・る・れ・ろ |
| わ行 | わ |

浊音、半浊音分别归入所属行：
- **ば行** 属 **は行**（べ → は行・べ段）
- **ぱ行** 属 **は行**

## 女优的定位规则

每个女优由其**艺名的读音**决定所属行与段：

### 汉字名
按汉字的音读判断假名，再取**首假名**决定位置。

示例：
- 河北彩花（かわきた さいか） → 首字「か」→ か行・か段
- 相泽南（あいざわ みなみ） → 首字「あ」→ あ行・あ段
- 深田咏美（ふかだ えみ） → 首字「ふ」→ は行・ふ段

### 片假名 / 外来语名
按片假名实际发音读音，取**首假名**判断。

示例：
- ベアトリクス（べあとりくす） → 首字「べ」→ は行・べ段
- アイカ（あいか） → 首字「あ」→ あ行・あ段
- ミル（みる） → 首字「み」→ ま行・み段

### 混合名
汉字 + 假名混合，仍以整体读音的首假名判断。

示例：
- あずみ恋（あずみ れん） → 首字「あ」→ あ行・あ段

### 浊音 / 半浊音
浊音、半浊音按各自假名归类（ば・ぱ 归入 は行）。

- 读音以「ば・び・ぶ・べ・ぼ」开头 → は行 + 对应段
- 读音以「ぱ・ぴ・ぷ・ぺ・ぽ」开头 → は行 + 对应段

## list.yaml 结构

```yaml
title: 女优列表
items:
  - name: 女优名      # 艺名（汉字/片假名/英文）
    row: 行           # 五十音行名（あ/か/さ/...）
    col: 段           # 五十音段名（あ/い/う/...）
    completeness: N%  # 条目完整度（0-100）
```

### 排序规则

items 按以下顺序排列：
1. **行顺序**：あ → か → さ → た → な → は → ま → や → ら → わ
2. **段顺序**：あ → い → う → え → お

女优按读音在上述网格内依次排列。

## 文件系统映射

目录路径：`src/{row}/{col}/{女优名}.md`

示例：
- `src/か/か/河北彩花.md`
- `src/は/べ/ベアトリクス.md`
- `src/ま/み/Miru.md`

每个 `{row}/` 目录下应有 `index.md`（行索引），每个 `{row}/{col}/` 目录下也应有 `index.md`（段索引）。

## 一致性约束

以下三者必须完全对应：
1. **list.yaml** 中的 `row` / `col`
2. **文件系统**中的目录路径 `src/{row}/{col}/`
3. **目录索引** `src/{row}/index.md` 和 `src/{row}/{col}/index.md` 中的条目链接

任何新增、修改或删除操作必须同步更新上述三处。

## 完整度 (completeness)

| 等级 | 含义 |
|------|------|
| 100% | 条目内容完整（基本信息、简介、作品特征、年表、参考资料齐全） |
| 65%  | 条目有基础结构，但部分章节缺失 |
| 10%  | 仅有骨架，内容待填充 |
| 0%   | 未创建 |
