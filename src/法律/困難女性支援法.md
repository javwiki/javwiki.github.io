# 困難女性支援法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 困難な問題を抱える女性への支援に関する法律 |
| 通称 | 困難女性支援法 |
| 法令番号 | 令和3年法律第46号 |
| 施行 | 2021年10月1日 |
| 所管 | 厚生労働省 |

## 概要

该法为面临各种困难的女性提供综合支持，包括经济援助、就业支援、心理咨询、法律援助等。AV出演者因出演经历导致社会关系破裂、精神健康问题等时，可通过该法获得支持。

## 主要内容

### 支援对象

- 面临暴力、虐待、贫困等困难的女性
- 需要保护和支持的女性
- 包含AV出演后遭受社会歧视、网络暴力的女性

### 支援措施

- 经济援助
- 就业支援
- 心理咨询
- 法律援助
- 临时庇护

## 与AV行业的关联

AV出演者可能因作品传播面临网络暴力、社会歧视、心理创伤等问题，可通过该法获得政府提供的综合支持。
