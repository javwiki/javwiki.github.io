# 民法

| 项目 | 内容 |

| 正式名称 | 民法 |

## 概要

民法是日本民事法律的基本法，规定了私人之间的法律关系，包括契约、侵权、亲属、继承等基本法律制度。2022年4月施行的修订将成年年龄从20岁降至18岁，对AV出演者的签约能力产生重要影响。

## 主要相关条款

### 成年年龄

- 2022年4月1日前：20岁为成年年龄
- 2022年4月1日起：18岁为成年年龄
- 18-19岁者可独立签订契约，无需监护人同意

### 契约能力

- 未成年人（未满18岁）签订契约需监护人同意
- 成年者可独立签订契约

### 侵权行为

- 因故意或过失侵害他人权利者，应承担损害赔偿责任
- 适用于AV出演中的侵权行为（如未经同意的影像传播）

### 撤销权

- 因欺诈、胁迫而订立的契约可被撤销
- 适用于AV出演中的不当签约行为

## 与AV行业的关联

| 关联点 | 说明 |
| --- | --- |
| 签约能力 | 成年年龄降低使18-19岁者可独立签约，需特别保护 |
| 契约撤销 | AV出演者可以欺诈、胁迫为由撤销契约 |
| 侵权赔偿 | 出演者可因侵权行为请求损害赔偿 |
