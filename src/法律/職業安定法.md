# 職業安定法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 職業安定法 |
| 法令番号 | 昭和22年法律第141号 |
| 施行 | 1947年10月15日 |
| 所管 | 厚生労働省 |

## 概要

職業安定法规范职业介绍、劳务派遣等就业服务，保护劳动者的合法权益。

## 主要内容

### 职业介绍

- 职业介绍需获得厚生劳动大臣或都道府县知事的许可
- 禁止不当职业介绍行为
- 保护求职者隐私

### 劳动者保护

- 禁止强迫劳动
- 禁止不当解雇
- 保护劳动者合法权益

## 与AV行业的关联

AV制作涉及劳动者（出演者、工作人员）的权益保护。出演者作为劳动者，享有该法规定的各项保护，包括禁止强迫劳动、保护隐私等。AV制作方违反该法时，出演者可依法维权。
