# リベンジポルノ防止法

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 正式名称 | 私事性的画像記録の提供等による被害の防止に関する法律 |
| 通称 | リベンジポルノ防止法、复仇色情防止法 |
| 法令番号 | 平成26年法律第128号 |
| 施行 | 2015年1月1日 |
| 所管 | 法務省、警察庁 |

## 概要

该法旨在防止复仇色情（revenge porn）对受害者造成伤害，禁止未经同意传播他人私密影像。

## 主要内容

### 禁止行为

- 未经同意向第三方提供他人私生活影像
- 在网络上传播他人私生活影像
- 以伤害他人为目的提供影像

### 处罚

- 违反者面临刑事处罚（有期徒刑或罚金）
- 传播者可被追究刑事责任

### 受害者权利

- 可要求传播者停止传播
- 可要求删除相关影像
- 可请求损害赔偿

## 与AV行业的关联

AV出演者若遭遇未经同意的影像传播（如流出、转发等），可通过该法获得法律保护。与AV出演被害防止法形成互补，为出演者提供全面的法律救济。
