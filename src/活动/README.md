# 活动

JAV 相关的线下展览与活动，主要收录台湾、日本等地举办的成人展览、写真博览会等现场活动。此类活动通常邀请日本 AV 女优、写真偶像及各地 Coser 到场，进行舞台演出、签售合影与拍摄交流，是女优与粉丝直接交流的主要渠道。
