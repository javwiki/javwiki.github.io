# FANZA 成人奖

FANZA 成人奖（FANZAアダルトアワード）是由日本电子商务网站 FANZA（原 DMM.R18）主办的年度 AV 奖项，是日本 AV 行业最重要的奖项之一。该奖项自 2014 年开始举办，2019 年由 DMM 更名为 FANZA。**2020 年以后因各种原因未再开催**。

名称变迁：
- 2014年：DMMアダルトアワード
- 2015-2018年：DMM.R18アダルトアワード
- 2019年：FANZAアダルトアワード
- 2020年至今：未开催

| 奖项 | 说明 |

| 最优秀新人女优奖 | 年度最佳新人女优 |
| 优秀新人女优奖 | 优秀新人女优奖（2017年起新设） |
| 特别奖 | 特别贡献奖 |
| 话题奖 | 年度话题人物 |
| 媒体赏 | 媒体投票选出的最佳女优 |
| 週刊プレイボーイ赏 | 週刊Playboy购入者投票决定（2018年起，属个人奖） |
