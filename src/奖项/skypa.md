# 成人广播奖（スカパー!アダルト放送大賞）

成人广播奖（スカパー!アダルト放送大賞）是由日本 Sky PerfecTV! 主办的成人放送行业奖项。2005年开始举办（初期名为"日本アダルト放送大賞"），2008年改为现名。2020年因疫情延期，2022年起改为EXガールズ选拔模式。2024年起投票形式废止，改为EXガールズ选拔。

## 奖项类别

### 个人奖项（2006-2020）

| 奖项 | 说明 |
| --- | --- |
| 女优奖 | 年度最佳 AV 女优 |
| 新人女优奖 | 年度最佳新人女优 |
| 熟女女优奖 | 年度最佳熟女系女优 |
| 最多出演女优奖 | 年度作品数量最多的女优 |
| 媒体赏 | 各媒体颁发的奖项 |
| スカパー!オンデマンドアダルト赏 | 点播部门最佳女优 |

### EXガールズ（2022 至今）

2022年起，该奖项改为EXガールズ选拔模式，由各频道推荐女优，最终选出MVA（Most Valuable Actress）等称号。
