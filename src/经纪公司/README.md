## 经纪公司职能

### 主要业务

| 职能 | 说明 |
| --- | --- |
| 女优经纪 | 管理女优的演艺事业、合约谈判 |
| 工作安排 | 安排拍摄、活动、宣传等工作 |
| 形象管理 | 管理女优的公众形象、社交媒体 |
| 法律事务 | 处理合约、版权等法律事务 |
| 财务管理 | 管理女优的收入、税务等 |

### 与厂商关系

经纪公司与厂商是合作关系，经纪公司负责提供女优资源，厂商负责作品制作和发行。双方通过合约约定分成比例和工作条件。

## 经纪公司与女优关系

### 合约类型

| 类型 | 说明 |
| --- | --- |
| 专属合约 | 女优只在特定厂商发行作品 |
| 非专属合约 | 女优可以在多家厂商发行作品 |
| 独立合约 | 女优独立管理自己的事业 |

### 合约期限

合约期限通常为1-3年，到期后可以续约或解约。部分女优会选择独立发展，不再依赖经纪公司。

## 经纪公司选择

### 选择标准

| 标准 | 说明 |
| --- | --- |
| 公司规模 | 大公司资源丰富，小公司更灵活 |
| 业务范围 | 是否涵盖女优需要的业务类型 |
| 口碑评价 | 业界口碑和女优评价 |
| 分成比例 | 收入分成是否合理 |
| 发展机会 | 是否能提供更多发展机会 |

### 注意事项

- 选择正规经纪公司，避免黑中介
- 仔细阅读合约条款，了解权利义务
- 保留相关证据，维护自身权益
