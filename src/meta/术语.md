| 术语 | 说明 |
| --- | --- |
| 专属女优 | 与特定厂商签订专属合约，只在该厂商发行作品 |
| 企划单体女优 | 无专属合约，可在多家厂商发行作品 |
| 写真偶像 | 拍摄写真集、形象视频的模特 |
| 引退 | 女优结束 AV 生涯 |
| 活动休止 | 女优暂停活动，但未正式引退 |
| 移籍 | 女优从一家经纪公司转到另一家 |
| 复出 | 引退后重新开始活动 |
| 新人 | 刚出道的女优 |
| 専属移籍 | 专属女优从一家厂商转到另一家 |
