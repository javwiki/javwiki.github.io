# FANZA 成人奖

FANZA 成人奖（FANZAアダルトアワード）是由日本电子商务网站 FANZA（原 DMM.R18）主办的年度 AV 奖项，是日本 AV 行业最重要的奖项之一。该奖项自 2014 年开始举办，2019 年由 DMM 更名为 FANZA。

## 奖项类别

### 个人奖项

| 奖项 | 说明 |
| --- | --- |
| 最优秀女优奖 | 年度最佳 AV 女优 |
| 优秀女优奖 | 优秀女优奖（通常 2-3 名） |
| 最优秀新人女优奖 | 年度最佳新人女优 |
| 优秀新人女优奖 | 优秀新人女优奖 |
| 特别奖 | 特别贡献奖 |

### 作品奖项

| 奖项 | 说明 |
| --- | --- |
| 最优秀作品奖 | 年度最佳作品（配信部门、租赁部门、通販部門） |
| 话题奖 | 年度话题作品 |

### 媒体奖项

| 奖项 | 说明 |
| --- | --- |
| 媒体奖 | 媒体投票选出的最佳女优 |
| FLASH奖 | FLASH 杂志读者投票奖 |
