# ADULTOPIA 大人国

ADULTOPIA（アダルトピア）是由日本 Sky PerfecTV! 主办的成人放送大赏，是日本成人放送行业的重要奖项之一。该奖项自 2005 年开始举办，2020 年后因疫情调整形式，2022 年起改为 EXガールズ 选拔模式。

## 奖项类别

### 个人奖项（2006-2020）

| 奖项 | 说明 |
| --- | --- |
| 女优奖 | 年度最佳 AV 女优 |
| 新人女优奖 | 年度最佳新人女优 |
| 熟女女优奖 | 年度最佳熟女系女优 |
| 最多演出女优奖 | 年度作品数量最多的女优 |

### EXガールズ（2022 至今）

2022 年起，该奖项改为 EXガールズ 选拔模式，由各频道推荐女优，最终选出 MVA（Most Valuable Actress）等称号。
